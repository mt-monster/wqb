## 三、★根因：E2 是**数学重复计算**，不是新轴

E2 的定义：`(boundary_transaction_total − stable_boundary_trade_count_21d) / accounts`
而 A8 的腿是：`boundary_transaction_total / accounts` 与 `stable_boundary_trade_count_21d / accounts`

⇒ **E2 = A8 的两条腿相减**。把它加进 A8，等于 `L1 + L2 + L3 + (L2 − L1)`
   = `2·L2 + L3` —— 只是**把 L2 的权重翻倍**，并没有引入任何新信息。

**实测验证**：P5-5 与 A8 相关 **0.9625** ⇒ 确认是同一持仓的重新加权，不是新机制。
这也解释了为什么 S 从 1.22 掉到 1.14（等权平均把 L3 稀释了）。

**这是我的设计缺陷**：E2 是在 `fund_holdings_panel` 里硬造的「退出残差」，
而 `fund_holdings_panel` **没有独立的退出字段**（只有 boundary_total 这个双向合计）。
真正的退出侧只能在 `institutions6` 的 `disposed`（E1）拿到 —— 而 E1 组合后只有 0.70。
