## 二、判定：fundamental89 在 DEU 无效（数据有，信号无）

1. **数据存在，但持仓面偏窄**：`longCount` 仅 78-94，明显低于满覆盖组合件（如 qM7KxkQV 的 149/146）；
   平台 dataset listing 显示的 `coverage = 0.0` 与实际有数据不符（列表面板口径不可信，须以回测 longCount 为准）。
   ⚠ 具体覆盖百分比未测，不得据 78-94 反推百分比（中性化后持仓数受多因素影响）。
2. **信号几乎为零**：10 臂 S ∈ [-0.21, 0.69]，中位数 0.07。换算后 R 仅 0.002-0.037。
3. **应计异象在 DEU 不成立**（或该数据集的实施太弱）。Sloan 应计异象的强先验未转化为可交易信号。

**处置**：fundamental89 记 **弱/死**，不再投波次。但仍保留「已实测」状态，不算未探索面。

## 四、方法论补充：SC ≤ 0.3 预筛（论坛 → 「信号合成中的对冲思维」）

从论坛帖（article 41765214156439，作者 FF45555）及其评论提炼：

1. **「0.8 + 0.8 不一定等于 1.5」**：`add/subtract` 合成能放大共同信号、抵消独立噪声，**前提是 A、B 各自独立**；
   若两者只是同一底层因子的两种写法 → 「假对冲（pseudo-hedge）」，IS 涨了 OS 大概率回归。
2. **前置检查红线：两腿截面相关 SC ≤ 0.3**（帖子作者经验值，非平台硬门槛）再合成。
3. **量纲必须先对齐**（rank / zscore），否则差值被方差大的一方主导。
4. 降换手想保留瞬时冲击力用 `ts_decay_linear`（不是 `ts_mean`，后者滞后更大）。
5. `group_neutralize(A, bucket(B, 5))` 在 A=量价、B=基本面场景优于直接减（保留非线性）。
