# BE133 双波：三腿交互 + event age 时间维度（INSIDERS，decay0）

> 142 臂后 S 收敛于 1.54（幂次轴已证不敏感）。本轮引入**两个全新信息维度**，不是现有维度的重排。

## 波 A：三腿交互（`2hPi4kadh4K391Dm1EhSeVG`，8 臂）

当前结构是 `A + B + C`（纯加法）。BE125 已证**两腿乘法**把 2Y 推到 2.06（S 掉到 1.03），但**三腿交互从未系统测过**。

| # | 结构 | 含义 |
|---|---|---|
| 1 | A+B+C（冠军对照）| 基准 1.54 |
| 2 | **A×B + C** | 变化 × 信噪比一致度，再加集中度 |
| 3 | A+B + **B×C** | 信噪比 × 集中度一致度 |
| 4 | **A×C + B** | 变化 × 集中度一致度 |
| 5 | **A×B×C** | 三腿全乘（强门控）|
| 6 | A+B + **A×B×C** | 加法 + 交互项（线性+非线性混合）|
| 7 | A + B×C + C | 双 B 叠 C 交互 |
| 8 | A+B **−** C | HHI 反向（检验集中度方向）|

**核心假设**：加法把三腿信息等权平均，**乘法只在该腿同时强时给分**。若三腿的强信号股重合度低，乘法会大幅收窄持仓（可能 S 升或崩）。

## 波 B：event age（`2QfVOu5gI5178WDNCQ2Wv3o`，8 臂）

**全新维度**：`days_from_last_change(vec_avg(insd1_holdings))` = 距上次内部人持仓变化的天数。
构造：`freshness = 1/(age+1)` —— 越近越大。

| # | 结构 | 含义 |
|---|---|---|
| 1 | 冠军对照 | 基准 |
| 2 | **持仓新鲜度单腿** | 距上次变动越近 → 越强？ |
| 3 | 交易新鲜度单腿 | 用 shares 口径 |
| 4 | C → 新鲜度 | 用新鲜度替换 HHI 腿 |
| 5 | **四腿** A+B+C+新鲜度 | 加第四维 |
| 6 | A + **B×新鲜度** + C | 信噪比 × 新鲜度门控 |
| 7 | A+B + **C×新鲜度** | 集中度 × 新鲜度 |
| 8 | **A×新鲜度** + B | 变化 × 新鲜度 |

**理论依据**：Cohen-Malloy-Pomorski 2012 的核心主张是「知情交易的**信息量随时间衰减**」——刚发生的内部人交易信息量最大。若成立，新鲜度应带来 S 的提升。

## 判读线

- 任一臂 **S ≥ 1.58** ⇒ 该维度有效，进定向补冲双闸
- S 1.54-1.58 ⇒ 边际，但与冠军组合可能突破
- 全 ≤ 1.54 ⇒ 两维度关闭，INSIDERS 以 1.54 定型收档
