## 五、sentiment27 判定：单塔不可行（天花板 S 0.95）

两波共 16 臂，覆盖：
- 矩：变化面（Δ66/132/252）× 水平面（zscore252/504）× 位置面（ts_rank252/504）
- 腿数：单腿 / 双腿 / 分布形状叠加
- 字段：rank / 平均排名 / 最佳排名 / 分位排名 ×3 / 流行度 ×2 / 偏度 / 峰度 / 域名数 ×2

**S 天花板 = 0.95（BE27 臂 4），距 1.58 差 0.63。**

### 为什么它不可能达到 1.58

关键证据：**`vRAKQ1eb`（纯 rank504 单腿）S = -0.01，但 sub = 1.04。**

这说明 Tranco 域名排名的**方向性信息接近于零**——它在子宇宙层面很稳定（sub 高），
但没有横截面择时能力。企业网站流量是**结构性规模指标**（谁大谁小基本不变），
而 alpha 需要的是**可预测的变化**。

⇒ **sentiment27 属于「有覆盖无信号」的数据集**，与 fundamental72（lc=26-68）不同：
它数据充足（lc 175-188）、覆盖最高（0.90），但**经济内容不含可交易的方向性信息**。

**处置**：sentiment27 记 **弱/死**（单塔口径），不再投波次。
SENTIMENT 塔仍未点亮（1 颗），但 sentiment27 无法贡献新件。
