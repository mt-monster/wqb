## 一、nan_handling 的分族结论（BE74 实测）

| 字段族 | nan=ON | nan=OFF | 结论 |
|---|---|---|---|
| **高覆盖事件型 VECTOR**（nws20 情绪 cov 0.92） | **S 1.46** | S 0.18-0.54 | **ON 更好**：填 0 让无新闻股变现金腿，组合的横截面排序保留 |
| **低覆盖事件型 VECTOR**（insd1_holdings cov 0.53） | 待测（BE74b） | 同上 | 低覆盖字段需单独验证 |
| **纯 MATRIX 预估族**（est_12m_ebi_median 等，analyst） | S 0.51 | **S 2.02**（配合 FAST/decay0） | **OFF + FAST + decay0**：分析师预估字段不允许被填 0 |
| 水平型 rank 腿（I7） | 1.46（组合内） | -0.01（单腿） | rank 腿不怕 ON |

**推论**：nan ON/OFF 的选择取决于「无数据股票在该信号里应该扮演什么角色」——
事件型高覆盖字段：无事件 ≈ 现金腿，ON 合理；
预估类 MATRIX 字段：无数据 ≠ 零预期，OFF + FAST 让缺失股自然退出排序。

## 五、操作纪律（终版）

1. **新数据集首波必做设置档扫描**：nan ON/OFF × 中性化 × decay 0/4/8，每个信号族找到自己的档；
2. **复制存量 alpha 做对照时必须连 settings 一起复制**（表达式相同≠信号相同）；
3. **多腿组合的收割必须用平台 code 逐臂核对**（harvest 顺序≠提交顺序）；
4. **事件型 VECTOR 组合腿优先不回填**（低覆盖字段回填后 -1.37 反号）；
5. **二值门用 greater() 直接乘**，不要连续权重。
