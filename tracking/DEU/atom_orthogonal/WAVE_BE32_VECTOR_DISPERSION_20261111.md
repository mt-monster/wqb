## 二、两个关键判读

### 1. 分歧度方向为负 ⇒ 应做多高分歧，不是做空

四个分歧度臂（vec_stddev / vec_range / 双方法 / tail）**全部为负 S（-0.43 ~ -0.47）**，高度一致。
这说明机制确实存在（信号不弱），但**符号与论坛帖的说法相反**：
- 论坛帖说「正面情绪分歧度达峰 → 做空近期炒作」；
- 我的数据说「高分歧 → 后续表现更好」，即**分歧已被过度定价，反而是机会**。

⇒ 这是**有信息但方向反了**，不是没信号。按纪律应先翻转符号验证机制上限。

### 2. ★覆盖是硬约束：longCount 仅 17-95

sentiment33 的 platform coverage = **0.322**，实测 longCount：

| 结构 | longCount |
|---|---:|
| bucket 分桶（最窄） | **17** |
| tail 截断 | 52 |
| vec_stddev / vec_range | 63 |
| vec_count+vec_avg | 81 |
| 分歧+变化 | 95 |

满覆盖件是 149-188。**`ts_backfill` 救不回覆盖**——它只能填补已有数据的间隔，不能凭空创造缺失股票。
⇒ sentiment33 的 cov 0.32 决定其 longCount 上限约 95，这是结构性天花板。
