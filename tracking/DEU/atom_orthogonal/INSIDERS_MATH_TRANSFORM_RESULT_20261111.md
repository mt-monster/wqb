# INSIDERS 数学变换波结果（BE119/BE120，2026-11-11）

## ★方法论级发现：group_rank 下的单调变换不变性

**实证**：`group_rank(signed_power(ts_delta(ts_mean(holdings,66),66), 0.5), sector)` 与原始 Δ66 臂**逐位相同**（S 1.06 / F 0.88 / TO 7.23% / 2Y 0.87 / lc 63/sc 124）。

**机理**：`signed_power`、`log`、`ts_quantile`（作为纯变换时）都是**保序映射**；`group_rank` 只依赖排序，因此变换前后排序不变 ⇒ 输出完全一致。
**推论（可复用）**：在「最终步是 rank 类算子」的骨架里，**任何单调压缩/展开都是零收益**。真正能改变信号的只有六类：
1. 平滑（ts_mean / ts_sum / ts_decay_linear）
2. 差分（ts_delta / ts_av_diff）
3. 尺度归一化（divide by adv20 / market cap）
4. 比值（A/B 结构）
5. 时序统计量（ts_ir / ts_corr / ts_std_dev / ts_kurtosis）
6. 横截面/分组算子（group_* / bucket / vector_neut）

⇒ 这条推翻了「多做数学变换就能增强信号」的直觉：**变换必须改变排序，否则无效**。
