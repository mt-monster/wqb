# ★机制优先派发清单（Mechanism-First Dispatch Checklist）v1，2026-11-12

> 起因：用户问「数据字段你是依据什么组成 alpha 的，有无明确经济学含义」——自查发现本轮 30 臂里约 1/3 是**纯形态模板套用**（`group_rank(ts_mean(vec_sum(F),22),industry)`，只换 F），
> 且换手治理波 10 臂**零新增经济学**。本文是对该缺口的制度性修复，接入 [PROBE_PROTOCOL_V2_20261112.md](PROBE_PROTOCOL_V2_20261112.md)。

## 一、三条依据的分工（顺序不可颠倒）

| 层 | 依据 | 决定什么 | 不能决定什么 |
|---|---|---|---|
| 1 | **经济学含义**（文献 / 论坛实证） | 测什么、符号方向、预期幅度 | 写法细节 |
| 2 | **成熟模板** | 组合几何（骨架） | 是否值得测 |
| 3 | **字段形态**（type / 覆盖 / 更新频率 / 量纲） | 算子选择、窗口、回填窗、是否可比值 | **绝不能用来定机制** |

### 形态 → 算子 的硬约束表（平台语义，不是偏好）

| 形态 | 规则 | 违反后果 |
|---|---|---|
| VECTOR | `vec_*` 必须在最内层；`ts_backfill` 入参是裸字段 | 整批 CANCELLED |
| MATRIX | 直接进 `ts_*`；**不可** `vec_avg` | 类型错 |
| GROUP | 才能进 `group_*`；MATRIX 需 `bucket(rank(F),range="0,1,0.1")` 桥接 | `expected Unit[Group:1]` |
| 更新频率 | 决定回填窗（季频 ≥252；日内切片另议） | 回填窗=持仓宽度开关（DEU esm 实证 5d→7 只/252d→122 只） |
| 量纲 | 不同量纲**必须**比值，不可差值 | `add(count,0.0001)` 触发单位闸 |
| 稀疏度 | lc/sc 任一侧 <50 ⇒ 稀疏退化，不得进 L2 | 噪声冒充信号 |

## 二、派发前必填四栏（空栏 = 不得进主线）

每条臂必须登记：

| 栏位 | 填什么 | 空栏后果 |
|---|---|---|
| **机制声明** | 一句话：信息如何形成、为何被错误定价 | 空 ⇒ 只能进「廉价探针」配额，不占主线 |
| **文献来源** | 论文 / 论坛帖 id / 本区已出货件 id（三选一以上） | 空 ⇒ 降级为探索臂，不得作为判死依据 |
| **字段形态约束** | 该字段的 type / 更新频率 / 量纲，及因此选的算子与窗口 | 空 ⇒ 不得派发（类型错会整批 kill） |
| **预期幅度** | 预期 S 区间 + 预期符号 + 若不符如何处置 | 空 ⇒ 事后无法区分「假设错」与「样本短」 |

### 配额规则（关键）

- **主线臂**（占正常回测配额）：四栏全填。
- **廉价探针臂**（形态探测、密度、可执行性）：机制栏可空，但**单波不超过 3 条**，且**不得据此判死**。
- **治理臂**（decay / 换手 / 中性化调参）：**天然无机制**，必须单独成波、不得与机制臂混批，且不得计入「机制覆盖」证书。

## 五、与 PROBE_PROTOCOL_V2 的衔接

| v2 层 | 本清单如何约束 |
|---|---|
| L1 正交网格（10 臂） | 其中「2 臂文献模板」必须四栏全填；其余 8 臂允许机制栏简写但**不得空** |
| L2 升级（≥1.2） | 升级臂必须写「预期幅度」，否则升级无判据 |
| L3 六维满波 | 天然含设置维 ⇒ 治理臂须单独成波，不混入 |
| L4 窄点猎手 | 窗口阶梯属参数维，机制栏可继承主腿声明 |

## 六、判死证书的连带要求（沿用并强化）

判死档案必须同时给出：①已覆盖字段族数/总字段族数 ②每族最高 S ③每族有效持仓 lc/sc ④**已覆盖机制数**（而非臂数） ⑤未覆盖机制清单。

⇒ 只有「臂数」没有「机制数」的证书，一律标 `provisional`，不得作为数据集级判死。
