BE119/BE120 证明：**group_rank 下单调变换是空操作**，但 **ts_ir（时序信噪比）与 HHI（横截面集中度）改变了排序**，与 Δ66（变化维度）三者数学上正交 ⇒ 首次具备真实协同条件。

## 判读

1. **S 天花板 1.06 → 1.11（+0.05）**，且 **2Y 从 0.87 提到 1.49（+0.62）**——这是 INSIDERS 类第一次 **S 与 2Y 同步改善**（此前所有杠杆都是跷跷板）。
2. **协同结构清晰**：ts_ir 单独 0.97、HHI 单独 0.83，两者组合 1.09（+0.12 协同），再加 Δ66 到 1.11。三个数学构造各自捕捉不同维度：
   - **Δ66** = 持仓**变化**（变动速度）
   - **ts_ir** = 持仓**信噪比**（持续性 × 稳定度）
   - **HHI** = 交易**集中度**（秩序统计）
3. **ts_ir 的窗口敏感**：22 → 0.83 / 66 → 0.97 / 132 → 0.70，**66 是甜点**（与全战役其他族一致）。
4. **ts_ir(Δ66) 崩到 0.35**：对变化序列再取信噪比会抹掉信号（除零放大噪声）。
5. 臂 3（ts_ir+HHI）的 **sub 0.51 是全类最高**——两腿组合的多空分布最健康。

## 判定：进满波（Step 5）

判据达成：**1.11 > 1.07**（旧天花板）⇒ 数学变换 + 三正交排序组合路径有效，继续扩展。

**满波设计方向（BE122）**：
1. **权重结构**：三腿的等权是唯一合法形式（加权混腿被静态闸拦）；改用 **嵌套 group_zscore / group_neutralize** 做「二阶中性化」而非加权
2. **HHI 族扩展**：Top1 份额（现用）/ Top1−Top2 / Top2 份额 / 二级市场集中度
3. **ts_ir 族**：holdings / valueeur / shares 三个字段各自取信噪比
4. **中性化轴**：簇中性已提升到 1.11，再试 market / subindustry 外层
5. **窗口组合**：ts_ir(66) + ts_ir(110) 双窗（等权）
6. **门控**：用 HHI 高分位做 trade_when 门控（只在集中度高的股票上开仓）

**收档判据**：若满波后 max < 1.2 ⇒ 数学变换路径见顶（1.11），INSIDERS 类最终天花板 1.11，收档；若 ≥1.2 ⇒ 继续冲。
