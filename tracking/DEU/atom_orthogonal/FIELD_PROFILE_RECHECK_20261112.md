# ★DEU 字段画像再分析：判死证书是「数据集级」的，不是「字段级」的（2026-11-12）

> 用户裁定（本轮）：「重新分析一下其下数据集字段画像」。不把 12 塔收口当结论，回到字段层重算覆盖面。

## 一、方法（两张口径，取区间而非单点）

语料：`tracking/DEU` 全部 **1092 个 .json + 398 个 .md**（含波次派发、结果、报表、判死档），
从中抽出 **13,256 条真实表达式字符串**（含括号、可解析），得到表达式中的标识符集合 7,642 个。

| 口径 | 定义 | 性质 |
|---|---|---|
| **宽松**（上界） | 字段名在任意档案中出现过就算「测过」 | 会把「探针计划里列过但没派」的字段算成测过 |
| **严格**（下界） | 字段名只出现在真实表达式字符串里才算「测过」 | 会漏掉「结果表用散文写、没带括号」的已测字段 |

**两个口径的差就是不确定性区间**，所有结论都按区间表述，不取单点。

## 二、★发现一：20,012 个字段里，从未进入任何真实表达式的有 18,929 个（94.6%）

即使按**宽松**口径（任何档案提过即算），DEU 已点亮+已判死全部战役合计也只碰过字段池的 **5.4%**。

这意味着：**现有 9 张 v2 判死证书全部是「数据集级」结论，不是「字段级」结论。**
判死逻辑是「这个数据集我试了 3-30 个字段，最高 S 只有 X」⇒ 推出「这个数据集不行」，
而每个数据集的字段池是几十到上千。**这是推理跳跃，不是证据链。**

对照本战役自己的纪律（判死前探针穷尽度：不得凭先验封禁整个字段族），这一条被系统性违反了。

## 四、★★发现三：pv20 是一个「挂着 PV 招牌的 IBES 会计宝库」（684 字段仅碰过 1–20 个）

pv20 的 681 个字段，结构完全拆解如下：

**12 个 IBES 会计指标**：`bps / ebi / ebt / ent / eps / gps / nav / net / opr / pre / roe / sal`（各 52 个字段）。

**已测字段（严格口径 1 个 / 宽松口径 20 个）**：`adv20_usd_capped_100m` 是唯一被真实表达式用过的；

### 为什么这是本战役价值最高的一处

1. **同源信号在不同塔**：`ebi / ebt / pre / roe / sal / bps` 正是 analyst7 冠军件用的指标族
   （`6XM87Zb7` = `est_12m_ebi_median` + `ebt_mean` Δ4w + `pre_mean` Δ6w ⇒ **S 1.87**；
   存量 `RREPm361`/`zq3eb7No` = 2.02/2.01）。**同一批 IBES 会计信息，在 pv20 里挂的是 PV 塔。**
2. **PV 塔 0 颗 ⇒ 不受「已点亮塔冻结」约束**（用户 11-06/11-11 的硬约束只冻结已点亮塔）。
3. **PV 塔倍率 = 信号强度杠杆**：未点亮塔每颗 ATOM 点亮进度 +1，且 PV 塔倍率 1.6。
4. **pv20 已用尽的面只有流动性**：`pv20×insiders` 族 7 波 62 臂，天花板 **S 1.37 / 2Y 1.56**（差 0.21/0.02，
   PROVISIONAL 未判死）——而那一族自始至终**只用 `adv20_usd_capped_100m` 一个 pv20 字段**，624 个 IBES 字段一次没用。

### 必须先解决的不确定性（不能跳过）

- pv20 全部 681 字段的 `coverage` 都显示 **0.00**，但 `adv20_usd_capped_100m` 实测有健康持仓 ⇒
  **本数据集的 cov 字段不可信**（与 earnings6/fnd90/risk72/institutions1/pv1 同类，已 6 例）。
- 624 个 IBES 字段里，描述为 `Non-trivial feature` 的有相当比例（语义不透明），**必须实测数据存在性**，
  不能凭字段名推断含义。

## 七、结论（三条）

1. **DEU 的判死体系需要降级**：9 张 v2 证书是「数据集级」结论，建立在平均每集 <30 个字段的探针上；

2. **pv20 的 624 个 IBES 会计字段是本战役最大的未开采面**——同源信息在 ANALYST（冻结）出过 S 2.06，
   在 PV（全开）一次没试；且 PV 塔 0 颗、倍率 1.6。
3. **不能凭字段名推断**：cov 全 0 + 大量 `Non-trivial feature` 描述 ⇒ 先 4 臂验数据存在性，
   再决定是否整波。这一条是本战役已被 6 次证实的方法论（cov=0 ≠ 无数据）。
