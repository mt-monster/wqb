> 用户指令背景：KOR insd5 最优基线 S=0.71 / 2Y=2.42（2Y 已 PASS，Sharpe 差 0.87）。

## 一、核心结构认知：2Y 与全周期 Sharpe 是「强对冲」

**来源**：`43583615602711`【结构认知】全周期 sharpe 和 2y sharpe 的强对冲（LL46807，21 票，2026-09-18）

- **全周期 sharpe 与 2Y sharpe 呈强对冲**：全周期越好的配置，2Y 往往越差。
- **实证案例一**：分析师族信号，全周期 0.87，2Y 从 0.64→1.18 单调反向；**换到变化轴（`ts_delta 60d`）后全周期抬到 0.96，2Y 又压回 0.64** —— 两个指标像跷跷板，调参只是在跷跷板上挪支点。
- **实证案例二**：动量比率持续性族，全周期 1.0–1.2 平台全部达标，**2Y 变体无一超过 0.91** → **结构性真墙**（近两年信号衰减）。
- **实操用法**：
  1. 把 **2Y 当独立验收关卡**，不当全周期附属；
  2. **双车道设计**：一条车道按全周期最优配参，一条专门按 **2Y 最优**配（缩短窗口、加权近期）；两条车道找不到交集 → 信号是历史型，及早归档；
  3. 全车道闭合且 2Y 结构性不达标 → **整理证据链上报裁决，不要换批继续磨**。

⇒ **对本轮的意义**：KOR insd5 的 2Y=2.42（**远超门槛**），说明它不是"历史型信号"，**属于 2Y 富余型**；Sharpe 低是另一个维度的问题（信号弱/覆盖窄），不是 2Y 结构性墙。**两条车道在这里不冲突**。

## 二、提 LOW_SHARPE / LOW_2Y_SHARPE 的三个直接杠杆

**来源**：`41262095695127` 几个提高 LOW_SHARPE 和 LOW_2Y_SHARPE 的方法（LC69991，6 票 + 1 评论）

| # | 杠杆 | 原文要点 | 备注 |
|---|---|---|---|
| 1 | **`signed_power` 幂变换** | 带符号幂次压缩：保留正负号，对大绝对值开方/幂次，**把极端值压下去，中间段区分度拉开** → 长尾分布因子截面排序更稳定 | 评论区 QQ68782：**exponent=0.5（开方）对大部分 dataset 最稳**；0.7 在信号偏弱时反而压过头。**从 0.5 起调** |
| 2 | **decay 按换手率阶梯增加** | 不固定 decay，按因子换手率动态给：换手低给小 decay，换手高给大 decay | 评论区：**统一 decay=5 常拉低 2Y sharpe，阶梯 decay 能缓解** |
| 3 | **truncation 配合** | 若 2Y 离 1.58 差 0.1–0.2，可把 truncation **从 0.08 降到 0.05** | **signed_power 压尾后 truncation 不用开太大** |

⇒ **本轮 KOR insd5 的 S=0.71 差 0.87（远超 0.2）**，按该帖"太低的调节意义不大，一般 1.55 左右可轻松通过"的判断 —— **纯参数调节不够，需结构升级**。

## 三、`ts_delta` 是第一杠杆（实测证）

**来源**：`43211144870807` 看到 "2 year Sharpe of 0.75 is below cutoff of 1.58"，先别急着调 decay（DQ66419，16 票，2026-09-03）

**排查顺序（比瞎调参有用）**：
1. **先看 yearly Sharpe / 分年 PnL，定位哪一年拖后腿**。若集中在风格切换剧烈年份 → 多半暴露在没中性化的行业/风格上 → 上 `sector/subindustry` 中性化，或把 `rank()` 换成 **`group_rank(, sector)`**（财务类字段在行业内才有可比性）。
2. **警惕信号"断粮"**：delay1 财报字段更新慢 → **加 `ts_backfill`**，或改用 **`quantile(ts_rank(x, N))`** 时序排名把更新节奏磨平。
3. **别单吊一个数据源**：纯基本面因子近两年集体失灵 → **乘一个动量/波动类价格因子**（但注意：本项目铁律禁混腿，须用"门控/单信号结构化"替代）。
4. **顺手看 turnover**：换手高被手续费吃掉，加 decay 合理（**理由是控换手，不是调参**）。
5. **官方提醒**：Sharpe 和 2Y Sharpe **经常一起 FAIL**，很少只挂一个；达标后重点应放在**收益**上。

**来源**：`41707021146263` MEA TOP400 实战（YZ54944，47 票，12 次手搓）
- **关键：`ts_delta` 窗口 500→250**（缩短动量窗口）→ **信号对近期变化更敏感 → 修复 2Y Sharpe**（0.81 → 1.63 ↑）
- 配合：外层 `ts_zscore(...,250)` 压极端权重（修 Weight Concentration）；decay 8→6；neutralization MARKET→SUBINDUSTRY
- 数据：Sharpe 1.65→2.03 ↑ / Fitness 1.78→2.60 ↑ / 2Y 0.81→1.63 ↑

⇒ **`ts_delta` 是论坛多篇独立印证的第一杠杆**。w7 批已实测（22/63/5/252 窗口）。

## 四、`ts_std_dev` 标准化 —— Sharpe 0.37→3.08 的关键跳跃

**来源**：`43307320610583`【Alpha Idea】投资者注意力因子（WW11235，Sharpe 0.37→3.08，fitness 0.21→2.38）

**50+ 次迭代中真正起作用的四步**：
1. **拆成 up/dn 两腿**：`abs(r−mkt)` → `up = ts_max(returns - mkt, 20); dn = ts_max(mkt - returns, 20); alpha = rank(dn) - rank(up)`（**买近期最大单日暴跌的，卖被爆炒的**）
2. **多市场验证**（找信号最强的区域）
3. **group 从 `market` 换到 `subindustry`** —— 在 subindustry 里"扎眼"效应更强
4. **★ 标准化 `ts_std_dev`**：原始版用绝对值量"扎眼"，隐含假设所有股票共用一把尺子；但投资者感知的是"**这只股票平时不这样**"——大票跌 3% 可能是 1σ 平常事，小票跌 3% 是 5σ 大事。**除以 `ts_std_dev` 后 Sharpe → 3.08**

**评论区补充（可直接试）**：
- FF45555：**窗口越短信号越强**（5 日 S=1.20、10 日 0.89、22 日 0.75、66 日 0.46）→ 可以往下扫 **5/10/15**
- FF45555：**`quantile(gaussian)` 加权** → Sharpe 从 0.75 提到 0.82、回撤更低
- QQ38141：**换中性化投影（STATISTICAL）** 比加流动性更便宜；SUBINDUSTRY 撞池 0.806 判死 → STATISTICAL 降到 0.549，**Sharpe 同时 +0.33**

⇒ **`ts_std_dev` 标准化是对本轮最可迁移的一条**：KOR insd5 是事件流（每条内部人交易的规模差异极大），
原始 `divide(vec_sum(trd_amt), vec_sum(source_data))` 未做"平时尺度"归一 → **除以 `ts_std_dev` 可能显著提 S**。
