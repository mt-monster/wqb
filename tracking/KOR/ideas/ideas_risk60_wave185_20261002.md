## Concept 1 — 拥挤度截面强度（活动迹象主腿，纯截面）

**经济机制**：做空拥挤度是全市场共同的风险偏好状态。绝对水平无信息，
但**横截面上哪些股票被借券资金集中做空**有信息——拥挤者未来承压回补。
截面化同时天然满足 KOR `SUBINDUSTRY prod 饱和` 铁律（不碰已饱和子空间）。

**Implementation Example**:
```
group_rank(ts_zscore(ts_backfill(vec_avg(rsk60_crowding), 22), 252), subindustry)
```

**形态分类**: H1 净方向价差 / 单信号结构化
**合规说明**: 单信号腿 + group_rank 结构化，无 add(multiply()) 混信号
**算子数**: 4（ts_backfill / vec_avg / ts_zscore / group_rank）
**预期墙**: SUBINDUSTRY 在 KOR REV1 类信号 prod 撞墙 0.797–0.801 ⇒ 若此槽 prod ≥0.7 换 MARKET/INDUSTRY 轴

## Concept 2 — 拥挤度 vs 费率背离（H3 分歧）

**经济机制**：拥挤（活动迹象）与费率（价格）应当同向——借券需求推高费率。
**当拥挤度高但费率不高时**，说明做空在累积但尚未被定价 ⇒ 未来费率上行、做空方承压。
这是**同一经济关系内的两个观测量的分歧**，不是两条独立信号腿相加（合规）。

**Implementation Example**:
```
subtract(group_rank(ts_zscore(ts_backfill(vec_avg(rsk60_crowding), 22), 252), subindustry),
         group_rank(ts_zscore(ts_backfill(vec_avg(rsk60_offer), 22), 252), subindustry))
```

**形态分类**: H3 分歧（subtract of two group_rank）
**合规说明**: subtract(rank,rank) 是记忆 §0 放行的 5 类形态之一
**算子数**: 7
**经济含义**: 拥挤减费率 = 未被定价的做空压力

## Concept 3 — 拥挤累积速度（H2 门控，避开 GLB 时序变化死路）

**经济机制**：GLB 实证「变化类（ts_delta22/ts_zscore66/ts_rank66·252/crowding 日度与 22d 累计）
全部 |S|≤0.85 无信号」⇒ **纯时序变化无信号**。
但**门控**不同：不是拿变化当信号，而是用变化**开关**控制拥挤度水平是否生效。
经济含义：拥挤只在**加速累积**时才是负面信号，稳态拥挤是存量信息。

**Implementation Example**:
```
trade_when(ts_zscore(ts_backfill(vec_avg(rsk60_crowding), 22), 66) > 0,
           group_rank(ts_backfill(vec_avg(rsk60_crowding), 22), subindustry),
           -1)
```

**形态分类**: H2 门控（trade_when）
**合规说明**: trade_when 是放行形态；`-1` 兜底避免无仓
**算子数**: 5
**预期墙**: 稀疏事件 CW>0.5（KOR 加严）⇒ 须看 longCount

## Concept 4 — 借券费率相对自身历史的位置（H1，费率水平但时序化避开 prod 墙）

**经济机制**：GLB 证明费率**水平** prod 0.966 撞墙，DEU 证明费率几何 best|S|=0.29。
但 GLB 那条 S2.76 的表达式用了 `ts_decay_linear(...,5)` **衰减**。
思路：**用"费率在自身历史中的分位"代替"费率水平"**——分位数化是单调变换，
不改变 prod 空间（prod 看的是持仓向量），但改变横截面载荷。

**Implementation Example**:
```
ts_rank(ts_backfill(vec_avg(rsk60_offer), 22), 252)
```

**形态分类**: H1 单信号时序分位
**算子数**: 3
**注意**: 记忆铁律 `KOR-ANL10-TSRANK252-PRODWALL` —— ts_rank 252 在 KOR 撞过 prod 0.7686 墙，
同结构 ts_rank(66) 全绿（0.6003–0.6045）⇒ **本槽用 252，若 prod 撞墙立刻降到 66 重试**

## Concept 5 — 拥挤/费率比值（跨字段比值，非加法）

**经济机制**：拥挤是**量**（活动迹象），费率是**价**（价格）。
量价背离度 = 拥挤度 / 费率水平。比率把两个量纲统一，捕捉"拥挤但便宜"vs"不挤但贵"。
`divide` 是放行形态。

**Implementation Example**:
```
group_rank(divide(ts_backfill(vec_avg(rsk60_crowding), 22),
                   ts_backfill(vec_avg(rsk60_offer), 22)), subindustry)
```

**形态分类**: H4 跨字段比值
**合规说明**: divide 是放行形态，不是两条信号腿相加
**算子数**: 4
**风险**: 分母费率可能接近 0 ⇒ 极端值，须 winsorize 或 signed_power 压尾

## Concept 6 — 拥挤的行业内相对拥挤（分组轴 H1）

**经济机制**：绝对拥挤度受市场整体情绪支配，**行业内相对拥挤**才是个股层面的压力。
这与 KOR 记忆里的实证一致：「分组轴是独立维度，B1(subindustry) +0.54 vs B2(country) −0.34，
同集同机制仅换轴差 0.88」。

**Implementation Example**:
```
group_rank(group_zscore(ts_backfill(vec_avg(rsk60_crowding), 22), subindustry), market)
```

**形态分类**: H1 双层分组（内层行业中性化 + 外层截面秩）
**算子数**: 4
**说明**: 内层 group_zscore 去行业共同成分，外层 group_rank(·, market) 是**独立增益维度**
（记忆 §1 实证：设置层已 MARKET 时内嵌 group_rank(·,market) 仍把 S 0.44→1.22）

## Concept 7 — 拥挤持续性（H2 门控变体：稳定性加权）

**经济机制**：Concept 3 测"加速累积"，本槽测"持续性"——
用 `vec_count`（快照数）衡量数据到达密度，密度高 = 券源活跃 = 拥挤信号更可信。
`vec_count` 是 VECTOR 专用算子，不进经济量但进**质量门控**。

**Implementation Example**:
```
trade_when(vec_count(rsk60_crowding) > 1,
           ts_zscore(ts_backfill(vec_avg(rsk60_crowding), 22), 252),
           -1)
```

**形态分类**: H2 门控
**算子数**: 4
**经济含义**: 券源活跃标的的拥挤趋势才有信息
