## 4. 五问（A-1）

| # | 问 | 答 | 对骨架的决定 |
|---|---|---|---|
| 1 时间维度 | 存量 / 流量 / 变化率 | A 族本身**已是变化率**（ghc_tr/vol_chg）；C 族是存量 | A 族**不套 ts_delta**，直接聚合；C 族必须 ts_delta 或取倒数 |
| 2 相对性 | 水平差 / 排序差 | 比例跨公司量纲差异大（大股东 vs 小股东） | 横截面 `group_rank`，不用 zscore（尾部极端） |
| 3 被定价的是谁 | 广度 / 强度 | **强度**（单笔交易的方向与规模）+ **分歧**（内部人之间是否一致） | 先 `vec_*` 聚合再排序；分歧用 `vec_stddev` |
| 4 有无博弈 | 拥挤 / 可投资性 | 小盘 KOSDAQ 内部人交易多，行业结构差异大 | `group_rank(·, sector)`；规模残差留待 S 不足时 |
| 5 事件性 | 是否稀疏 | **是**（cov .7318，多日无交易） | 用 55–66 日窗口聚合把事件摊平；禁裸单日 rank |

## 5. 机制声明 A-2（四族）

### M1 · 内部人交易**分歧度**（已实证，主机制）
| 项 | 内容 |
|---|---|
| 谁在被定价 | 同一公司内部人（高管/大股东）之间的**观点分歧**——有人增持、有人减持 |
| 为什么会被错 | **Miller (1977) 分歧-高估**：卖空受限时，高分歧资产由乐观者定价 ⇒ 系统性高估 ⇒ 后续收益低。韩国卖空制度多次收紧（2008/2011/2020），约束真实存在 |
| 错了多久修复 | 数季（分歧冲击半衰期约 1 年，3 年内回归；见 HKUST 转述的 *Disagreement and return predictability of stock portfolios*） |
| 预期方向 | **分歧高 ⇒ 后续跌**（做空高分歧） |
| 失效条件 | ① 单笔大额交易造成的伪分歧；② cov .7318 ⇒ 无交易股票读数为空 |

### M2 · 内部人净买入**方向强度**（待验证）
| 项 | 内容 |
|---|---|
| 谁被定价 | 知情交易者（informed trader）的净方向 |
| 为什么会被错 | 信息摩擦 + DART 披露滞后 ⇒ 反应不足 |
| 修复期 | 数周–一季（66 日） |
| 方向 | 净买入 ⇒ 后续涨（Lakonishok-Lee 2001 买入侧强于卖出侧） |
| 失效条件 | 家族传承式转让；单笔噪声 |

### M3 · 控制权**集中度** = 代理成本（已实证 −1.55）
| 项 | 内容 |
|---|---|
| 谁被定价 | 控股家族/关联方的存量集中度 |
| 为什么会被错 | KOR 财阀（재벌）结构下，集中度 ↑ ⇒ 隧道效应/关联交易/继承安排侵蚀小股东 ⇒ 治理折价 |
| 修复期 | 结构性、慢变量（TO .058） |
| 方向 | 集中度高 ⇒ 后续弱（负向，实测 −1.55/−2.05） |
| 失效条件 | 分拆/合并导致比例跳变 |

### M4 · 高管 vs 非高管交易的信息含量差（未验证）
| 项 | 内容 |

## 6. 双通道取证

**通道 B｜文献**
| 文献 | 可证伪结论 | 迁移性 |
|---|---|---|
| Miller (1977, JF) | 分歧 + 卖空限制 ⇒ 高估 ⇒ 后续低收益 | ⭐ M1 主依据；KOR 卖空限制真实存在 |
| *Disagreement and return predictability of stock portfolios* | 分歧冲击半衰期 ≈1 年；高分歧组合后续收益显著低 | 支撑 M1 方向与持有期 |
| Lakonishok & Lee (2001, RFS) | 内部人**买入**预测力强于卖出，小盘更强 | ⭐ M2 方向；KOR TOP600 小盘占比高 |
| Jeng-Metrick-Zeckhauser (2003, REStat) | 买-卖组合年化 ~6%，收益主要来自买入腿 | M2 佐证 |
| Cohen-Malloy-Pomorski (2012, JF) | 机会型内部人交易可预测，例行型不可 | M4 假说（本集无 routine 标识） |

**裁决**：① M1 通道 A/B 同向 ⇒ **优先组装**（已有两颗实证）；② M2「A 有模板、B 有机制」⇒ 组装但方向正反各测（铁律 B）；③ M3 属本区自建（论坛无对应表达）；④ M4 仅假说，作门控对照。
