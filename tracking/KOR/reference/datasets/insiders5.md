**名 vs description 差异（被名字误导过的点）**：
- `insd5_ghc_tr` 名字看不出「比例」，description 明确是 **ownership percentage 的变动**（不是股数）⇒ 与 `vol_chg`（股数）是两条不同量纲的腿，不可混用同一 rank 含义。
- `insd5_trd_amt` description 只说 "Monetary amount of the transaction"，**未说明带符号** ⇒ 保守当作**绝对金额（活动强度）**，不能当买卖方向。
- `insd5_fb_tr`/`fa_tr` 是「交易前/后比例」，二者之差 = 该笔比例变动，可交叉校验 `ghc_tr`（一致性检验，不单独当腿）。
- `insd5_rpst_grp_typ` / `insd5_trd_reason_b` 是**编码值**，需先映射再用；直接进算子等于把类别码当连续变量（禁用）。

## 4. 五问（A-1）

| # | 问 | 答 | 对骨架的决定 |
|---|---|---|---|
| 1 时间维度 | 存量还是流量 | **流量**（交易组）+ 存量（快照组） | 流量直接水平聚合即可（本身已是变化率，不套 ts_delta）；存量必须 `ts_delta` |
| 2 相对性 | 水平差还是排序差 | 比例变动跨公司量纲不同（大股东 vs 小股东） | 横截面 `group_rank`，不用 zscore（尾部极端） |
| 3 被定价的是谁 | 广度还是强度 | **强度**（单笔交易的方向与规模） | 先聚合（vec_sum）再排序 |
| 4 有无博弈 | 拥挤/可投资性 | 小盘 KOSDAQ 内部人交易多 | 壳层：`group_rank(..., sector)`；暂不加规模残差（留待 S 不足时） |
| 5 事件性 | 是否事件稀疏 | **是**（多数股票 66 日内零交易） | 用 66 日窗口聚合把事件「摊平」，`trade_when` 留作后续；禁裸单日 rank |

## 5. 机制声明 A-2（收益来源硬门）

| 项 | 内容 |
|---|---|
| 谁在被定价 | 公司内部人（高管/大股东）相对于外部投资者拥有关于未来现金流与事件的私有信息；其申报交易是**信息的不完全显影** |
| 为什么会被错 | ① 内部人交易动机混杂（分散化、税务、继承、控制权）⇒ 市场无法逐笔区分信息交易与噪声交易，系统性**低估**信息交易的预测力（信息摩擦）；② 韩国 DART 披露有滞后、且关联方交易频繁 ⇒ 反应不足（行为偏差：保守性）；③ 卖出一侧存在**崩盘风险**的不对称（Kim 2017 韩国内部人卖出预测崩盘） |
| 错了多久修复 | 数周–一季（披露后漂移），与 66 交易日聚合窗口同量级 |
| 预期方向 | 买入（`ghc_tr`/`vol_chg` 为正）⇒ 后续正漂移；卖出 ⇒ 后续负漂移。⚠ 论坛实证（EUR）显示「内部人持仓变动」单腿为**负向**（内部人越买、后续越弱），与经典文献方向相反 ⇒ **铁律 B：正反各测一条**，不预设方向 |
| 失效条件 | ① 控制权变更类交易（继承/集团重组）不含信息；② 覆盖率 0.73 ⇒ 27% 股票无交易记录，零值不等于中性；③ 2020 后 KOR 内部人申报电子化提速，披露滞后结构可能变化 |

## 6. 双通道取证

**通道 A｜论坛（平台可落地表达）**
- `43501264459799`【同源信号与噪声对冲】：内部人持仓变动 = `vec_avg` + `ts_backfill(126)` + `ts_delta` + `rank`；**单腿为负向且弱**（EUR），必须拆腿验证；评论指出「126 backfill + 短 delta ⇒ 90% 股票增量为 0，rank 变成『今天谁更新了数据』的触发器」⇒ 本波改**长窗聚合（66d sum）而非短窗 delta**，规避伪事件。
- 同帖评论（TL53163）：内部人交易高频、机构季度 ⇒ 两端窗口不可对称；跨 category 只做线性结构。⇒ 印证本波单数据集 + 单窗口。
- `43534263049239`【同源披露节奏差】：`rank(ts_backfill(F_insider)) - rank(ts_backfill(F_institution))`；仅作**跨 category 备选**（INSIDERS × INSTITUTIONS，不在本轮 60 颗主路径）。

**通道 B｜外部文献（机制 + 方向 + 持有期）**
- Lakonishok & Lee (2001, RFS)：内部人买入的预测力显著强于卖出，且在小盘股更强（★ 与 KOR TOP600 小盘占比高的结构相符）。
- Jeng, Metrick & Zeckhauser (2003, REStud)：构造内部人净买入组合，年化超额 ~6%，主要来自买入侧。
- Kim, Cho & Kim (2017, 韩国财务研究)：**内部人卖出预测崩盘**（韩文期刊）⇒ 卖出一侧的非对称风险信息。
- 平台帖子（中文论坛）实证方向相反 ⇒ 文献与本区实证可能分歧，本轮以**实测为准**，方向双测。

裁决：A、B 指向同一机制（内部人交易信息含量），表达取 A（长窗聚合 + 秩），方向取 B 的「买入正向」为**主假设**、论坛的「负向」为**备择**。两者同时进波 ⇒ 一次回测即完成方向裁决。

## 8. 本波（wave 185）设计 —— 探针批 / 单一设置 / 方向双测

设置：KOR / TOP600 / D1 / STATISTICAL / decay 4 / trunc 0.08 / nanHandling OFF / 2013–2023（沿用战役基线，便于与历史波次横比）。
并发：`_multi_sim_batch_size=2` + `--serial` ⇒ 任一时刻 ≤2 个仿真在飞（符合用户要求 3）。

**归因计划（收批即做，铁律 F）**：
1. `get_alpha_yearly_stats` × 8：逐年 S 分布；S<1.0 年份占比 ≥3 成 ⇒ 2Y 结构性不可达，**不进入参数微调**。
2. `get_alpha_pnl`：阶梯 vs 尖峰；停滞段计数。
3. raw vs RN 分解（铁律 E）：RN 涨幅 ≫ raw ⇒ 换中性化档；同步走弱 ⇒ 换机制族。
4. 若某族 S≥1.0 且 2Y 缺口小 ⇒ wave 186 在该族上扫窗口（22/66/252）+ 套 P-ATOM-1 壳层（bf/σ/p/tvr），候选数 ≤ ⌈8/3⌉=3。

**禁忌（本集专属）**：不对 `trd_amt` 当方向；不对编码字段（`trd_reason_*`/`rpst_grp_typ`）直接做算术；不对 VECTOR 裸字段进算子；不与 PV/MODEL/OTHER 组腿（用户要求 5）；不混信号（add 两腿）。
