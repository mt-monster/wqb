### ⚠ 0.1 名 vs description 的第一处纠错

category 标 `sentiment`，但 19 个字段里 **没有一个**是文本情绪分。
全部是「发行人的映射域名在观测日的 DNS 排名分布」⇒ **本集测的是「数字关注度 / 网络流量注意力」**，
与 news 塔的「新闻情绪」是两条完全不同的经济含义。**按 category 名当成情绪集会判错方向。**

## 2. 覆盖率 .356 的性质判定

- 16/19 字段覆盖率**几乎逐位相同（.3559–.3562）**，`dltcc` 略高（.375）
  ⇒ 缺的 64.4% 是**同一批标的全字段缺**，不是逐字段稀疏。
- 语义上必然是**结构性不在域**：只有「有已映射域名」的发行人才有值（外资/小盘/无官网的 KOSPI 标的不在域）。
  ⇒ **`ts_backfill` 不会造出横截面不存在的标的**，只能用它在个别日期的缺口上补。
- 与 other106（cov .404、结构性不在域、实测十年覆盖 PASS）**同型** ⇒
  十年覆盖（约束 4）大概率 PASS，但**首波必须 `get_alpha_yearly_stats` 实核**。
- **不按「cov<0.4 换集」一刀切**：用户约束 4 明示「覆盖率可动态调整，但近十年都要有数据」。
  本集的低覆盖是**在域范围**问题（类似行业子集），不是时间缺失；判据改为**十年逐年 longCount 非零**。

## 3. 字段画像五问（A-1）

| 问 | 答 | 决策 |
|---|---|---|
| **1 时间维度** | 存量（当日观测的排名快照） | 存量单边 ⇒ 变化率（铁律 A） |
| **2 相对性** | 水平差异（排名绝对值）+ 排序差异（横截面） | 排名类是**序数** ⇒ 先 `rank` 或 `ts_zscore`，禁直接当连续值用 |
| **3 被定价的是谁** | **散户注意力**（DNS 访问 = 零售投资者信息获取与交易冲动）；强度（排名越前）与广度（域名数）是两个量 | 广度用水平；强度取变化 |
| **4 有无博弈** | 有 —— 注意力驱动的买压是**拥挤的散户行为**，机构在反向侧提供流动性 | 需加「规模/流动性」残差壳或行业中性 |
| **5 事件性** | 非事件型（每交易日都有快照，只要在域） | 不用 `trade_when` 门控；但缺口日期要 `ts_backfill` |

## 4. A-2 收益来源声明

| 声明项 | 内容 |
|---|---|
| **谁在被定价** | **散户投资者**。DNS 访问量/域名广度是信息获取的**前置行为**（Barber & Odean 2008：注意力 ⇒ 买入压力，且散户只买不卖） |
| **为什么会被错** | **注意力引致的净买压**：被关注的股票面临零售买入潮，价格短期被推高（不是基本面改善）；**卖空约束**放大上行偏误（Miller 1977）⇒ 短期高估 |
| **错了多久修复** | **1–4 周**：Da, Engelberg & Gao (2011) 的 ASVI 显示关注度冲击后**第 1–2 周正收益、随后 2–4 周反转**；持有期主窗 **22**，对照 **5 / 66** |
| **预期方向** | **关注度（广度/强度）上升 ⇒ 短期涨、随后跌**。⇒ 可交易腿是**反转侧**（`reverse`）；正向臂必须同测（铁律 B） |
| **失效条件** | ① 在域比例过低导致 sub-universe 不可信；② 排名字段是序数，若原值被当连续值会引入非线性偏差；③ 若注意力只在「无信息」的小盘股上聚集，则收益会被流动性成本吃掉（TO 会冲高） |

### 5.1 A 通道读数（诚实结论：**有文献指向、无专属配方**）

| 命中帖 | 可用内容 | 判定 |
|---|---|---|
| 《【论文合集】量化研究推荐论文》**108 赞** | 列有 *Investor Attention, Visual Price Pattern, and Momentum Investing*、*Frog in the Pan: Continuous Information and Momentum* | ⭐ 唯一机制线索：**注意力 → 动量**（与 §4 的「注意力 → 短期反转」是**持有期不同的两条读法**） |
| 《【内容不符直通不通过】【Alpha灵感】新闻影响股票实践的理解与感悟》 | 正文直接引 **Barber & Odean (2008) "All that glitters"** —— 与本文件 §4 A-2 同一篇 | ⚠ 标题前缀「内容不符直通不通过」= **该帖未通过 PPA 内容审核**，只能作文献索引、不能作配方式样 |
| 《【内容不符直通不通过】【Alpha灵感】新闻流持续性的Alpha因子研究》 | 引 Tetlock (2007) | 同上，仅文献索引 |
| 《【Field更新】56,000多个新字段上新！》 | 字段上新通告 | 无机制 |

**⚠ 双通道裁决（②.d 要求，不得跳过）**：A 指向「注意力 → **动量**」，B（Da et al. 2011）指向「注意力 → 短期**反转**」，
表面矛盾，实为**持有期分工**：注意力冲击后 **1–2 周内延续/超调，2–6 周转为反转**。
⇒ **裁决 = 两种持有期各测一条**（§7 的 #1 取水平/长窗 ≈ 动量读法，#2 取 22 日变化率 ≈ 短期冲击读法），
**不预设方向**；读数后按「哪个窗口成立」写死机制句，另一条按铁律 B 记录反号臂。

⚠ **文献偏误登记**：三篇均为 **USA** 样本，且 Da et al. 用的是 Google 搜索量（散户主动查询），
本集是 **DNS 解析量**（被动访问，含爬虫/企业流量）⇒ 噪声成分更高、与交易的因果链更长。
**只作机制假说，方向与持有期必须本区实测**。

## 6. 预处理决策（按 ① 的体征查表）

| 体征 | 预处理 |
|---|---|
| 全 VECTOR | 先 `vec_avg` 降维（`vec_max` 作对照：域名排名分布右尾 = 最差域名，无经济含义 ⇒ **只用 `vec_avg`/`vec_sum`**） |
| 排名类「低 = 好」 | 先 `-1 *` 翻成正向，再做 `rank`/`ts_delta`（否则方向句与表达式符号相反，读数会误导归因） |
| cov .356 | `ts_backfill(·, 22)` 前置（不补横截面，只补日期缺口） |
| 存量单边 | `ts_delta(·, 22)` / `ts_zscore(·, 66)`（铁律 A） |
| 序数 | `rank` 或 `group_rank`（禁裸值当连续量） |
| 稀缺关注 = 挤权重 | 分组轴 `sector`（KOR `industry` 已三次更差，见 risk59 wave 213） |

| 预注册证伪条件 | 实测 | 结论 |

**判定：`KOR-SENTIMENT26-NO-CROSS-SECTION-AND-7Y-COVERAGE`** —— 双重死因，任一独立成立：
① **时间覆盖 2017 起（7/10 年）** ⇒ 违反约束 4；
② **截面无定价力**（`max|S| 0.20`、`max F 0.03`、逐年 S 符号乱跳）。

**归因三条（铁律 E/F 要求）**：
1. **反号臂不给方向**：`reverse(#1)` S = **0.00**（不是 +0.13）、PnL 仅 +7,475、longCount 319/333
   ⇒ 正反两臂都是零 ⇒ 原信号是**噪声**，不是「方向押错」。铁律 B 的又一次实证：
   `reverse()` 与正向**不精确反号**（STATISTICAL 中性化 × truncation × decay 交互），
   不能假设「反号即得到 |S|」。
2. **raw 与 2Y 同步走弱**（#3 是唯一正向臂，2Y 0.55 也远低于 1.58）⇒ 按铁律 E 属**信号自身衰减**，
   **不扫中性化档、不扫平滑器**（本波 TO .17–.50 全在健康带，平滑无对象）。
3. **机制层面**：USA 文献（Da-Engelberg-Gao 2011）的「注意力 → 短期反转」在 KOR TOP600 **不成立**。
   本集是 **DNS 解析量**（被动访问，含爬虫/企业流量），与 Google 主动查询的因果链不同
   ⇒ §5 登记的**文献偏误成立**，不可跨区照搬（与 macro63 的「域错配」、risk70 的「无截面」并列，
   但本集是第三种死法：**有截面、有年份，就是没有信息**）。

**⚠ 方法论教训（写入本区档案）**：平台 `coverage` 是**横截面覆盖率**（本集 .356），**不是时间覆盖**。
一个 `coverage` .36 的集照样能只有 7 年历史；反之 `macro63` `coverage=1.0` 却是 10/10 年零持仓。
⇒ **约束 4（近十年都要有数据）只能靠 `get_alpha_yearly_stats` 的逐年 `longCount` 判，不能靠 `coverage` 字段预判。**

**塔级结论**：sentiment 塔四集全死 —— 189（覆盖）· 190 `other106`（机制）· 192 `other553`（机制）·
**216 `sentiment26`（覆盖 7/10 + 无截面）** ⇒ **`KOR/D1/SENTIMENT` 塔关闭，不再投配额**。
