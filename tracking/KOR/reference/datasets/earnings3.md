## 2. 名 vs description 差异表

| 字段 | 陷阱 |
|---|---|
| `pre_interval` | 描述写 "Number of trading days **before** the last earnings report date (should be negative or zero)" ⇒ **符号是负的**，直接 `rank(pre_interval)` 会把「刚发财报」排到最低 —— 必须取绝对值或 `-pre_interval` |
| `next_interval` | 正数；**0 = 今天发**，NaN = 无排期 |
| `*_reptime` | 是 HHMM 时钟码，**不是日期**；做信号需转「盘前/盘中/盘后」三分类 |
| `next_*` 覆盖 .58 vs `pre_*` .78 | **未来排期只有 58% 有值** ⇒ 用未来事件做门控会让 42% 股票永久空仓（coverage 陷阱） |

## 3. 字段画像五问（A-1）

1. **时间维度**：**时点距离**（存量式计数，非流量）⇒ 可水平直接用，但**符号必须先修正**（见上）。
2. **相对性**：本质是**时间排序**，`rank`/`group_rank` 会把「距离」压成横截面序 —— 更稳的是**阈值门控**（1–5 日 / 6–20 日）。
3. **被定价的是谁**：**事件临近度**（pre-announcement premium）与**信息新鲜度**（post-earnings drift 窗口）。
4. **有无博弈**：有。财报前后是流动性/波动率跳变区 ⇒ 必须 `trade_when` 限定窗口，不能全天持仓。
5. **事件性**：**纯事件型** ⇒ 禁裸 rank（KOR skill 铁律：事件型必须 `trade_when`）。

## 4. A-2 收益来源声明（主机制：财报公告溢价）

| 项 | 内容 |
|---|---|
| **谁在被定价** | 不愿持有事件风险的投资者（财报日波动大、方差风险溢价为负）⇒ 事件前「让渡」股票，事件前收益被抬高 |
| **为什么会被错** | 方差风险溢价 + 注意力前置：市场为「避开不确定性」付钱，事件前一戳就兑现 |
| **错了多久修复** | 事件前 1–5 个交易日累积，事件当日兑现 ⇒ **持有期极短（1–5 日）** |
| **预期方向** | 距离下一次财报 **1–5 日** ⇒ 偏多；**0 日（当日）** ⇒ 风险敞口最大，回避 |
| **失效条件** | 无排期（cov .58 缺 42%）；财报改期；小盘一次性事件 |

**文献**：Beaver (1968) 首次记录公告期收益/成交量放大；Frazzini & Lamont (2007, JFE) "The Earnings Announcement Premium and Trading Volume" —— 公告前后一周存在正超额收益，且**与交易量正相关**；Savor & Wilson (2016, JF) 拆出「公告日」与「公告前」两段。
⚠ 均为 USA 样本；KOR 财报集中在 3/6/9/12 月 ⇒ **季节性极强**，必须逐年看 S 分布（归因阶段重点）。

## 5. 近十年覆盖验证

`pre_*` 族 cov .78 说明近十年大概率连续；`next_*` 族 .58 是**排期数据缺失**而非历史短。仍以首个候选的 `get_alpha_yearly_stats` 为准。

## 6. 波次设计（P4，独立线，首波 ≤8）

| 候选 | 表达式草案 | 说明 |
|---|---|---|
| E1 | `trade_when(between(ern3_next_interval,1,5), -1*ern3_next_interval, -1)` | 事件临近度加权（越近权重越高），非事件期空仓 |
| E2 | `trade_when(between(ern3_next_interval,1,5), 1, -1)` | 纯事件组合（等权）—— 对照组 |
| E3 | `trade_when(between(ern3_pre_interval,-20,-1), group_rank(0-ern3_pre_interval, sector), -1)` | 财报后 1–20 日漂移窗口（仅时间维度，无 surprise ⇒ 方向待测） |
| E4 | E1 的 `reverse()` | 方向对照（铁律 B） |

⚠ `between` 是否在本区 live 算子白名单内、参数顺序需先过 `preflight_expressions`；若不可用改用 `and(greater_equal(…),less_equal(…))`。
⚠ 等权组合（E2）大概率 fitness 不足；E1 是主腿。

## 7. 禁区

- 不把 `pre_*` 与 `next_*` 相加（两个不同事件窗口）。
- 不用 `_all_delay_1_*` 与无前缀版组腿（同源）。
- 不与 PV/MODEL/OTHER 组腿（用户约束 5）。
- 拥挤度 540+ ⇒ 提交前必查 prod（MCP）。

### 8.5.2 三条硬结论（每条都有对照）

**① `trade_when` 事件门控 = 方向性证伪，不是微调问题。**
同一底层信号，裸 `rank` S **+0.84** → 门控到「财报前 6 日」S **−0.17**（Δ=−1.01）、2Y **+1.71 → −0.78**。
⇒ **KOR 的财报日历溢价不在公告前的窗口里**，Frazzini-Lamont 的 announcement premium 机制**在本区不成立**；
收益来自「**远离**财报披露日」的那一侧（即持有披露间隔长的股票）。
⇒ 该轴**判死**，后续任何 `trade_when(<财报临近>, …)` 变体不再进 quota。

**② 事件门控在 KOR 系统性触发 CONCENTRATED_WEIGHT。**
`akKXKJOR` CW = **0.14069**（限 0.1，日期 2014-01-10），失败项 `LOW_SHARPE / LOW_FITNESS / CONCENTRATED_WEIGHT / LOW_2Y_SHARPE`。
这与 roadmap §2 登记的 `KOR-AIEQUITY-PROBE-DEAD`（「CW 1.0 事件日集中为 KOR 事件类数据通病」）**同形**。
⇒ 纪律：**KOR 任何事件稀疏型信号，第一读数看 CW，不看 Sharpe**；CW 不破 0.1 的门控结构一律不进下一波。

**③ 前瞻窗口 ≫ 回看窗口。**
`next_interval`（距下次财报天数）S **0.94** / 2Y **1.68** vs `pre_interval`（距上次财报天数）S **0.56** / 2Y **0.98**。
⇒ 市场定价的是**即将到来的披露不确定性**，不是已发生的披露距离。同一机制族内 `pre_interval` **判为劣轴**，不再扫。

**④ 换手不是瓶颈（反证「降 TO 救 F」路线）。**
门控版 TO 从 .177 降到 **.1084**（−39%），但 S 从 +0.94 塌到 −0.17 ⇒
**在本线，TO 与 S 同向下降，压换手不能救 Fitness**。Fitness 的唯一出路是**抬 returns 或抬 S**（与 §8.3 的算术一致）。

**§8.6.3 三条必须写下来的结论**

1. **「S<1.0 年份 ≥3 成」是启发式，不是判决**——本候选 40% 命中但 2Y 实测 1.68 过线。
   原因：KOR 的 2Y 是**平台固定尾窗 2022–2023**（S 2.24 / 1.21），不是「任一连续两年」。
   ⇒ 该启发式的真正含义应改写为：**「2Y 过线是否依赖尾窗位置」**。本候选**依赖尾窗**——
   把 IS 尾年平移两年到 2017–2018（1.22 / −0.55），2Y 立刻塌到不可过。**这是窗口位置风险，写进提交前必核清单。**
2. **2014 的 RN 曲线是负的**（investability-constrained pnl 全年 −258k → −444k，raw 却 +216k~+572k）。
   即**加权后组合在 2014 全军覆没**：瓶颈是 `LOW_INVESTABILITY_CONSTRAINED_SHARPE`（实测 .70），
   不是 raw alpha。这与 §8.5.1 的列一致（inv 列 .70 vs subject 列 .77）。
   ⇒ 若后续要救 2014，方向是**可投资性壳层**（`vector_neut(...pow(rank(cap),p))`），不是改核心信号。
