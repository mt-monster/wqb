# KOR/PV intraday_pv_feats 机制边界探针（KOR/D1/TOP600）2026-11-06

> 定位：KOR/PV 塔 2/3，只差 1 颗点亮。本波不是「再找一个新面」，而是一次**设计过的机制边界检验**：把在 EUR 已判死的同一数据集、同一批字段、同两条表达式原样搬到 KOR，隔离出「区域」这一个变量。

## 一、假设（可证伪）

从本轮 EUR 结果反推：`intraday_pv_feats` 的日内时段/价格类型结构在三个区域的表现是 ——

| 区域 | 最强实测 S | 市场结构 |
|---|---:|---|
| HKG | **2.41**（ZYQ716j1 时段分歧）/ 2.34 / 1.80 | 散户主导、集中、日内波动大 |
| GBR | 判死（复合结构，台账记录） | 机构主导 |
| EUR | **|S| 0.1–0.51**（本波 4 骨架） | 宽基、流动性高、HFT 深度参与 |

**H1（主假设）**：日内时段性/价格类型溢价是**散户订单流失衡**的产物，只在散户占比高的市场存活。⇒ KOR（散户占比高、日内波动大）应当复现 HKG 的正信号。
**H0（零假设）**：这个效应是 HKG 的市场特异性伪影（HKG 的收盘竞价机制、A/H 股结构、南向资金流），不跨市场。

**判据（预先写死）**：
- KOR 任一条 S ≥ 1.2 ⇒ H1 得到支持，立即展开其余 12 个模板（已预检全过）。
- KOR 两条 |S| < 0.6 ⇒ H0 成立，`intraday_pv_feats` 整面在 EUR/KOR 两点同时判死，HKG 的 S 2.4 归因于市场特异性，不再向任何区域移植。

## 二、为什么这个实验值得占用 2 个仿真槽
1. **零新增设计成本**：表达式与 EUR 批 A 完全逐字相同，只是 region 从 EUR 换成 KOR。没有新字段、没有新几何。
2. **结论双向可用**：正结果 ⇒ KOR/PV 2→3 点亮 + 拿到一颗强候选；负结果 ⇒ 永久关闭这个数据集在 3 个区域的移植尝试，省掉后续所有试错。
3. **补上方法论空缺**：既有记忆里只有「跨区搬配方前先预检字段是否存在」，缺的是**「搬过去之后如何判定机制是否迁移」**。本实验给出一个成本 2 槽的标尺做法。

## 六、判决：H0 成立，该机制整面判死

预注册判据是「KOR 任一条 S >= 1.2 => H1；两条 |S| < 0.6 => H0」。实测 0.29 / -0.57，**两条都落在 0.6 以内 => H0 成立**。

- T01 是 HKG 侧过全闸的最强骨架（HKG 的 ZYQ716j1 同构 S 2.41），在 KOR 只剩 0.29，落差 2.12。
- T03 在 HKG 是 RRE7vM2e 同构（S 1.80/prod 0.6172），在 KOR 变 -0.57，**符号都翻了**。
- KOR 的 vol 是 4.37-4.69%，明显高于 EUR（1.71-1.92%），所以 F 的数学墙在 KOR 不成立（KOR 有空间）。
  **但 S 依然近 0 => 这次不是「信号有但被 F 数学压死」，而是「信号本身不存在」。**

结论链条完整：

| 区域 | 同数据集同字段同表达式的最强 S | 市场结构 |
|---|---:|---|
| HKG/TOP800 | **2.41 / 2.34 / 1.80**（全闸） | 散户主导、集中、日内波动大 |
| EUR/TOP2500 | **-0.09 / 0.11 / -0.51 / -0.28** | 宽基、HFT 深度参与 |
| KOR/TOP600 | **0.29 / -0.57** | 散户占比高但 vol 结构不同 |

KOR 反例最关键：它按 H1 的因果（散户占比高）本该复现，但没复现。
=> 该效应不是「散户订单流失衡」的普遍产物，而是 **HKG 特有的收盘竞价机制 / A-H 股结构 / 南向资金流**的产物。
=> `intraday_pv_feats` 日内时段 x 价格类型机制：**三个区域两点判死（EUR、KOR），不再向任何区域移植**。

## 七、方法论沉淀（已入 Agent Memory）
跨区搬配方的正确做法：首批必须含「原区最强骨架」当标尺，它的 S 直接给出机制在该区的存活率，成本 2 个仿真槽。
不要因原区 S 高就默认新区能复现，也不要因新区塌了就去调窗口/几何 —— 那是机制问题不是参数问题。
配套：vol 是数据集固有属性，1-2 条探针即可先验测出，再按 F = S^1.5 x sqrt(vol/0.125) 反算该数据集达 F=1 所需的 S 门槛。
