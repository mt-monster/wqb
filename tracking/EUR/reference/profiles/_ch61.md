## 第六十一章 · 提交层实证 + pv20 crowding + pv87 死池（2026-11-13 续）

### 61.1 ★★★ 平台「WARNING」在提交层等于不通过（硬实证）

`YPadpndA`（S 1.37 / F 0.82 / 2Y 1.32）模拟层全部只判 WARNING，但 `submit_verdict` 返回：

```
verdict: BLOCKED
exit_code: 1
reason_code: FAILED_COUNT_RA:LOW_SHARPE,LOW_FITNESS,LOW_2Y_SHARPE
```

**规则确认**：提交层的 Failed-count 资格门把 WARNING 计入失败数。⇒ **必须真正跨过 S>1.58 / F>1.0 / 2Y>1.58，"差一点"在提交层就是不过。**
用户口径「S>1.58 且 F>1.0 是硬闸」在平台行为上得到完整印证。

### 61.2 ★★★ pv20 crowding：S 极强（1.77）但被换手锁死

**|S| = 1.77 已超 1.58 门槛**，唯一阻塞项是 **TO 89.6% > 70%**。

**成本核算（决定要不要继续投入）**：
| 假设单边成本 | 年化成本 | 净收益（取反后 ret 10.96%） |
|---|---:|---|
| 10bp | 8.96% | ≈ +2.0% |
| 20bp | 17.9% | ≈ −7.0% |

⇒ **10bp 下勉强为正、20bp 下为负。实盘价值边际，但平台不检成本，只要 TO<70% 就能过闸。**
**判据**：这类高频信号值得挖（平台闸能过），但不能作为主力交付件，且必须把 TO 压到 70% 以下。

### 61.3 ★ pv87 在 EUR 是死池（1649 字段）

`pv87_ann_matrix_*` / `pv87_target_price_mean` 等字段：
- 带 `pv87_` 前缀 → `dataset-prefixed field not found at this region/universe/delay`
- 不带前缀（`ann_matrix_return_on_equity_mean` 等）→ `unknown_fields`

⇒ **两种命名都不可用，pv87 的 1649 字段在 EUR 平台侧根本未注册。**
**教训**：字段目录 JSON 里有 ≠ 平台该区域可用。**选集前必须 preflight**，不能凭目录判断。
（这与既有判据「MCP preflight 会误报合法算子、但字段校验可靠」互补：**字段存在性用 preflight 验是可靠的，反之算子不可靠**。）
