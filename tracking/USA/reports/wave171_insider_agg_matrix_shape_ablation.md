## 3. 核心归因

### 3.1 F 天花板算术（决定性，判死依据）

平台 `fitness = sharpe × sqrt(|returns| / max(turnover, 0.125))`，分母有 **0.125 地板**。

本波全部 13 条的 TO 落在 **2.9%–18.8%**，绝大多数在 0.125 地板之下 ⇒ 实际生效公式为

```
F = S × sqrt(R / 0.125)
```

最佳 `pwd0nbp6`：`S = 0.87`、`R = 3.76%` ⇒ `S²·R = 0.87² × 0.0376 = 0.0285`。
要 `F ≥ 1.0` 需要 `S²·R ≥ 0.125`，**缺口 4.4 倍**。

反推所有可能的提 F 路径：

| 路径 | 假设 | 结果 |
|---|---|---|
| 提 S 到 1.58 | R 不变 3.76% | `F = 1.58 × sqrt(0.0376/0.125) = 0.87`，仍差 0.13 |
| 提 TO 到 12.5% | margin 保住 16bp（形状族水平） | `R` 需涨到 7.4%，即 margin 翻倍到 32bp —— 形状族实测最高 18.12bp，**不可能** |
| 同时提 S 与 margin | 二者实测反向（见 3.2） | 不可兼得 |

⇒ **该数据集的 F 结构性天花板 ≈ 0.48**（在 S 最高那条上取得）。继续在此数据集上换窗口 / 换算子没有任何出路。

### 3.2 模板族排序：Sharpe 与 margin 恰好反向

| 族 | 代表 | S | margin |
|---|---|---|---|
| 序位族 `ts_rank` | I4b / I4 | **0.87 / 0.77** | 6.04 / 4.57bp |
| 序统计形状族 | I7 / A2 / I5 / I6 | 0.83 / 0.80 / 0.71 / 0.41 | **16.39 / 18.12 / 14.36 / 7.70bp** |
| 水平族 | I1 | 0.54 | 2.94bp |
| top 过滤族 | I8 | 0.33 | 8.64bp |
| 一阶差分族 | I2 | 0.29 | 1.00bp |
| 时序 z 分族 | I3 / I3b / I9 | **全 NaN** | — |

**经济解释**：
- 序位族赚「方向一致性」——每天对全部标的做序位重排，信号平滑、持仓稳，但每次调仓携带的信息量小（margin 低、换手相对高）。
- 形状族赚「每次交易的信息量」——只在有真实知情交易时给出大跨度，交易频率低但单次 alpha 大（margin 高、换手极低）。
- **在 TO < 0.125 地板下，形状族的高 margin 优势被地板吃掉了**（TO 再低也不会提升 F 的分母），而它的低换手又让它无法通过「提 TO」来放大 R。**这是形状族在本平台指标公式下的系统性劣势。**

### 3.3 工程铁律：`ts_zscore` 对步进/离散指示器字段一律失效

`directional_indicator_2` 是离散指示器。三条 z 分模板全返回 `S=0 / TO=0 / F=null / fRA=5`：

- I3：`ts_zscore(b(di2,22), 252)` — 常规
- I3b：`ts_zscore(b(di2,252), 252)` — **回填窗与 z 分窗对齐**（用于排除"回填缺口导致前列 NaN"）
- I9：包在 `trade_when` 内（用于排除"信号在其他形状下才出"）

**三条全零彻底证伪「回填缺口」假设。** 机理：离散指示器在长平段上滚动标准差恒为 0 ⇒ 除以零 ⇒ 全 NaN。
对照组：`ts_rank`（序位）、`ts_delta`（差分）、水平直读都不除滚动 std，全部正常出信号。

⇒ **对步进 / 离散 / 稀疏指示器字段，禁用任何「除以滚动标准差」的算子族**（`ts_zscore`、`ts_ir`、`ts_rank` 之外的标准化变体）。排查清单：先用 `ts_rank` 同窗跑一条对照，若 `ts_rank` 有值而 `ts_zscore` 全零，即确认为本类问题。

### 3.4 top 过滤轴判死
I8（top 序统计量 / 全序统计量比值）S 仅 0.33。旁证：`top_*` 字段 `userCount` 仅 1–8、`alphaCount` 仅 1–9 ⇒ 平台用户与提交者都未从中获得增量信息。**封盘。**

### 3.5 无符号强度轴存活但制度依赖
I12 `ts_mean(abs(ts_delta(di2,5)),66)` 得 S 0.81、**invest_ratio 1.0741（全波最高）**，但 2Y = **−0.43** ⇒ 近两年失效。经济含义：|Δ信号| 无方向，度量的是「知情交易强度」，在多头拥挤期会反向。

## 5. 泛化规则（写入 dead_end）

1. **F 天花板由 `S²·R` 决定，选数据集前先估该量级。** 若一个数据集的字段是「稀疏知情交易事件的序统计量」，其 R 天然在 1–4% 量级、TO 天然在地板下 ⇒ `S²·R` 天花板 ~0.03，离 F=1 差一个数量级。不要在该类数据集上堆模板。
2. **离散指示器字段禁用「除以滚动标准差」算子族**（见 3.3），且必须用 `ts_rank` 同窗对照来定位，不能靠回填窗调整。
3. **序统计形状族在 TO < 0.125 地板下天然吃亏**：高 margin 低换手的组合无法转化为 F。若候选的 TO 已在 0.125 以下，优先选**高 S + 中等 TO** 的骨架，而不是高 margin 低 TO。
4. **`top_*` 过滤轴在 USA 区无增量信息**，字段级 userCount ≤ 10 可作为快速排除先验。

## 6. 与历史结论的一致性

- **第四个「骨架不可跨数据集迁移」反证**：本数据集最优是 `ts_rank` 序位（S 0.87），而 `shortinterest3` 最优是协方差/矩类、`earnings_sent_matrix` 最优是有符号差分 + 长窗 z 分。⇒ **只能继承「候选机制清单」，绝不能继承「哪个形状有效」的判断。**
- **反证波 168「无符号量全死」**：I7 是无符号序统计跨度却出 S 0.83。⇒ 「无符号量」不是一票否决项，起决定作用的是**信息几何**（是否捕捉知情交易集中度）而非有无符号。
- **`group_rank` 负增量结论的边界**：波 167 / option3 上 `group_rank` 是稳定负增量，本波 13 条全部使用 `group_rank` 却未出现系统性负增量。⇒ 该结论的适用边界是「分组轴上组内样本足够、信号本身为连续量」；对离散/稀疏字段，`group_rank` 仍是安全的中性化手段。

## 7. 结论

**判死 `insider_agg_matrix`（USA / D1 / INSIDERS 塔）。**
不出货的根因不是「模板没选对」，而是 **F 指标公式的 0.125 地板 + 该数据集 R 量级 1–4%** 的组合使 F 上限锁死在 0.48。已在 `registry_empirical` 层写入 `USA-INSIDERS-AGGMATRIX-DEAD`。
