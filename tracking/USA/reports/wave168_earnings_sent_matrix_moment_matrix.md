# 波 168 · earnings_sent_matrix 矩矩阵消融

**区域**：USA / TOP2000 / D1 / INDUSTRY / decay 0 / trunc 0.05 / 2014-01-01..2023-12-31
**数据集**：`earnings_sent_matrix`（Global Earnings Call Sentiment Matrix，7 个 MATRIX 字段，cov 0.7）
**目标**：earnings 塔已 1/3（`QPYOPLAK`），补 2 颗点亮；同时找与 `QPYOPLAK` 正交的信号现象
**结论**：**PASS** — n_pass=1（`RREXk770` 全闸）、n_near=1（`58ERq5LM` 差 S 0.01 / F 0.11）

## 1. 数据集结构

`earnings_sent_matrix` 的字段是**三分类概率**，正 / 负 / 中三者之和 = 1：

| 字段 | 语义 | cov | users/alphas |
|---|---|---|---|
| `positive_sentiment_probability_3` | 正面概率 | 0.70 | 295 / 585 |
| `negative_sentiment_probability_3` | 负面概率 | 0.70 | 241 / 505 |
| `likelihood_of_neutral_tone` | 中性概率 | 0.70 | 46 / 64 |
| `overall_sentiment_score` | argmax 类别标签 | 0.70 | 284 / 599 |
| `sentiment_weighting_method1` / `_method2` | 两种加权口径 | 0.70 | 145/232、175/290 |
| `intraday_delay_indicator` | 元数据 | 0.70 | — |

**关键结构推论**：三类概率和恒为 1 ⇒ 任意一阶组合都落在二维 simplex 上。因此「正 − 负」是有符号的一维方向，「和/熵/HHI」是无符号的集中度。这两类在经济学上完全不同：前者是**观点方向**，后者是**观点确定性**。

论坛实测（`get_datafields` 的 alphaCount / userCount 与帖 `43620895448343`）已知 `overall_sentiment_score` 单用 Sharpe 仅 1.2–1.5，信息量低于概率差，故本波不使用。

## 3. 核心归因：活的是「方向」，死的正是「去掉方向」

### 3.1 12 条按「是否有符号」二分，结果完全分离

| 类别 | 模板 | S 范围 | 结论 |
|---|---|---|---|
| **有符号方向性** | E3 / E7 | **1.57 – 1.63** | 全活 |
| 无符号量（集中度、波动、分歧） | E1 / E4 / E5 / E6 / E9 / E12 | −1.16 – −0.25 | 全死 |
| 单维水平（非差） | E2 / E10 / E11 | −0.28 – 0.83 | 全弱或死 |

E3 与 E7 的共同点不是「某个矩」也不是「某个算子」，而是**保留了正负情绪概率的有符号方向**；且都对它做了**长窗时序标准化**（W504 / W252）。E10 也是「正概率水平 + 长窗加权」但只有单一维度、没有「减负概率」这一步，S 就掉到 0.83。

⇒ **有效机制 = 有符号的正面−负面概率差，做长窗时序归一后再截面分组排序。** 三个要素缺一不可：
1. 必须有「减」形成符号（E10 缺此步 → 0.83；E11 单用负概率 → −0.28）
2. 必须长窗时序归一（E8 用 ts_delta 的 504 差分 → 0.05，因为差分会消灭水平信息）
3. 截面必须分组（用 `industry`）

### 3.2 与波 167（shortinterest3）的归因**相反**，这是本轮最重要的方法论修正

| 数据集 | 活的结构 | 死的结构 |
|---|---|---|
| `shortinterest3`（波 167） | **4 种矩全活**：水平 1.78、方差 2.04、vol-of-vol 1.74、绝对一阶矩 1.74 | 数量族（任何矩）全死 |
| `earnings_sent_matrix`（波 168） | **只有水平/秩活**：ts_rank 1.63、条件化水平 1.57 | **矩类全死**：二阶 −0.52、绝对一阶 −0.23、三阶 −0.60 |

⇒ **「矩类模板」不是通用机制，不能跨数据集外推。** 波 167 曾得出「矩是放大器不是开关」的结论，本波证明在 `earnings_sent_matrix` 上矩**连放大器都不是，是负项**。

两个数据集唯一共享的有效性条件只有一条：**活的是「有方向的单一测度」**。
- shortinterest3：费率（借券价格）天然有方向 ⇒ 1 阶 2 阶都活
- earnings_sent_matrix：三分类概率本身无方向，必须人为构造「正−负」才有方向 ⇒ 无符号的矩全死

### 3.3 E6「方法分歧」有信息但方向相反

`Jjel58dW = reverse(group_zscore(ts_zscore(method1 − method2, 252), industry))` 得 S **−1.16**，即**去掉 `reverse` 约 +1.16**。但 fRA=4、`invest_ratio` 0.6983 贴着 0.70 线，即便改向也够不到 1.58，且两套加权口径的定义未公开，暂不追。

## 4. 点塔相关性墙：QPYOPLAK 是「中心锚」

`compute_mutual_correlation`（4 年日收益，986 点，纯本地零配额）：

```
                RREXk770   58ERq5LM   QPYOPLAK
RREXk770          1.0000     0.6521     0.8067 *
58ERq5LM          0.6521     1.0000     0.7591 *
QPYOPLAK          0.8067 *   0.7591 *   1.0000
```

**反直觉但决定性的结论**：
- `QPYOPLAK` 与另外两颗**都超线**（0.8067 / 0.7591）⇒ 它是这个数据集上「最中心」的那颗，会把另外两颗全封死。
- `RREXk770 ↔ 58ERq5LM` = **0.6521**，在线下 ⇒ **最优两点集 = {RREXk770, 58ERq5LM}，把 QPYOPLAK 排除**。

⇒ **取舍**：QPYOPLAK 虽然 S 1.70 > RREXk770 的 1.63，但它会封死第 2 颗。
⇒ **earnings 塔第 3 颗必须来自 earnings 塔下的另一个数据集**（`earnings_sent_matrix` 上任何第三颗都会与这两颗之一撞线，因为它们是同一个现象的不同测量）。

可用数据集：`earnings27`（0 已挖、cov 0.26、邮件词频）、`earnings7`（0 已挖、EPS+股息日历）、`earnings6`（104 已挖、best_s 1.77）、`earnings_chart_dl`（10 已挖、best_s 0.69）、`earnings4`（13821 alphaCount，饱和，不用）。

## 5. `58ERq5LM` 的破闸算式：TO 地板反向经济学

`58ERq5LM` 只差两项：`LOW_SHARPE 1.57 / 1.58`、`LOW_FITNESS 0.89 / 1.0`。

平台 `fitness = sharpe × sqrt(|returns| / max(turnover, 0.125))`，本条的 **TO = 5.44% 只有 0.125 地板的 43.5%** ⇒ 分母被地板钉死：

```
F = 1.57 × sqrt(0.0398 / 0.125) = 1.57 × 0.5643 = 0.886  ≈ 平台 0.89 ✅
```

即 **F 此时只由 S 与 R 决定，与 TO 完全无关**。

要 F ≥ 1.0 的三条路径：

| 路径 | 需要达到 | 可行性 |
|---|---|---|
| 提 S（R、TO 不变） | S ≥ 1.772 | ✗ 需 +12.9% Sharpe |
| 提 R（S 不变） | R ≥ 5.07% | ✗ 需 +27% 收益 |
| **提 TO 到 0.125 附近** | R/TO ≥ **0.406** | **✓ 当前 R/TO = 0.0398/0.0544 = 0.732，是阈值的 1.80 倍** |

**当前 margin 效率有 80% 的安全边际** ⇒ 提换手是本条唯一可行且有实证支撑的破闸方向。这与「降换手提 fitness」的常规动作**方向相反**，是本轮从平台公式反推出来的。

### 波 169 的 6 条提换手杠杆（已派发）

| 杠杆 | 改动 | 预期效应 |
|---|---|---|
| L1 | `ts_zscore` 252 → 66 | 信号翻转加快，TO 上升 |
| L2 | `ts_zscore` 252 → 22 | 同上，更激进 |
| L3 | `trade_when` 第三参 `-1` → `0` | 条件不满足时清仓（而非持仓不变），TO 会大幅上升但 margin 可能崩 |
| L4 | `group_rank` → `group_zscore` | 保留幅度信息，TO 通常更高 |
| L5 | 条件 `rank < 0.5` → `rank < 0.7` | 放宽筛选、覆盖更多票、提高交易频率 |
| L6 | L1 + L4 组合 | 复合杠杆 |

**判据**：TO 升到 0.08–0.12 且 R/TO 保持 ≥ 0.50 ⇒ F 可到 1.0 以上。

## 7. 可复用结论

1. **三分类概率数据集的有效机制**：只有「正 − 负」的有符号差 + 长窗时序归一 + 分组截面排序这三件套能出货。分布几何（HHI / 联合概率 / 有符号集中度）在这个数据集上全部为负，不要再试。
2. **「中心锚」概念**：点塔凑数时，先算候选两两相关矩阵。**S 最高的那颗往往是中心锚**，它自己过闸但会封死别人。最优组合不一定是 Top-N by Sharpe，而是**最大互不相关子集**。本波 `max_mutually_below_subset` 直接返回了 {RREXk770, 58ERq5LM}，与 QPYOPLAK 无关。
3. **TO 地板反向经济学**：拿到候选先判 `TO < 0.125` 与否。在地板下时 F 与 TO 完全无关，此时「降换手」是净亏，**提换手可能白拿 fitness**。判据 = `R/TO` 相对 0.406 阈值的倍数。
4. **矩类模板不可跨数据集外推**：波 167（费率族 4 种矩全活）与波 168（矩类全死）是直接反证。每个新数据集都必须独立做矩消融，不能继承上一个数据集的结论。
