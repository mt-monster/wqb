## 2. 归因①：水平型是唯一有效形状（★ 决定性）

| 形状 | 模板 | S 区间 |
|---|---|---|
| **水平型**（`group_rank(ts_backfill(F,120), G)`） | T1 / T2 / T3 / T4 | **1.14 – 1.26** |
| 时序型（一阶 / 二阶 / 时序秩 / 时序 z） | T5 / T6 / T7 / T8 | 0.33 – 0.93 |
| 两字段结构比 | T9 | −0.23 |

四条时序算子变体的 `risk_neut_S` **全部 ≤ +0.14 甚至为负**（−0.06 / −0.13 / +0.14 / −0.13）。

**机理**：治理字段是慢变量，**价值在横截面的水平排序（谁治理更好），不在自身的时序变化（治理变好了多少）**。治理变化太慢，时序算子只能捕到噪声。

**⚠ 这里推翻了我设计波 192 时的一个假设**：我当时认为「网络计数非单调 ⇒ 时序算子可用」。实测否定 —— 即使字段本身非单调，对慢变量治理字段用时序算子仍是错的维度。

## 3. 归因②：T9 结构比把两个正信号相互抵消

`group_rank(divide(连接数, 任期+1))` → S −0.23 / F −0.05 / 2Y −0.78 / DD 14.90%。
任期长（+）与连接多（+）各自都是好的，相除后互相抵消。
⇒ 这是「禁 `add(A,B)` 混信号调参」在 `divide` 上的同构实证：**两个同向正信号的比值不是新信号，是信号抵消器**。

## 4. 归因③：T10 换分组轴救不动 SUB

姓氏集中度从 subindustry 换到 market：`SUB 0.14 → 0.13`（几乎没变），`2Y 1.90 → 1.99`（略升）。
**根因暴露**：`longCount 965` vs `shortCount 1574` —— **多空极度不对称**。
⇒ SUB 问题的根源是「信号在长边覆盖不足」（家族企业本就少），**不是分组轴选错**。换轴是无效修法。

## 5. 归因④：T6 是「方差陷阱」的第三次复现

`ts_std_dev(网络连接, 252)` 的 DD **5.03%** 是 10 条里最低，但 S 0.93 / **2Y 0.57**。
⇒ 把信号换成「方差」能大幅降波动率与 DD，但会同时砍掉 S 与 2Y。
与 `earnings_chart_dl` 的教训完全一致（那边唯一把 TO 压到 9% 的模板靠 `ts_std_dev`，代价是 SUB −0.22）。
**「二阶矩换稳定」在所有已知数据集上都以牺牲收益为代价。**

## 8. 判定与下一步

**判据**：这是「信号源天花板」而非「骨架选错」——21 条里所有非退化形状都收敛到 S ≤ 1.30，且 `risk_neut_S` 稳定为正（+0.76 到 +1.09），说明**信号是真的但太弱**（治理水平对日频收益的解释力有限）。

**结论**：`board_gov_stats` **单塔单数据集到不了 1.58 闸**。保留最优 3 条作 salvage（`E563xJMP` S 1.30 / `pwd03gN3` S 1.22 SUB 0.62 / `LLMerE0a` S 1.26），**不判死数据集**（它仍是 INSIDERS 塔最低拥挤的入口，且 `surname_concentration_total_personnel` 全平台 0 人使用）。

**下一步的三个分支（按性价比排序）**：
1. **换 INSIDERS 塔的另一数据集**：`insiders1`（9 字段 / cov 0.755 / alphaCount 386 / **multiplier 1.5**）与 `insiders4`（16 字段 / alphaCount 1,422）。塔位同为 INSIDERS，挤占配额但不重复机制。
2. **回 `board_gov_stats` 补 universe 降档**（TOP1000）—— 大盘股治理数据更完整，S 可能上移。
3. **与 `surname_concentration` 组双字段水平差**（不是比值）—— 但 T9 已证明混信号风险高，优先级最低。

## 9. 复用警示

1. **慢变量治理字段只能做水平信号**，任何时序算子（一阶/二阶/时序秩/时序 z）都会崩。
2. **`group_rank(分组轴)` 之后仍需平台中性化**（NONE 导致 DD 68.9%）；但**别用与表达式内层相同的轴**（双重扣行业），MARKET / INDUSTRY 是更好搭配。
3. **两个同向正信号的 `divide` 是信号抵消器**，不是新机制。
4. **SUB 闸靠换分组轴救不动**，先查 longCount/shortCount 是否对称。
