## 三、核心结论：模板效果由「频段」决定，不是「机制」

| 字段频段 | 最佳模板 | 次佳 | 最差 |
|---|---|---|---|
| **慢频文本/事件**（A） | **一阶差分** (+0.19) | 二阶差分 (+0.17) | 双窗秩乘积 (−0.09) |
| **慢频分析师预期**（B） | **双窗秩乘积** (+0.52) | 横截面秩 (+0.66 中位更高但 max 1.17) | 二阶差分 (−0.24) |
| **高频价量**（C） | **双窗秩乘积** (+0.17) | 横截面秩 (+0.24) | 差分族（−0.07~−0.11） |
| **慢频基本面**（D） | 横截面秩 (+0.13) | 冠军栈 (+0.13) | 二阶差分（max 仅 0.16） |

**四条可执行规则**：

1. **快 / 价量 → `rank` + 双窗秩乘积**（短窗即期 × 长窗持续，两者都高才是稳定信号）
2. **慢 / 文本情感 → 一阶/二阶差分**（信息在「变化」不在「水平」；水平已被定价）
3. **慢 / 分析师预期 → 双窗秩乘积**（短窗预期变化 × 长窗预期水平，捕捉「变化 + 位置」）
4. **慢 / 基本面 → `rank` / 冠军栈**（比率已归一化，直接取位次）

## 四、推翻的旧认知

| 旧认知 | 实证结果 |
|---|---|
| 「双窗秩乘积是 A 级万能模板」 | **只在 B / C 面板有效**（starmine S 1.39、PV S 0.82），在 A 面板最差（−0.09）、D 面板平庸（+0.08） |
| 「冠军栈是通用冠军」 | 在 B 面板有效（max 0.74），在 C 面板中位 −0.12（**高频价量上反而有害**） |
| 「差分总能提信号」 | 只在 A 面板（慢频文本）成立；在 B 面板中位 −0.04、C 面板 −0.07 |

## 五、size 对照验证（面板 D 的 `risk70.current_market_cap_usd`）

| 模板 | best_S | 判定 |
|---|---:|---|
| T6 时序秩 | **−1.00** | size 反向（市值小的未来收益高） |
| T1 冠军栈 | **−0.73** | 同上 |
| 其余 | −0.15 ~ +0.28 | — |

**⇒ 市值本身是强信号（|S| 0.73–1.00），但方向为负，且这正是 institutions 战役中 `vector_neut(size)` 后归零的那个因子。**
结论：**size 必须作为默认正交项处理，任何 level 类字段都要先做 size 体检。**

## 六、面板局限（必须承认）

- 每个面板只有 8 个字段，中位数置信度低；结论是**方向性**的，不是精确参数
- 面板 A/D 的字段本身弱（best_S 中位 <0.2），主要提供**相对排序**
- 面板 B 是唯一有 ALIVE 证据的，其结论（双窗/秩最优）可信度最高
- 未覆盖：`cluster_label` / `identifier` / `sentiment` 型的独立面板
