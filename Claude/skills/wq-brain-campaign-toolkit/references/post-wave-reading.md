# 波后解读：比较、研究线索、纠错复验

> 从 `selection-plan.md` 拆出（那一页只讲选波）。这里讲选波**之后**：S4 / S6 怎么读结果、什么时候写研究线索、什么算「纠错复验」。

## 名词（先定义，再用）

- **资格线**：区域 `mode_b_qualification`（判定工具 `tools/mode_b_qualify.py`；口径与「主闸 + 旁路 A–E + 判死线」见 `wq-brain-alpha-optimization-v1/references/mode-b-qualification.md`）。**增强资格** = 过了资格线、有资格进入 Mode B 增强。沿用用户提示词 / 区域配置里的资格线，不在本页另设。
- **平台 UNITS 警告**：回测详情 `checks` 里 `name=UNITS`、`result=WARNING` 的项（表达式各腿的单位不一致）。它不影响 Sharpe，却说明这条式子的比较对象有问题。
- **缺陷白名单**（只有这三类算「缺陷」，才有资格触发纠错复验）：① 单位警告；② 字段映射错误（字段被当成另一个含义）；③ 对照不匹配（预处理、设置或样本范围与配对基线不一致）。**「Sharpe 弱」不是缺陷。**

## 下一波怎么选

S4 / S6 比较主假设和对照的 Sharpe / Fitness、RN 指标、逐年表现及相关性，再判断变换是否值得继续；不要仅按单次最高 Sharpe 扩展窗口。优先补未覆盖的独立机制或缺少的对照；有证据的方向再做有限敏感性检验。延后项记录重访条件，只有实际回测失败且满足判死规则才能成为 `dead_end`。阶段总结要列：计划数、选中数、门禁通过数、完成数、未覆盖的问题和下一步原因。

## 指标上升但尚未达到增强资格

**先确认比较有效**：配对的经济问题、字段口径、预处理、设置与样本范围须一致；检查平台 UNITS 警告。跨机制的两批最高 Sharpe 只能表示发现了更强候选，不能证明某次变换有效。有单位 / 语义缺陷的旧式不适合做干净对照，也不能用其失败判死正确的经济假设。

**把值得调查的问题写进同区域 ledger 键 `research_leads_w<W>`**（`mcp__wqb-db__upsert_ledger_key`，每波一条）。它只保留研究证据，**不是 near / ready 池，不自动获得 Mode B 资格或追加模拟权限**。字段（格式示例）：

```json
{"region": "EUR", "wave": "251",
 "alpha": "<alpha_id>", "control": "<配对基线 alpha_id>",
 "same_row_metrics": {"sharpe": 1.21, "fitness": 0.83, "two_year_sharpe": 0.95, "rn_sharpe": 0.4},
 "open_question": "应收周转改善的收益是否被规模因子解释",
 "next_check": "只读平台详情核查逐年收益与 RN；无需新回测",
 "stop_when": "RN 强度 ≤ 0，或近窗 2Y 持续为负"}
```

先用已有结果和只读平台详情核查覆盖、逐年收益、2Y 与 RN 强度。保留正证据和反证，不因全期 Sharpe 提高而忽略近窗或风险暴露恶化。全期 / 年度 Sharpe 不是独立重复试验，未经配对检验不能宣称提升显著。

## 最小纠错复验（每个缺陷最多一次）

只有命中上面的**缺陷白名单**时才允许，按已授权研究范围做**一次**。先写一张「纠错复验单」（可放进 `research_leads_w<W>` 的同一条，字段 `correction_plan`）：

| 字段 | 内容 |
|---|---|
| `defect` | 缺陷是哪一类（单位警告 / 字段映射 / 对照不匹配）+ 证据（警告原文或不一致的设置项） |
| `question` | 修正后要回答什么（例：去掉单位警告后，水平基线是否仍不及变化信号） |
| `must_test` | 必测项（修正后的式子 + 它的配对对照；已有同设置对照直接复用，不重跑） |
| `frozen` | 与缺陷无关而必须冻结的参数（窗口、分组、设置） |
| `stop_when` | 停止条件（一次复验后无论结果如何都停） |

新表达式仍走 GEM → 身份清单 → 门禁 → 回测；平台警告未解决则只记录「测量未决」。**不能借「纠错」给无缺陷的弱信号反复换窗口、翻号或组腿**；纠错后的结果须重新满足资格线才能发增强波。

没有具体可检验缺口时保留线索，转向其他独立机制。S6 同时记录「原式未达标」和「研究问题是否已解决」两件事，避免把「停止参数扩展」写成「停止一切研究」。
