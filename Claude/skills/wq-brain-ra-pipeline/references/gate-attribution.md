# 闸失败归因（只差一两闸时先归因、再定向推闸）

> 层：L-RA 细则｜机制来源：用户指令 2026-10-16｜执行器：`tools/gate_attribution.py`  
> 判定逻辑唯一出处：`src/wqb/gate_attribution.py`（本文件只解释判据，不复写数值）

## 0. 什么时候用

**触发条件：一条候选 `failed_ra_count` 只剩 1–2 道闸**（不是全灭，也不是零闸）。

- 零闸 → 直接进步 8 提交判定，不要在这里磨
- 全灭（≥3 闸）→ 走常规多轮诊断 / `s4-prescreen` 判死，不属本机制
- **1–2 闸 → 本机制**：先归因，再按杠杆表定向推

**本机制不替代推闸，也禁止变成「分析 paralysis」**：归因是**排序 + 定停手线**，  
拿到杠杆表后照样要一条一条推仿真。它唯一替代的是**无差别盲扫**。

## 1. 为什么（实测依据，不是理论）

2026-10-16 KOR 两轮、约 50 次仿真的复盘：

| 现象                                                         | 盲扫的代价         | 归因能提前多久发现             |
| ---------------------------------------------------------- | ------------- | --------------------- |
| 分析师族 S↔prod **剪刀差**（S 每 +0.07 ⇒ prod 同 +0.01，6 个结构永不交叉）    | ~15 次仿真全部白跑   | 第 1 次候选就知「不可达」        |
| `quantile` 单点 S +0.09 **有效**，但同时 prod 0.6989→0.7117 **过线** | 差点当成有效杠杆继续推   | prod 余量 0.0011 ⇒ 先验否决 |
| shortinterest38 族 2Y 在 4 个**互不相关**杠杆上全部收敛 1.51–1.56        | 收敛前一直以为参数没调到位 | 收敛即信号 ⇒ 机制层天花板        |
| 门控窗口→S **单调**（66→1.41 / 22→1.51 / 10→1.57）                 | —             | 这是「可解释轴上的定向搜索」，不是盲扫   |

**可执行判据的两条硬结论**：

1. **先测 prod 余量，再决定要不要推 S。** 抬 S 的杠杆多半同时抬 prod；  
   余量 < 0.01 时任何抬 S 杠杆都先验撞线。
2. **收敛即天花板。** 同一闸在 ≥3 个互不相关杠杆上收敛到同一档 ⇒ 机制层问题，  
   继续刷参数是纯浪费配额。

## 2. 三条口径铁律

1. **闸线取平台回传的 `limit`**，不取仓内常量。实测冲突：KOR D1 平台回  
   `LOW_SHARPE limit=1.58`，而 `config.PLATFORM_CHECK_LINES` 记 delay1 = 1.25  
   —— 冲突时**以平台为准**（与「判定只走平台」一致）。
2. **`fail: []` 不等于过闸。** RA 计数口径 = 平台插件 `getAlphaCheckStates`：  
   结果既非 PASS 也非 PENDING（**WARNING / ERROR 都算**）即计入  
   （见 `src/wqb/config.py` RA_2Y_NAMES 段内注释）。本工具把 `warning` 也计入失败。
3. **不轻信状态桶**：若某 check 列在 `pass` 但 `value < limit`，照样判失败  
   （口径漂移时真会出现，漏判会让归因给出错误的「可推」结论）。

## 3. F 闸闭式公式（零仿真可得精确 TO 天花板）

```
F = S × √( |returns| / max(TO, 0.125) )
```

三点反解验证（平台值 vs 公式值，Δ ≤ 0.003）：

| alpha      | S    | returns | TO         | 平台 F | 公式 F  |
| ---------- | ---- | ------- | ---------- | ---- | ----- |
| `akVJLlWO` | 1.51 | 0.0746  | **0.0852** | 1.17 | 1.167 |
| `QPYr21wg` | 1.29 | 0.101   | **0.0203** | 1.16 | 1.160 |
| `bl82VavN` | 1.79 | 0.0933  | 0.2835     | 1.03 | 1.027 |

前两行 TO **低于**地板 0.125：若用「无地板」公式会算成 1.41（差 0.24），证明地板存在。

⇒ **`TO 地板 = 0.125` 是硬约束**：把 TO 从 0.125 继续压低**不再改善 F**。

由此得闭式判据 **`to_target = returns × (S / F_target)²`**：

| 条件                                     | 含义             | 动作                     |
| -------------------------------------- | -------------- | ---------------------- |
| `to_target > 0.125` 且 `TO > to_target` | 减速**可**救       | 减速，给出需砍的百分比            |
| `to_target > 0.125` 且 `TO ≤ to_target` | 已过             | —                      |
| `to_target ≤ 0.125`                    | **减速路线数学上不可达** | **停手**，必须抬 returns 或 S |

## 4. 逐年归因（按闸分诊）

同一条腿常常**同时**满足「单年塌陷」与「近段衰减」，但两者对不同闸的可行动性不同：

| 归因类               | 判据                      | 对 LOW_SHARPE 的含义    | 对 IS_LADDER_SHARPE 的含义   |
| ----------------- | ----------------------- | ------------------- | ------------------------ |
| `single_collapse` | 最差年 S < 0.5 且中位 S ≥ 1.2 | 收益被单年/少数极端股主导 ⇒ 压尾部 | 若塌陷年不在近段窗口 ⇒ **与该闸无关**   |
| `recent_decay`    | 末 2 年均值 < 前段均值 − 0.5    | 说明**别修 S**          | ladder 就看近段窗口 ⇒ **正是病因** |
| `uniform_weak`    | 逐年中位 S < 1.2            | 机制整体弱               | 同                        |
| `target_gap_only` | 其余                      | S 差口小、无单年塌陷         | 同                        |

⚠ **样本量要求 ≥5 年**才让 `recent_decay` 成立（需要「前段」可比）。3–4 年时  
工具会标 `sample_ok=false`，此时该归因按低置信度对待，**不要据此换轴**。

## 5. 相关性闸（`PROD_CORRELATION` / `SELF_CORRELATION`）

**它不在 `checks` 里，必须单独补。** 平台把这两项在 `checks` 中恒标 `PENDING`  
（提交时才计算），真值只在 `check_correlation` / `check_self_correlation` 的  
`correlation.{production,self}` 里。若不单独处理，归因器在**最常见的卡线态**  
（RA 全过、只差 prod）会误报「失败闸 0 道 ⇒ PUSH_TARGETED」，等于漏诊。

判定口径两条：

1. `passes_check === false` 即失败；否则用 `max_correlation >= limit` 兜底  
   —— **提交层是严格不等式**，KOR 实测 prod 恰为 `0.7000` 判 FAIL。
2. 病因按余量分三型：

| 余量                 | cause_class          | 裁决                        | 动作                                         |
| ------------------ | -------------------- | ------------------------- | ------------------------------------------ |
| `≥ −0.01`          | `knife_edge`         | `PUSH_CORRELATION_CORNER` | **不要改结构**，在 `(门控窗口 × winsorize std)` 二维找角点 |
| `< −0.01` 且剪刀差预测过线 | `scissor_structural` | `BLOCKED_BY_CORRELATION`  | 换字段/数据集                                    |
| `< −0.01` 其余       | `mechanism_crowded`  | `BLOCKED_BY_CORRELATION`  | 换字段/数据集                                    |

> **`knife_edge` 是本机制的核心价值**：KOR 分析师族 prod 在 `0.6989–0.7081` 之间  
> 随 (gate, std) 非单调散布，`std` 轴单独就能让 prod 振 0.008。2026-10-17 正是靠  
> `gate6 × std0.22` 命中 `prod 0.6991 / S 1.60`（全闸通过），而 `gate5/std22` 是  
> `0.7000`（判 FAIL）、`gate15/std26` 是 `0.7003`。**差 0.0003 就是过与不过。**

## 5b. 剪刀差检测（跨候选采样）

给同族采样 `[{sharpe, prod_corr}]` ≥3 点，拟合 `prod ~ a·S + b`：

- `a > 0` 且外推到 `S = 1.58` 时 `prod ≥ 0.70` ⇒ `scissor_structural`  
  ⇒ **该腿在当前机制层不可达**，顶层裁决 `SWITCH_AXIS`
- KOR 分析师族实测 6 点：slope 0.1321 ⇒ `prod@S1.58 = 0.709 ≥ 0.70` ⇒ 不可达  
  （而其中 S 1.58 的两档真实 prod 0.7063 / 0.7087，都没过）

## 6. 杠杆表（摘要；完整表见执行器 `_LEVER_TABLE`）

杠杆表里每条都带**本项目实测证据**，不是通用清单。已实测的几条：

| 闸                       | 归因类                 | 首选杠杆                                               | 实测证据                                                             | 代价                             |
| ----------------------- | ------------------- | -------------------------------------------------- | ---------------------------------------------------------------- | ------------------------------ |
| LOW_SHARPE              | 任意 + prod 余量 < 0.01 | 先找 **prod 中性**的 S 杠杆                               | `akVJLlWO` prod 余量 0.0011，`quantile` +0.09S 即顶到 0.7117           | —                              |
| LOW_SHARPE              | `single_collapse`   | 压尾部（`winsorize`/`quantile`/`tail`）                 | `rank_by_side` 帖 2Y 0.28→2.44；⚠ **本账号无该算子权限**（实测 `inaccessible`） | margin 掉（0.001→0.000935）       |
| LOW_SHARPE              | `target_gap_only`   | `quantile` / `signed_power` 幂次扫描                   | `quantile` +0.09（处方预测 +0.10 吻合）；幂次 2.5 为 IS 最优点                  | `quantile` 微抬 prod             |
| LOW_FITNESS             | `slowing_enough`    | 减速：**`ts_backfill` > `decay` > `ts_decay_linear`** | `hump`/`TVR` 类会毁强度                                               | 中                              |
| IS_LADDER_SHARPE        | `single_collapse`   | **内层 `group_neutralize`**                          | 论坛 2Y 1.15→2.04；KOR 1.17→1.51                                    | 掉 S/F，可能触发 `LOW_INVESTABILITY` |
| IS_LADDER_SHARPE        | `recent_decay`      | 换字段/数据集                                            | KOR shortinterest38：4 杠杆收敛 1.51–1.56                             | 高                              |
| LOW_SUB_UNIVERSE_SHARPE | —                   | 换**粗轴**                                            | sub 是**比率闸**（limit ≈ 0.53×S）⇒ 抬 sub 而非追 S                        | 低                              |

### 内层 `group_neutralize` 的粒度铁律

`group_neutralize` 是正交投影 `P`（`P² = P`）。**内层粒度必须严格细于外层 setting**，  
否则外层把内层效果整个吸收，退化成恒等变换（论坛实测三档 SELF_CORR 0.9909–0.9932）。  
有效自由度 = 内层粒度与外层 setting 的**差集**。

## 7. 退出码（流水线分支用）

| 码 | 裁决                        | 流水线动作                                                                                                                  |
| - | ------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 0 | `READY`                   | RA + prod + self 全过 ⇒ **停手**，不得再做结构性改动（会重掷骰子）                                                                          |
| 0 | `PUSH_TARGETED`           | 按 `diagnoses[].levers` 的 rank 逐条推，每条只动一个变量；若相关性未实测，先补 `check_correlation` + `check_self_correlation`，**不能凭「0 道失败」判就绪** |
| 0 | `PUSH_CORRELATION_CORNER` | RA 全过、仅相关性差 ≤0.01 ⇒ `(gate × std)` 二维找角点，**不改结构**                                                                      |
| 3 | `SWITCH_AXIS`             | 本腿到天花板 ⇒ 换字段/数据集；**不要**继续刷参数                                                                                           |
| 4 | `BLOCKED_BY_CORRELATION`  | 先找 prod 中性杠杆，否则所有仿真白跑                                                                                                  |
| 5 | 两闸以上                      | 不属本机制，走常规多轮诊断                                                                                                          |

## 8. 停手线（写进每份归因报告，不可省）

1. 同一杠杆连推两次 `Δ ≤ 0.005`（按 2 位小数比较）⇒ **分辨率极限**，停手换轴
2. 同一闸在 ≥3 个**互不相关**杠杆上收敛到同一档 ⇒ **机制层天花板**，停手换轴
3. `SWITCH_AXIS` / `BLOCKED_BY_CORRELATION` 裁决 ⇒ **不得**再用同一结构族发批
4. 论坛/处方给的杠杆若 3 个以上在本腿失效 ⇒ 记一条跨区实证，别再重复试

## 9. 与既有 skill 的分工

| 环节                     | 归属                                                                | 说明                                                 |
| ---------------------- | ----------------------------------------------------------------- | -------------------------------------------------- |
| 逐年 + 子宇宙 + 集中度**归因报告** | [`brain-alpha-robustness`](../../brain-alpha-robustness/SKILL.md) | S4→S5 必经闸，结论落台账 `robustness_<id>`，**REJECT 由代码执行** |
| **闸失败 → 定向杠杆 + 停手线**   | 本机制 + `tools/gate_attribution.py`                                 | 只管「怎么推」，不管「该不该提交」                                  |
| 单条候选的参数级修改             | `brain-alpha-repair` / `wq-brain-alpha-optimization-v1`           | 拿到杠杆表后交给它们执行                                       |

顺序：**归因（本机制）→ 定杠杆表 → repair / optimization 执行 → 复审 → 提交判定**。  
`brain-alpha-robustness` 的 Phase B 是本机制的**数据来源之一**（逐年 + 集中度），  
两者互补、不重复：`robustness` 判「该不该交」，本机制判「该往哪推」。
