# 六步纵深骨架 · 通用主文档

> **本文件是「主 skills」层**：六步中**跨 region 通用**的方法论，表述保持通用，
> **不含任何 region 的专有规则 / 档位 / 参数 / 实证数值**。
> 各 region 在自身 SKILL.md 的「六步纵深骨架（本区覆盖）」节中引用本文件，
> 并把 region 特有差异写进该节各步的**「本区覆盖」**子块（override）。
>
> - **主 skills（本文件）** = 通用方法、铁律定义、接线关系、判据框架。
> - **region override** = 平台档位、实测杠杆值、已死轴、本区工程坑、实证数值。
> - 二者冲突时**以 region override 为准**（override 覆盖主 skills），但不得放宽「锁定项」。
>
> 出处：自 KOR（`wq-brain-ra-kor`）六步纵深骨架提炼，剥离 KOR 专有内容后泛化。
> 配套：九步通用正文 → [`wq-brain-ra-pipeline`](../SKILL.md)。

## 主干：六步纵深 + 一圈发波闭环

```
① 六法体检  调 L1 → 摸清字段性格            ┐
                                           │
② 组装      立机制 → 定核心形态 →           │  一个信号
              选壳层 → 双通道取证            │  从零到提交
                                           │
③ 归因      判「信号衰减」还是「因子拖累」  │
                                           │
④ 破闸      每闸一根杠杆，单变量对照         │
                                           │
⑤ 算子穷举  先分组轴 → 再时序平滑 → 最后幂次 │
                                           │
⑥ 终验      prod/self 实测 + 反过拟合 → 交用户┘

       ↺ 发波闭环：开波前跑 ③ 归因 → 查决策表 → 写清继承/准入/收窄
         → 发波 → 收割 → 回到 ③
```

**六步是纵深**（一个信号怎么走完），**闭环是横向**（每波怎么设计）。两者独立且强制。

## 发波闭环（每波开波前必走）

> 违反此纪律的代价：归因被跳过、每波从基线重启、已知死轴反复重测 —— 白烧配额。

### 1. 归因前置（铁律 F）

开波前对**上一波优胜候选**跑两个工具，缺一不可：

| 工具 | 必答问题 |
|---|---|
| `get_alpha_yearly_stats` | 逐年 S 分布如何？**S<1.0 的年份占几成**？top1 年占正收益多少？ |
| `get_alpha_pnl` | 曲线是阶梯累积（健康）还是尖峰暴涨（可疑）？**有几段停滞 / 回撤**？ |

### 2. 归因读数 → 发波决策表

| 归因读数 | 含义 | 下一波必须做什么 |
|---|---|---|
| 单年占正收益 >30% | 过拟合 | **换机制族**，不做参数微调 |
| **S<1.0 年份 ≥3 成** | 2Y 闸结构性不可达 | ⛔ 停扫 decay / 平滑 / 门控，**换 regime 无关的机制** |
| 近年 S 断崖（S 从 2+ → <0.5） | 机制性衰减 | 换字段族（衰减是机制的，不是参数的） |
| 停滞段 ≥3 | regime 依赖 | ⛔ 平滑器谱整族无效，**必须换机制** |
| RN 涨幅 ≫ raw 涨幅 | 因子暴露拖累 | **换中性化档**（唯一该继续扫的轴） |
| raw 与 RN 同步走弱 | 信号自身衰减 | 换字段族 / 机制族 |
| 阶梯健康 + 停滞段少 + 单年 <30% | 信号真实但强度不足 | ⭐ **此时才允许**做强度 / returns 杠杆扫描 |

⚠ **归因先行不是仪式，是止损**：逐年 S<1.0 占比高时，2Y 闸在任何参数档都不可达，
继续扫 decay / 中性化必然白烧配额。

### 3. 波次三问（铁律 G）

开波前逐条写清，缺任一条 = 设计退化，必须重写：

1. **继承**——上一波的哪条结论被写成本波的准入条件？
2. **准入**——本波禁止触碰哪些轴？（对本区「已死轴清单」）
3. **收窄**——候选数 vs 上一波候选数，比值多少？**不降即退化**。

**反模式**：一边写下「X 是唯一某杠杆」，一边仍派发上一波已实测更劣的同类结构 ⇒ 把已知会败的东西重复烧配额。

### 4. 已死轴清单（命中即禁入 quota）

> **主 skills 只给通用骨架**，具体条目由各 region 在本区 override 中填写。
> 通用上应排查这几类（region 各自实测后再定）：

| 死轴类别 | 通用判据 |
|---|---|
| 档位类扫描 | 平台 `get_platform_setting_options` 实测**唯一合法档** ⇒ 该轴被平台锁死，禁扫 |
| 已分优劣的平滑器 / 算子窗口谱 | 同族内已分出优劣后，劣者窗口不再扫 |
| 跨区照搬的结构配方 | 杠杆**逐字段 / 逐族实测**，不可跨区移植 |
| 同波「在飞批次」的读数 | **不得**当作下一波设计依据（避免同波自我污染） |

> ★★ **已死轴的三个来源必须合并**（2026-10-28 GLB 事故的根因修正）
>
> 「避判死」若**只查 registry 死路表**，就会漏掉**写在组合分支卡里的死轴** —— 而那正是本区最贵的情报。
>
> | 源 | 位置 | 查什么 | 动作 |
> |---|---|---|---|
> | ① registry 死路 | `get_dead_ends` / `get_dead_datasets` | 已封存的路（族 / 数据集级） | 禁入 quota |
> | ② **组合分支卡的「避」段** | `wq-brain-ra-<区域>/references/<类别>.md` | 本区**已实测**的「禁碰字段 / 已被 prod 饱和的获胜字段 / 已死形态」 | **禁入 quota**（硬闸） |
> | ③ **组合分支卡的「prod 已测（低于上限）」存量表** | 同上 | **prod 已确认低于上限的现成候选** | **优先复用**（直接进篮子，不重挖） |
>
> - **② 是硬闸**：命中的字段 / 形态 ⇒ 不派发。GLB 2026-10-28 实测：分支卡已明写
>   「`mean_high_price_return_30m_pre_close_2`、`corr_last_trade_price_with_volume` 已被 prod 饱和闸拦」，
>   该批仍被派发并占掉 **~10 条仿真槽**。
> - **③ 是机会不是障碍**：存量表里 prod 已确认低于上限的候选**优先复用**（直接进篮子），同一候选不要重挖。
>   GLB 2026-10-28 的组合分支索引表已列 pv 43(11) / other 48(9) / model 1(0) / risk 10(0)，
>   括号里第一个数是「prod 已测」、第二个是「其中低于上限」⇒ **后者就是可复用池**。
> - **发批前执行点**：步 3 / 4 / 7 各读一次本波数据集所在组合的分支卡（总则见 `wq-brain-ra-pipeline/SKILL.md`
>   「区域 skill」段的「步 3 / 4 / 7 / 8 先读分支文件」—— 此处把它落成「已死轴清单」这一可判定动作）。
> - **反模式**（原文已有，此处补实例）：一边写下「X 是唯一某杠杆」，一边仍派发上一波已实测更劣的同类结构
>   ⇒ 把已知会败的东西重复烧配额（GLB 2026-10-28：~44 / 75 条派发是重复劳动，约占 60%）。

### 5. 席位判定（同族变体先本地算互相关，再占仿真槽）

**开波前对「同族变体」的硬前置**：任何一族的多个变体在派发前先跑 `compute_mutual_correlation`（**纯本地、零成本、不占平台槽**），只用返回的 `max_mutually_below_subset`。

- **同族互相关 0.927–0.973 是常态**（USA `assetutilization_sentiment_polarity` 四变体实测）⇒ 一个经济概念**只出得起 1 颗**。给同族投 3 个变体 = 用 3 个槽验证 1 个已知结论。
- 点塔要求「同塔 3 颗且三对互相关 < 0.5」⇒ **3 颗 = 3 个正交经济概念**。概念不足时先找概念，不要用变体占位。
- 选哪一颗：点塔场景按 **`sub_universe_sharpe`** 排（fitness 高的那颗 sub 常常更差）。
- 派发前还要查**两塔组合配额**（同一个两塔组合 ≤ 3，超配封盘）——`tools/gates/tower_quota.py`；**配额是派发前闸，不是事后盘点**（本区 `risk/model` 曾累积到 6 颗才发现）。

## ① 六法体检（★ 入口 —— 调 L1，不自建）

> **铁律 I（①部分）**：直接调 L1 的字段体检 skill，不重造。
> 它已有完整实现（离线优先 / 合批成本 / 最小集 / 扩展集 / 类型先行 MATRIX·VECTOR·EVENT·GROUP / 每法「→交 FE」映射）。
> **本节只写通用入口三件事、接线关系，以及留给 region 的特例位。**

### ★★ 0. 入口三件事（顺序不可倒，**跳步必付配额代价**）

| 序 | 事 | 干什么 | 判据 / 产物 |
|---|---|---|---|
| **0.1** | **字段质量先验** | 按 `alphaCount` 降序（同分按 `userCount`）取 **TOP30 看轴** | ⭐ **头部字段 = 该集最强经济轴**。若头部指向的轴 ≠ 拟挖方向 ⇒ **方向本身可能已偏，先纠偏再开波** |
| **0.2** | **字段分类（以 description 为准）** | 只读 description 分类，**禁按字段名**；并**逐条记录名 vs description 的差异** | 差异表 = 被漏掉的资产 |
| **0.3** | **字段画像五问 + 预处理决策** | 测什么/怎么测/时间维度/为何存在/可靠性 ⇒ 推算子与窗口 | cov<0.4→backfill；季频→窗口≥63d；VECTOR→`vec_avg`；单边→变化率 |

**为什么 0.1 必须在最前**：头部字段常揭示该数据集**最强的经济轴**（不必然是直觉的那个轴）。

**为什么 0.2 不能按字段名**：同一数据集内前缀写法常不统一（如 `estimate_count_*` 与 `count_*`、
`four_weeks_prior_` / `_3mth_prior` / `recent_` / `flash_period_`），
**按名分类会切成互不相认的族、丢失时间窗梯度**；只有读 description 才还原出真实矩阵结构。

**0.1–0.3 的产物落盘**：`tracking/<REGION>/reference/datasets/<dataset>.md`（每数据集一份）。

### ★ 接线（体检读数接不上 = 体检白做）

| 来源 | 交给下游哪一步 |
|---|---|
| 0.1 质量先验（TOP30 轴） | **②.a A-2 收益来源声明**（先确认方向 = 头部轴） |
| 0.2 分类差异表 | ②.b（矩阵结构 ⇒ 跨标的物广度，非单标的物强度） |
| 0.3 五问 + 预处理决策 | ②.b 算子与窗口（**不许自由发挥**） |
| cov<0.4 / 零占比高 / `zero_inflated` | ②.b 第 3、5 行（门控 + backfill，**禁裸 rank**） |
| 更新频率（季频 ≥63d） | ②.b 窗口下限 |
| 中心趋势（单边恒正） | 铁律 A ⇒ ②.b 第 1 行 |
| 量纲跨度 | ②.b 第 2 行（去量纲） |
| 全套读数 | ②.a A-1 五问 + A-2 收益来源声明 |

### 8 问法的适用边界

按透明度分档：**含标准财务词汇、或描述覆盖率 ≥80% ⇒ 透明集 ⇒ 跳过 8 问**，
走「0.1 质量先验 → 0.2 分类 → 0.3 五问 → 预处理决策」。

⇒ **豁免的只有 8 问本身；0.1 / 0.2 / 0.3 三件事在任何档位都不能跳。**
黑盒集（字段名无语义、描述覆盖率 <30%）才做 8 问全问。

## ② 组装（★ 自建，禁止套模板）

> **铁律 H**：**组装不是挑一副现成骨架往里填字段。**
> **核心信号形态由 ① 的体检体征决定；壳层每一层是否存在由经济机制（收益来源）决定；灵感模板走外部双通道取证。**
> **说不出「这个字段的收益从哪来」的，不许组装。**

### ②.a 立机制（A-1 五问 + A-2 硬门）

**A-1 五问定骨架方向**（每问答案直接决定 ②.b / ②.c 走向）：

| # | 问句 | 答案 ⇒ 骨架方向 |
|---|---|---|
| 1 **时间维度** | 存量水平 / 流量 / 变化率？ | 存量 ⇒ `ts_delta(F,N)`（铁律 A）；流量 ⇒ 水平直接用 |
| 2 **相对性** | 水平差异 / 排序差异？ | 水平 ⇒ `zscore`/`ts_zscore`；排序 ⇒ `rank`/`group_rank` |
| 3 **被定价的是谁** | 广度（覆盖数 / 家数）/ 强度（修正幅度 / 评级升降）？ | 广度 ⇒ 水平即可；强度 ⇒ 必须先取变化率 |
| 4 **有无博弈** | 拥挤 / 存量博弈 / 需可投资性？ | 是 ⇒ 加规模轴残差化壳层（②.c 第 1、3 行） |
| 5 **事件性** | 事件型稀疏（非事件期无信息）？ | 是 ⇒ `trade_when` 门控，**禁裸 rank** |

**A-2 收益来源声明（硬门，缺项即不许组装）**：

| 声明项 | 要求 | 判死条件 |
|---|---|---|
| **谁在被定价** | 具体到主体（卖方分析师 / 流动性提供者 / 被动资金…） | 写不出主体 ⇒ 不是机制，是相关性 |
| **为什么会被错** | 行为偏差 / 信息摩擦 / 制度约束，点名一种 | 只能说「大家没注意」⇒ **不可用** |
| **错了多久修复** | 落到窗口量级（数日 / 一季 / 数季） | 无修复期 ⇒ 是水平暴露不是错误定价，**换机制** |
| **预期方向** | 明确「被高估 ⇒ 后续跌」，不许「可能涨可能跌」 | 方向不明 ⇒ 走铁律 B 正反各测 |

**A-3 概念块（自产，供 GEM 消费）**——标记必须与 GEM 解析器一致：

```markdown
**Concept**: <机制一句话，不是字段名>
- **Fields Used**: <完整字段 id，逗号分隔>
- **Definition**: <测的是什么 + 怎么测>
- **Logical Meaning**: <谁被定价 + 为什么错 + 修复期>
- **Directionality**: <方向句，含时间窗>
- **Boundary Conditions**: <失效条件：停牌 / 覆盖变更 / 阈值失效>
- **Expected Exposure**: <momentum|reversal|value|quality|growth|lowvol|liquidity|sentiment|flow|risk|other>
- **Implementation Example**: `<模板，{占位符}用字段后缀>`
```

| 契约 | 要求 |
|---|---|
| 占位符 | `{xx}` 必须是本数据集字段的**后缀**，对不上会被 GEM 丢弃 |
| 窗口 | 只用标准窗口 1 / 5 / 22 / 66 / 252 / 504 / 1008 / 1260 |
| **禁加权拼腿** | `0.5*a+0.5*b`、`add(multiply(…),multiply(…))` 被闸拦 |
| **禁跨字段等权相加** | `add(rank(A), rank(B))` **同样被拦**。**秩化 ≠ 豁免**：闸门按「顶层实参 ≥2 条互不相等、各自引用数据字段的信号腿」判定，与是否 `rank`/`group_rank` 归一化无关。**放行**：① `subtract(rank(A),rank(B))`（两腿**同源**同一数据集 + **单一经济含义**）② `add(ts_mean(x,22),ts_mean(x,66))`（同一字段仅窗口差异）③ 换算子几何 `group_rank`/`group_zscore`/`ts_quantile`。**「多字段合成一个机制」的正解 = 价差（背离）或条件门控，不是相加** |
| `Expected Exposure` | **必写**，不写被关键词推断补 `(inferred)` |
| 落盘 | `manual_<REGION>_delay<d>_<ds>_ideas.md` + 台账 `s1_<dataset_id>_d<d>`，**`source` 必写 `manual`**（写 `standalone` 会被 GEM 静默忽略） |
| 概念预算 | 一 dataset **≤6 个**（小宇宙区更紧）；每概念 1–2 字段；同一字段至多进 2 个概念 |

⚠ **通用陷阱**：字段名「看起来自解释」≠「在本区可用」。
标准财务词汇命名的字段（如含 eps/revenue/estimate）**仍必须跑 ①**，不许因名字清楚直接组装。

### ②.b 体检体征 → 核心信号形态（查表，不许自由发挥）

**每行都要能指回 ① 的某个读数，指不回的形态不许用。**

| ① 体检读数 | 核心信号形态 |
|---|---|
| 单边恒正 + 有界小量纲 | `ts_delta(F,N)` 变化率（铁律 A） |
| 近正态、连续 | `rank(F)` / `zscore(F)`，无预处理 |
| `zero_inflated` / 事件稀疏 | `trade_when(<事件条件>, <信号>, -1)`，禁裸 rank |
| 季频更新 | 窗口 ≥63d；短窗被 NaN 污染时按季频取 252 |
| cov<0.4 | 必须 `ts_backfill(F,N)` 前置 |
| 覆盖广度型字段 | 同字段多窗 `rank` 乘积（**广度 × 持续性**） |
| 强度型字段 | `ts_delta` 后多窗乘积（**修正幅度 × 修正加速度**） |
| VECTOR | 先 `vec_avg` / `vec_max` 等 `vec_*` 降维 |

### ②.c 壳层按机制选层（**不是四层全上**）

> 每一层是否存在由 A-1 第 4 问决定。**机制上无关 ⇒ 不加壳**（加壳 = 引入非目标暴露，毁 S）。

| 经济机制 | 需要加的壳层 |
|---|---|
| 小市值 / 流动性差，需可投资性 | `vector_neut(·, power(rank(<规模>), pow))` |
| 事件型信号，非事件期不该持仓 | `trade_when(greater(rank(<流动性>), T), ..., -1)` |
| 收益可能只是行业轮动 | `group_neutralize(·, <行业轴>)` + `bucket(rank(<规模>))` |
| 分布有极端尾部、挤权重 | `tail(·, lower, upper, newval)` |
| **机制上与上述无关** | **不加壳** |

⚠ **换粗轴是无损轴，可优先试**：中性化 `subindustry < industry < sector`（sector 易饱和），换粗轴常使 robust 与 S **同升**。
⚠ **别把壳层当信号**：壳层只解决 investability / 行业暴露 / 稀疏持仓；**S 的来源只能是核心信号**。

### ②.d 外部取证（组装前必做，**双通道**）

> **论坛是辅助，不是唯一来源。** 只查论坛 ⇒ 有模板但不知机制是否本区成立；只查论文 ⇒ 机制自洽但可能落不到平台算子上。

**通道 A｜BRAIN 论坛 → 给可落地的表达模板**

| 步骤 | 工具 |
|---|---|
| 搜机制模板 | `search_forum_posts(search_query="<机制关键词> 模板")` |
| 读正文 + 评论 | `read_forum_post(article_id="<id>")`（正文在 `post.body`） |
| 术语 / 算子核对 | `get_glossary_terms`、`get_documentations` / `get_documentation_page(page_id)` |
| 判死取证纪律 | `seal_dead_end` 的 `forum_recon` 闸 fail-closed：**工具故障 ≠ 论坛无解** |

**通道 B｜外部金融研究与论文 → 给机制 + 方向句 + 持有期**

| 步骤 | 工具 | 说明 |
|---|---|---|
| 机制假说与实证 | **`domain_search`** | 一句话高层意图；**把 A-1 五问的答案写进 query** |
| 补充单点事实 | `WebSearch` / `WebFetch` | arXiv / NBER / SSRN / 期刊摘要页，取**摘要 + 结论段** |

⚠ **`domain_search` 昂贵**（远端规划 + 多源检索 + 高延迟）⇒ **每个机制只调一次**；查定义用 `WebSearch` 即可。

**通道 B 的检索纪律**：

| 纪律 | 要求 |
|---|---|
| **只取可证伪的机制** | 必须给**方向句 + 持有期 + 适用域**；只给相关系数不给机制 ⇒ 不采 |
| **警惕文献偏误** | 因子动物园多在特定市场样本；**本区制度 / 宇宙规模可能不同** ⇒ 先当**假说**，不当模板 |
| **不可迁移的结论显式标记** | 论文自带 "US only" / "NYSE" / "large cap" 限定 ⇒ **在概念块写明**，防照搬 |
| **时效性 + 复现状态** | 优先近 5 年；被后续复现推翻的经典异象**不作默认依据** |
| **失败即记录** | 查不到 ≠ 无此机制，**记进战报**（已查渠道 / 检索式 / 结论），避免下波重复空转 |
| **A-2 硬门不因有论文而放宽** | 论文给的是机制，**不是本区证据**；仍须本区实测 |

**双通道裁决（对不上必须裁决，不得跳过）**：

| 情形 | 处置 |
|---|---|
| **A、B 指向同一机制** | ⭐ 优先组装（论坛给表达、论文给方向句与持有期） |
| A 有模板、B 无机制支撑 | 可组装但**降优先级**，标「经验模板，机制未验证」，A-2 从严 |
| **B 有机制、A 无对应表达** | ⭐ **最有价值** —— 按 A-1 五问**自建骨架**，用论文的机制句定形态 |
| **A、B 机制矛盾** | ⛔ 不组装；先查样本差异，**矛盾未解不得进入 ③** |

⚠ **两通道结论都只作起点，必须本区实测** —— 跨族照搬可反向，论文的他区结论同样不保证在本区成立。

**三者分工**：论文给「机制 + 方向句 + 持有期」，论坛给「可落地的表达模板」，
A-3 概念块给「本区的机制定义与落地记录」。冲突时在 `Logical Meaning` 里写清三方差异并注明采信哪个、为什么。

### ②.e 组装硬规则

| 规则 | 要点 |
|---|---|
| **同字段多时间窗 = 单信号结构化** | 合规（不属混信号） |
| **多字段组合只走条件门控** | `add`/`multiply` 相加不同机制字段 = **混信号违规**；`trade_when`/`if_else` 合规 |
| **条件字段须机制正交** | 频段 / 机制不同的字段用 AND 门常双杀；先单测门控收益再上 |
| **组装顺序敏感** | `group_neutralize` 在 `group_rank` **之前**；`tail` 在其后 |
| **乘积的腿要同机制** | 不同机制字段相乘 = 噪声占优 |
| **一字段一条腿** | 跨数据集同机制 = 同一条腿 ⇒ 一条腿只出 1 颗，不铺量 |

**② 的产出（交给 ③）**——三样缺一不许进 ③：
① **表达式**（能指回 ②.b 某一行）② **A-2 收益来源声明** ③ **加了哪几层壳、依据哪条机制**（②.c）。

## ③ 归因（先判类型，再选杠杆）

> 归因不只是第三步的事后复盘，**它同时是发波前置闸**（铁律 F）——不发波就不归因，本节就当它没发生。

| 归因类 | 工具 | 判读 → 处置 |
|---|---|---|
| 时期 | `get_alpha_yearly_stats` | 逐年 S；**S<1.0 年份占比 ≥3 成 ⇒ 2Y 结构性不可达** |
| **单年集中度** | `get_alpha_yearly_stats` 分年 PnL 加总 | top1 年占正收益 >30% ⇒ 过拟合指纹，换机制 |
| **曲线形态** | `get_alpha_pnl`（长序列会降采样） | 阶梯累积 = 健康；尖峰暴涨 = 可疑；**长期停滞段 ≥3 ⇒ regime 依赖** |
| **因子暴露** | `get_alpha_pnl` 的 `investability-constrained-pnl` / RN 列 | 逐年 `因子暴露贡献 = raw 增量 − RN 增量` |
| 行业 / 市值分位 | 导出 PnL | 收益集中少数行业 ⇒ 只是行业轮动；集中于极端市值分位 ⇒ 结构性问题 |

**铁律 E**：报告期塌陷**先做 raw vs RN 分解，再决定修什么**——
RN 增量 ≫ raw 增量（因子贡献为负）⇒ 纯 alpha 没坏 ⇒ **换中性化档**；
raw 与 RN 同步走弱 ⇒ 信号本身衰减 ⇒ 换字段 / 机制族。

⇒ 读数统一落到「发波闭环」的**归因读数 → 发波决策表**（本节不重复该表）。

## ④ 破闸杠杆图谱（每闸一根，单变量对照）

> **主 skills 只给「闸 → 杠杆类型」的通用映射**；**具体杠杆值 / 最优档 / 实测边界一律由 region override 给**
> （杠杆逐字段 / 逐族实测，跨区照搬可反向）。

| 闸 / 症状 | 杠杆类型 | 通用方向 |
|---|---|---|
| 报告期塌陷 | 先 raw vs RN 分解（铁律 E） | RN ≫ raw ⇒ 换中性化档 |
| **中性化档** | **换族必重扫全档**（逐族择优，勿照搬） | 最优档是**结构特异**的 |
| LOW_SHARPE | decay 降 / 加正交腿 | decay↓ 推高 S，同时推高 inv 门槛 |
| LOW_FITNESS | `tail` 收紧 | 纯改善（不牺牲 S 的量级） |
| IS_LADDER（2Y） | decay 调至峰值 | S↔2Y 权衡，峰值档**逐族实测** |
| **IS 推全过** | `group_neutralize(·, <行业轴>)` | 剥行业暴露，综合改善 F 与 2Y |
| INVESTABILITY | vector_neut 幂次调至甜蜜区 | **过高会触发 ladder window 跳变致 2Y 崩** |
| prod | **先判 n 判据**：`[0.7,0.8)` 桶 n≥1 ⇒ 密墙别扫窗口；n=0 才可扫 | 见下 |

**F 公式反推缺口**：`F = S × √(returns / max(TO, 0.125))`
⇒ 先判缺口归属 S / TO / returns 哪一档，再选杠杆。

**中性化档清单**：由 `get_platform_setting_options` 实测，**各区合法档不同，勿照搬别区**。
**默认不盲用单一档**（如 MARKET）——逐族实测择优。

**prod 墙处置顺序**：换族 → 换连续桶分组轴（`bucket(rank(<规模>))`）→ 加 rank 阈值门控（`trade_when(rank(<流动性>)>T)`）。
⚠ **每桶必实测、不可跨族照搬**（同一杠杆在不同族可反向）。

### ④ 的 region 特例位

> 各 region 在 override 中填写：本区合法中性化档清单、本区各闸实测最优杠杆与数值、
> 本区特有的跳变 / 门槛边界。

## ⑤ 算子穷举（顺序 = 先分组轴，再时序平滑，最后幂次）

对照平台算子目录补未试家族。

⚠ **当格局是「IS 全过 + prod 墙」时，族内穷举算子通常无新杠杆 ⇒ 及时止损转下一族。**

**穷举顺序（不可颠倒）**：

1. **分组轴**：`group_rank` / `group_zscore` / `group_neutralize` 的轴（subindustry < industry < sector）
2. **时序平滑**：`ts_mean` / `ts_decay_linear` / `hump` / `ts_backfill`
3. **幂次与形变**：`signed_power` / `tail` / `truncation` / `quantile`

## 通用工程坑（跨 region）

> region 特有工程坑写在各区 override；以下是通用项。

- **发批前三闸**：`ensure_safe_for_dispatch` + 新算子小批验存在性 + 字段 `get_datafields` 实名核对；
  本地库可能含已下架数据集 ⇒ **必跑 `preflight_expressions`**。
- **禁混信号**：多字段组合只走 `trade_when`/`if_else`；`add`/`multiply` 相加不同机制字段 = 违规（同字段多窗口合规）。
- **「已点亮」按数据集级判定**，只排除该数据集；**不要按塔排除**——红的是「已试结构」，不是字段或塔。名单查 `get_submit_ready`。
- **宇宙是单一国家时**（`config.REGION_COUNTRY_SCOPE`）⇒ country 轴中性化 / 分组等于全市场，别用。
- **僵尸批次判据**：`progress` 非空**只是慢，不是僵尸**（会自行 COMPLETE）。
- **`get_user_alphas` 不支持 `order=-sharpe`**（400）；`batch_get_alpha_metrics` 对新建 alpha 可能全返回 null ⇒ 逐个 `get_alpha_details`。
- **平台算子目录可能过期 ⇒ 以实测为准。**

## override 契约（region 侧必读）

各 region 在自身 SKILL.md 的「六步纵深骨架（本区覆盖）」节中，**必须**为每一步给出：

| ② | 本区概念预算、本区特有的组装禁区 | 沿用主 skills 通用值，标注 |

**覆盖规则**：region override **覆盖**主 skills 的同名条目；主 skills 的**铁律与锁定项不可被放宽**。
