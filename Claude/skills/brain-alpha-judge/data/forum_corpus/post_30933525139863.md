前言各位好，我是去年10月 份线下进行培训的那一批的学员，先后经历了3次的Value Factor的更新，分别是0.67——>0.98——>0.99。这个变化完全是出乎自己的意料，诚惶诚恐。因为自己之前没有金融相关的经 验，现在也是当社畜没有很多时间来研究这方面。所以本次的经验分享完全基于自己在这几个月的实践过程中一些心得体会，如果有不对的地方大家可以评论区指正，希望我的完全感觉性的经验能够多多少少帮助到大家。1、最核心的分享——只做Single Data Set Alpha（ATOM）为什么我最开始的Value Factor只提升了一点捏？就是因为第一个月我年轻不懂事，一阶不行就二阶，二阶不行就三阶，三阶还不行就再次嵌套一二三阶，这样子做首先操作符的数量会直线上升，我记得上个季度我的平均ops最开始好像是9点几，其次就是引入了很多别的数据，非常有可能过拟合。最后就是alpha的质量可能非常不稳定，差的可能os就直接爆 Alpha了，我宁愿断粮，那一天就不交了。我个人感觉后面两次的Value Factor更新能有很大的提升最核心的原因可能就是我只交Single Data Set Alpha，这也算是我个人最大的一个特点了。2、个人做Single Data Set Alpha的步骤因为本人对金融方面的知识一窍不通，然后又是社畜的关系平时 的数据集，基本上就是没啥出alpha的机会。第二步：跑一阶：选好数据集后就可以开始一 阶了。一阶的模板我是这样选择的，首先最开始培训的那套代码还是可以选择的，不过可能现在应该要放在那些Value Score稍微高一点，Alpha数量较少的数据集。如果实在是感觉最开始培训那套一阶方法Prod太高了，那就换自己的模板。我的模板是社区的模板分享里推荐的，不过我会拿过来魔改。魔改的方法是只保留最核心的2-3个操作符，然后保留一个数据 字段field的符号（op2（op1（field））大概这样子），后面一阶就是把选定的数据集的数据字段都填充进去遍历回测就行。我个人感觉一阶的模板越简单越好，复杂的模板我也尝试过，但是感觉有点难出货（可能运气不好没有选到合适的）。后面我就自己魔改了，反正魔改的越简单越好，我自己感觉越简单的出货概率越大。不过这个策略仅供参考，不要迷信，还是那种有经济学意义的模板更好。第三步：选取表现较好的一阶alpha&Neutralization：一阶全部都回测完了就开始筛选了，我的筛选的话还是还是先以fitness为准，首先各项指
