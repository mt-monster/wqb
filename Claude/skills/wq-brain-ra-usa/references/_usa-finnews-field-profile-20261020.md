## 1. 字段画像（八问）

### 1.1 字段家族结构

105 条字段 = **3 个极性（positive / negative / neutral）× 7 类统计量 × 5–6 个变体**：

| 统计量族 | 字段前缀 | 含义 | 信号读法 |
|---|---|---|---|
| 均值 | `average_*_sentiment_score_1..5` | 当日该极性新闻的平均语气 | **水平**（Level） |
| 中位数 | `median_*_sentiment_score_1..5` | 中位语气 | 水平稳健版；与均值差 = 日内偏度 |
| 最大值 | `maximum_*_sentiment_score_2..6` | 最强单篇语气 | **尾部强度** |
| 最小值 | `minimum_*_sentiment_score_1..5` | 最弱单篇语气 | 尾部强度（反向） |
| 标准差 | `stddev_*_sentiment_score_*` | 当日文章间语气分歧 | **分歧/不确定性**（Dispersion，HIGH 桶） |
| 95% 置信下界 | `lower_confidence_*_sentiment_*` | 均值估计下界 | 估计不确定性 |
| 95% 置信上界 | `upper_confidence_*_sentiment_*` | 均值估计上界 | 上界 − 下界 = **置信宽度**（篇数少/分歧大） |

### 1.2 覆盖率与使用度

- **覆盖率**：105/105 字段均为 **1.00**（平台口径）。⚠ 覆盖 1.0 ≠ 每日都有新闻；无新闻日的取值形态（NaN / 0 / 前值填充）需在首批回测中通过 turnover 与 NaN 比例间接核验。
- **使用度**：绝大多数字段 `alphaCount = 0`，最高的少数为 8–13（如 `maximum_negative_sentiment_score_6`=8、`average_negative_sentiment_score_3`=13）。**字段级低拥挤**，与 analyst 的拥挤修正族相反。
- **变体 1–6**：同一统计量的不同聚合/来源变体（描述显示 variant 1 为主口径，variant 2 为 GLOBAL D1 口径）。首批先用 **variant 1 均值/中位数**与 **variant 5 标准差**，避免一开始就做变体遍历。
- ⚠ **变体编号不连续，按统计量族各不相同**（2026-10-20 实测踩坑）：`average`/`median`/`stddev`/`confidence` 从 `_1` 起；`maximum`/`minimum` 从 `_2` 起；而 **`stddev_positive_sentiment_score_1` 根本不存在**（positive 族 stddev 只有 `_2.._6`）。批 22 首提因引用该字段导致整批 8 条 `CANCELLED`（一条坏字段连坐整批）。**发批前必须逐字段在 catalog 里核对，不能按族推编号**。

### 1.3 分布与取值特征（先验）

- 三极性分数为 0–1 的极性强度（描述：polarity in [0,1]）；`neutral` 通常占新闻大多数，均值高、方差小。
- `stddev` 非负、右偏；高分歧多出现在「多篇新闻、观点冲突」的股票日。
- 置信界满足 `lower ≤ mean ≤ upper`；宽度 ≈ 2×1.96×stddev/√n，**同时受分歧与篇数影响**，是比 stddev 更接近「估计不确定性」的字段。
- 所有字段与收益无关的文本统计（本集没有 syllable/sentence 等文风字段，那是 `news_sentiment_dl`）。

### 1.4 机制假设（可证伪）

1. **Level（水平）**：净语气（正 − 负）相对自身 252 日基线偏高 → 后续超额收益为正（新闻情绪缓慢定价；若被过度反应则反号）。
2. **Dispersion（分歧）**：当日文章间分歧高 → 不确定性溢价/后续跑输；方向由首批实测裁决。
3. **Change（变化）**：净语气的 22 日变化 → 新闻动量。
4. **Skew（日内偏度）**：均值 − 中位数（正/负极性各自）→ 少数极端文章主导当日语气；与 analyst 偏度族同构，但载体是「新闻文章分布」而非「分析师预测分布」。

## 2. 适用模板

首批统一使用 analyst 战役已验证的「归一 + 内层中性化 + 稳健化」壳，只替换信号核：

```
quantile(group_rank(hump(ts_backfill(winsorize(group_neutralize(SIGNAL, industry), std=4), 252), hump=0.01), subindustry))
```

- `SIGNAL` = `ts_zscore(核心量, 252)`（水平/分歧/偏度）或 `ts_av_diff(核心量, 22)`（变化）。
- 反向候选 = 核内两个极性相减顺序对调；分歧/偏度反向用 `-group_rank(...)`。
- 设置：USA / TOP3000 / D1，neutralization **SUBINDUSTRY**，decay **5**（区域缺省；news 为快信号，后续若 turnover 高再升 decay），truncation 0.08，pasteurization ON，unitHandling VERIFY，nanHandling ON，maxTrade OFF，FASTEXPR。
- ⚠ 与 analyst 的差异：本集没有 `ts_backfill` 之外的慢变量，**decay 不当会同时抬 turnover 与 self/prod**；首批先固定 decay=5，不做参数扫。

### 4.2 归因（不是盲扫：三条指纹各自指向明确的失效点）

**指纹 A：turnover 全部卡在 1.2–1.3%，8 条几乎相同。**
一条日频新闻信号经过 252 日 z-score → 行业中性化 → subindustry 分组百分位后，持仓几乎不换手，说明**截面排序本身在日频上近乎不动**。这不是「壳太慢」这么简单，而是**净语气是一个持续性股票特征（类似质量/风格），不是事件序列**：有的公司常年偏正面报道，排序年复一年稳定。由此：
- 收益幅度被锁死在 1–2%，而 fitness = S×√(returns/max(TO,0.125))，在 TO≪0.125 时 F≈S×√(returns/0.125)。要把 F 抬到 1.0、S 抬到 1.58，returns 必须到 **~5%**（现最好 1.6%，差 3 倍以上）。
- 该量级无法靠壳微调（hump/decay/backfill/分组）补足；杠杆必须来自**信号自身的截面幅度**。

**指纹 B：方向不对称（净语气 0.77 多 vs 0.37 空；偏度 ±0.61 对称）。**
正面语气的**水平**带微弱正漂移，负面语气几乎不贡献——典型的「坏消息即时定价、好消息慢慢渗透」+ 大盘覆盖饱和。⇒ 继续做「负语气做空」或在负面上找信号是低效方向；应把预算集中在**正面语气的创新/事件**上，并显式区分正负两条腿的权重。

**指纹 C：SUB/S 比值 0.54–1.7，SUB 不是墙。**
0.77 对应 SUB 0.57（比值 0.74）、0.61 对应 0.61（1.0）——子宇宙一致性好，说明信号不是靠小票或大票单边。**问题纯粹在幅度**，不在持仓集中或子宇宙。

**结论（本集的第一条可复用判据）**：`finnews_nlp_scores` 的**极性水平**是持久特征，252 日 z-score 壳只能拿到 S<0.8、returns<2%；要验证本集是否有 1.58 潜力，唯一还没被证伪的假设是「**短窗创新（1–5 日）+ 事件门控**」——把信号从持续特征改造成新闻事件响应。若短窗创新仍 <1.0，则本集不适合作 ATOM 主线（字段级 alphaCount 极低也侧面说明历史上少有人在此拿到强信号）。
