### 1.2 类型与可用性

- **全部 MATRIX**（标量，无 VECTOR 聚合问题），取值 **0–100 的 Google 相对热度**，非成交量、非绝对搜索次数 ⇒
  **只有截面/时序相对变化有意义，跨股票的水平不可直接比较**（0–100 是各查询自身归一化的结果）。
- **两条渠道**：公司名（`corporate_name`，cov 0.85–0.90）与股票代码（`equity_symbol`，cov 0.61–0.64）。
  代码渠道覆盖低约 26 pt，但字段 aC 更低（8–20 vs 14–87）⇒ 更少人挖。
- **六个窗口**：1d / 7d / 14d / 28d / 84d / 364d，天然提供「短窗 vs 长窗」的**同源变化量**，
  这是本集最重要的结构特征：可以用同一数据集构造「关注度加速度」而不违反 ATOM。
- **更新频率**：日频（D1），滚动均值平滑度不同；`today` 为点值（噪音最高，aC 33）。
- **缺失**：cov < 1，必须 `ts_backfill`（本批统一 252）；不做 backfill 会因长期 NaN 造成持仓集中
  （`CONCENTRATED_WEIGHT`）——与 news 家族同一纪律。
- **量纲**：0–100 有界，`winsorize(std=4)` 后再 `group_rank`；不要直接进 `divide`（0 值/近 0 分母）。

### 1.3 数据集的 alpha 生态

- 单字段最高 aC 87（7d 公司名），但**代码渠道全部 ≤ 20** ⇒ 白空间在 `equity_symbol` 一侧。
- 平台层面未见该集 dead_end（`get_dead_ends(USA)` 无命中）。

## §2 适用模板与机制

### 2.1 经济机制（可陈述）

1. **零售关注度 → 短期价格压力/反转**（Da, Engelberg & Gao 2011；Barber & Odean 2008 attention）：
   搜索热度上升代表散户注意力涌入，短期推高价格、随后反转；用于日频截面时应取**变化量**而非水平。
2. **关注度加速度**：7d 相对 84d 的抬升 = 注意力边际变化，比水平更接近「新增关注」。
3. **代码 vs 公司名的分歧**：代码搜索更接近交易意图（查 ticker 多为准备下单），公司名搜索更接近新闻/
   信息获取；两者之差是「交易意图强度」的代理。
4. **自身历史归一**：0–100 有界尺度下，`ts_zscore` 把「这家公司自己的搜索常态」除掉，避免大盘股天然高热度。

## §4 归因（批 1 + 批 2）

1. **信号真实且强**：`akVExbg2` 的 S 2.05、2Y 2.19、rns 1.79、TO 20% 全部健康 ⇒ 不是风格 beta，
   也不是慢变量；`leM3KvNe`（反向水平）同样 S1.85 / rns1.83，说明信号来自关注度的**方向**而非幅度。
2. **代码渠道 ≫ 公司名渠道**：同一 7−84 结构，代码 2.05 vs 公司名 1.50；同一 28d 水平，代码 1.31 / 反向 1.85
   vs 公司名 1.31 / 反向 0.45 ⇒ **交易意图（ticker 搜索）才是定价通道**，信息获取（公司名）噪声更大。
3. **全批唯一系统性墙 = LOW_SUB_UNIVERSE_SHARPE**：8/8 全挂 SUB，且 SUB/S 比值集中在 0.17–0.39
   （最优 `akVExbg2` 0.385）⇒ 收益集中在中小盘，**不是构造错误而是容量结构**。
4. **时序慢化毁 2Y**：`ts_rank504` 把 2Y 从 2.19/1.48 压到 0.81，与 pv63/pv103「归一化抹掉信号」先验一致。
5. **水平 vs 变化方向相反**：公司名 −28d 0.45 vs +28d 1.31；代码 −28d 1.85（正向水平更弱）
   ⇒ 同族符号不可假定，必须成对发批（与 USA 六步 override「reverse 必须与原方向成对」一致）。

### 4.2 批 2 归因

1. **SUB/S 是数据集级常数，不是构造缺陷**：八个杠杆把比值锁在 **0.346–0.413**，无一把过 0.43。
   其中 `ts_mean` 平滑（0.373）与 `ts_zscore 504`（0.354）**反而更低** ⇒ 时序归一在本集不是
   「量纲对齐」（与 analyst `e76xgXkM` 0.339→0.556 的成功案例相反），而是把关注度冲击削平。
2. **窗口越短、比值越高**：7d−28d 0.413 > 7d−84d 0.394 > 28d−84d 0.346 ⇒ 收益来自**近期注意力增量**，
   同一条信号在中小盘的反应更强；这是容量结构（小盘搜索热度→交易意图更灵敏），不是参数问题。
   短端已到 7d（日频 1d 点值噪音高、aC 33），没有更短的可信窗口 ⇒ **该自由度的最优已被覆盖**。
3. **分组与外壳无关命运**：subindustry（0.394）≈ industry 基准（0.394）；去 `quantile`（0.391）
   几乎不变 ⇒ SUB 缺口不来自分组或权重映射。
4. **门控是负杠杆**：`trade_when(spread>0, …)` 把 S 从 2.05 打到 0.73、2Y 0.99、rns 0.45 —— 门控削掉了
   主要持仓期（覆盖率 61% 的代码渠道本来只在有搜索时才非零），与 pv103「hump 是载体」同族的
   「条件层不是免费午餐」结论。
5. **最强读数**：`9qE7WOxr` S2.18 / F1.31 / 2Y2.24 / SUB0.90（限 0.94）/ rns1.95 / CLUSTER PASS。
   除 SUB 外全闸通过，且 rns 接近 2 ⇒ **高特异性、非风格**。差 0.04 是**容量闸**，不是信号闸。
