# other571（Wikipedia Viewing Data）字段画像 — USA / TOP3000 / D1

- **as_of**: 2026-10-21
- **数据集**: `other571` · category `other` · pyramid `USA/D1/OTHER`（**未点亮**，multiplier 1）
- **平台规模**: 30 个字段全部 MATRIX；`get_datafields` 返回 28（2 个被平台 sharpe 预筛移除，未列出）
- **拥挤度**: 数据集 alphaCount **335** / userCount 212；单字段最高 alphaCount **80**（`oth571_viewstodaymobile`）
  ⇒ 属 S0 排名里**最低拥挤档**（对照 socialmedia12 的 60341、pv1 的 2191717）
- **选入理由**: 未点亮塔 + 低 α 计数 + 有明确学术机制（Da–Engelberg–Gao 2011 的 ASVI 注意力代理）

## 1. 八问

### ① 字段类型
全部 **MATRIX**（28/28），无 VECTOR ⇒ 不需要 `vec_*` 两段处理，标量算子可直接用。

### ② 覆盖率
| 统计 | 值 |
|---|---|
| min | 0.5377（`views1y` 系 7 个字段） |
| median | 0.5941 |
| max | 0.5973（`views7d` 系 6 个字段） |

全部 < 0.7 ⇒ **必须 `ts_backfill(x, 252)`**（本批统一使用，未用 756：字段本身已是长窗合计，
再叠 3 年回填会把上市新股永久排除）。

### ③ 更新频率
- 5 个窗口族：`viewstoday` / `views7d` / `views14d` / `views28d` / `views84d` / `views1y`。
- ⚠ **滞后不一致（本数据集最大的坑）**：
  - 聚合字段是**滚动窗口合计**，窗口末端有滞后：14d→滞后 14 天、28d→28 天、84d→84 天、1y→364 天；
  - 日内桶字段（`*morning/afternoon/evening/night`）是**单日快照**（"the day 7 days ago"），
    与同名前缀的滚动合计**不是同一量纲**。
  ⇒ 只能把「同窗口的合计」与「同窗口的移动端/桌面端合计」相除；**不要把日内桶除以窗口合计**。
- 交易日频，日更；但最短的有效信息滞后 = 7 天（`viewstoday` 例外，为当日）。

### ④ 分布特征
- 计数型（page views），右偏严重、长尾；跨股票量级差异可达 4–5 个数量级
  ⇒ 一律先 `ts_backfill` 再取**秩或 z-score**，禁止裸用水平值（会退化成"大公司 vs 小公司"）。
- 比值型构造（移动端占比、7d/28d 加速）取值在 (0,1] 或 (0,∞)，适合 `group_rank`。

### ⑤ 可用性
- 覆盖率 0.54–0.60，回填后可用；缺失多为小盘 / 新股。
- 无 VECTOR、无事件类型 ⇒ 无 `divide` 连坐风险。
- 单位：view 计数，`unitHandling=VERIFY` 下比值构造是无量纲的，安全。

### ⑥ 拥挤度（族级）
`oth571_viewstoday` 76 / `viewstodaymobile` 80 / `views7d` 42 —— 都是"最近一周注意力"这一件事，
**同族已有人在用**，但绝对量级低于任何已判死族（institutions 持股、目标价修正都在 1000+）。
风险评级：**中低**。若某条候选 prod ≥ 0.75，按 D0-P 判死，不要再在同字段换壳。

### ⑦ 机制假设（预登记）
| 编号 | 机制 | 文献 | 核心字段 | 方向 |
|---|---|---|---|---|
| **M1** | **异常关注 → 短期反转**（ASVI） | Da, Engelberg & Gao (2011) *J.Finance*：散户关注度升高预示短期负收益 | `views7d` 的时序 z（66 / 252） | 负 |
| **M2** | **关注度动量**（关注度变化的延续） | Barber & Odean (2008)：注意力驱动的买入压力有短期持续性 | `ts_delta(views7d, 22)` | 正（与 M1 反向，用于定向） |
| **M3** | **移动端占比 = 散户强度** | 移动端访问更接近散户/非专业注意力；散户参与度高 → 后续跑输 | `views7dmobile / views7d` | 负 |
| **M4** | **关注度加速**（短窗/中窗） | 信息扩散加速期后的收益衰减（Hong & Stein 1999 渐进扩散的反面） | `views7d / views28d` | 负 |
| **M5** | **当日关注度异常** | 最即时的注意力冲击，滞后最短 | `viewstoday` 的时序 z（66） | 负 |

### ⑧ 使用规则
- 统一壳：`ts_backfill(x, 252)` → （可选 `ts_zscore` / `ts_delta`）→ `group_rank(…, subindustry)`。
- 只用标准窗口：1 / 5 / 22 / 66 / 252 / 504 / 1008 / 1260。
- 比值构造只在**同窗口合计**之间做（7d/7d、7d/28d、28d/84d）。
- 每条主候选配一条反号镜像，用于定向与判断"是信号还是纯风格"。

### 2.1 归因结论（先写后测口径不变）

1. **方向整体反了**：8 条里每条都有精确反号孪生，盈利的一侧**全部是正号 = 关注度动量**（Barber–Odean 2008 注意力买入压力），
   预登记的 M1/M3/M4/M5「异常关注→短期反转」（Da–Engelberg–Gao 2011）在 USA/TOP3000/D1 **全负**。
   镜像后：M1-z66 S 1.31/F 0.69；M1-z252 **1.34/0.79**；M2 1.24/0.63；M3 **1.25/0.80**；M4 1.20/0.57；M5 1.37/0.72。
2. **判死准则核对**：max |S| = **1.37 ≥ 1.0** ⇒ `USA-OTHER571-WEAK` **不触发**，不发该封存；无机制满足「≥2 条且 max|S|<1.0」⇒ 无机制封存。
3. **闸型**：最优两条都只差 **LOW_SHARPE + LOW_FITNESS**（M3 另差 2Y 1.42）。SUB 通过（SUB/S = 0.56 ≥ 0.43）。
4. **`gate_attribution` 判定 = PUSH_TARGETED**（mLyMgpQ6 在线 / rKdO5YVa 闭式复算）：
   - F 闸**不能靠减速达成**：F≥1 所需 TO 天花板 = `TO×(F)²` ⇒ M3 **0.085**、M1z252 **0.110**，均低于 0.125 地板
     ⇒ `need_more_returns_or_sharpe`，唯一通路是**抬 S 或抬 returns**。
   - 闭式耦合：R/TO 不变时 **S→1.58 即 F→1.01（M3，双闸同清）**；M1z252 F→0.93（尚需 R/TO +7%）。
   - 杠杆序（工具输出）：① `quantile` / `signed_power`（保序提 S，代价是 prod 微抬）② `trade_when` 重定时（低代价定向轴）
     ③ 2Y 走**内层 group_neutralize** 或**粗化外层组轴**（subindustry→industry→sector）。
5. **批 2 授权**：符合「1–2 闸不过 ⇒ 先归因再推进」，归因已完成，按 §5.4 走正方向脉冲链，不盲扫。

### 2.2 批 2 设计（10 条，全正方向，单数据集）

**静态闸纠错（2026-10-21，首次派发被 toolkit 静态闸整批拒绝）**：`ts_max` / `ts_min` 在
`platform_constraints.json` 的 `inaccessible_ops` 里——语法合法但**回测 ERROR 并级联整批 CANCELLED**。
论坛骨架里的 `ts_max(bf,5)` 必须换掉。**不换成 `ts_mean`**，改用论坛同一帖记录的**原始形态**

且 `max`（二元）是 live 算子。`quantile` 按 `quantile_arity=1` 只用单参（带 `driver` 会被闸 4 拒）。

**2.3.1 预登记判据核对（四条，逐条）**

1. **无候选 S ≥ 1.58 且 F ≥ 1.0**（批 2 max S 1.08 / max F 0.31）⇒ 不进相关性闸。
2. **脉冲族全部低于 zscore 族 ⇒ 触发，论坛骨架对 other571 不迁移。** 脉冲最好 0.52/0.19（#1），仅为 zscore 腿 #8 的 **51% S / 70% F**；
   5 条脉冲无一超过 0.52，且 bf22→252（#3→#5）与 quantile（#1→#2、#3→#4）只在 ±0.07 内摆动。
   **可复用结论**：DEU/SENTIMENT 的「注意力脉冲链」依赖 VECTOR 字段 + `vector_neut` + `ts_max` 三件套；
   在 MATRIX 计数型、覆盖 0.54–0.60 的 other571 上，把 `ts_max` 换成 `max(x, ts_delay(x,5))` 后整条链的 S 掉到 0.41–0.52，

3. **`group_rank` 不是成本，是强杠杆（论坛结论②在 USA 反向复现）。**
   - M3：`1.25 / 0.80 / TO 0.1343` ⇒ 去 rank 后 `0.72 / 0.19 / 0.3058`（S −42%、F −76%、TO ×2.28），SUB 由 PASS 翻 FAIL；

4. **全数据集 max |S| = 1.37（批 1 M5 镜像）≥ 1.34 且 < 1.58 ⇒ 机制成立、平台线未达；按预登记转「2Y / 组合腿（正交化）」，不磨参数。**

**2.3.2 闭式闸型（决定批 3 只围绕 M3）**

`F = S·√(R/TO)`，在 R 与 TO 不变时 F 与 S 成正比：

| 基准 | S | F | TO | R | S→1.58 时 F | 结论 |
|---|---|---|---|---|---|---|
| **M3（+share，group_rank）** | 1.25 | 0.80 | 0.1343 | 0.055 | **1.01** | **唯一「只抬 S 就能双闸同清」的基准** |
| M5（+viewstoday z66 镜像） | 1.37 | 0.72 | 0.2097 | 0.058 | 0.83 | 还需 R/TO +45%，不可单靠抬 S |
| M1-z252（+zscore 镜像） | 1.34 | 0.79 | 0.1779 | 0.062 | 0.93 | 还需 R/TO +15% |
| M1-z66 + quantile（#9） | 1.08 | 0.28 | 0.4600 | 0.031 | 0.41 | TO 太高，F 结构性不可达 |

两条附带结论：
- **quantile 在本族是 SUB / 2Y 杠杆，不是 S 杠杆**：#8→#9 S +0.06、F +0.01，但 SUB 0.33→0.45（+36%）、2Y 1.48→1.74（+18%，由 FAIL 转 PASS）。
  后续若 M3 结构腿的 SUB 卡线，优先在最终候选上加 `quantile`，不要指望它抬 S。
- **trade_when 重定时是纯效率杠杆**：#10 相比 #8 TO 0.461→0.281（−39%）、S 1.02→0.99、F 0.27→0.31（+15%），

**2.3.3 批 3 设计（10 条，M3 结构正交化；先写后测）**

设计原则：M3 是唯一「抬 26% S 即双清」的基准 ⇒ 全部 10 条以 `share = bf(views7dmobile,252)/bf(views7d,252)` 或其「今日版」为核心，
只改变**结构轴**（分组粗细 / 时序归一 / 凸性 / 与流行度的正交化 / 信息新鲜度），不扫窗口、不扫正负号。

| # | 杠杆 | 机制假设 | 表达式 |

### 5.2 可复用骨架：注意力**脉冲**而非水平（DEU 三代实证）

`read_forum_post("43179860065303")`（LC97552，DEU/SENTIMENT，Sharpe 2.04 / FT 1.92 / 17 项全 PASS，获胜者 `np7nn69l`）： <!-- lint:counterexample: 论坛获胜模板原样引文；ts_max 不可派发、quantile 第二参为非法元数，可派发替代见下方表与 §5.4 -->


**能直接搬到 other571 的部分**（MATRIX 字段，去掉 `vec_avg` / `vector_neut`）：

| 环节 | 算子 | 为什么 |
|---|---|---|
| 覆盖率回填 | `ts_backfill(x, 22)` | 覆盖 0.54–0.60，不回填会 CW（帖内多人与本仓体检硬门一致） |
| 提脉冲 | `max(x, ts_delay(x, 5))` | 取 5 日峰值，抹掉周内周期基线；水平量早被套利。⚠ 原帖写 `ts_max(x,5)`，该算子不可派发（整批 CANCELLED）⇒ 用帖内记录的**原始二点形态**，它实测更强（FT 2.15 vs 1.92，见下方负结果 3） |
| 短平滑 | `ts_mean(峰, 5)` | 压单日野值；帖内实测这是**本线 FT 主杠杆（+0.62）** |
| 自身归一 | `ts_ir(x, 22)` = mean/std | 把「+100 次浏览」翻译成「相对自身历史有多异常」；大公司小公司同尺度 |
| 均匀化 | `quantile(x)` | 压尾部，替代 rank。⚠ 原帖写 `quantile(x, 120)`，但签名是 `quantile(x, driver=gaussian, sigma=1.0)`、**只收 1 个位置参数**（第二参会被元数闸拒）；分布档位靠命名参数 `driver` 选，没有桶数参数 |
| 去规模 | `vector_neut` / 或除以自身长窗基线 | 剥掉「本身高人气公司浏览量系统性偏高」；other571 无独立人气字段，用 `views1y` 当基线代理 |

**四条必须遵守的算子级负结果**（帖内 24 批 184 变体实测，比正结果更省配额）：

1. **`ts_ir` 换 `ts_zscore(x, 252)` 全结构崩盘**（SH −0.33 / FT −0.10）。⚠ 本批 M1/M5 恰好用的 `ts_zscore`，若它们弱而比率腿不弱，根因首先归到**算子不匹配**（稀疏计数型字段右偏长尾，zscore 的均值中心化被巨型突增整体抬升，普通日被压到 0 附近），不是机制无效。
2. **`rank` 包装逐层有害**：三重 neut+全 rank FT 1.34 → 双 neut+rank 1.47 → 双 neut 无 rank 2.12 → 单 neut 无 rank 2.15。每剥一层 +FT ≈ 0.3–0.65。⇒ **脉冲链末端不要套 `group_rank`**，中性化交给平台 SUBINDUSTRY 档；本批全 8 条都套了 `group_rank`，这是本批的结构性风险点。
3. **简化未必划算**：`max(bf, ts_delay(bf,5))` → `ts_max(bf,5)` 省 2 个算子实例，但 FT 2.15→1.92（−0.23）、Margin 26.92→24.21bps。⚠ 且 `ts_max` 平台不可派发 ⇒ 这条"简化"在本区**根本没得选**，二点 `max` 就是唯一可跑形态、恰好也是更强形态。
4. **反向不是镜像**：`-signal` 得到的是一本完全不同的账（帖内 JR57542 实测经验）。突降要用 `ts_min(5)` 走同一链路独立回测，不能对正向取负。⚠ 本批 M1–M5 都是成对正负号，这是**方向探测**（cheap，同批同表达式成本为零），但任何一侧若接近闸线，扩批时必须独立重测而不是取负。
