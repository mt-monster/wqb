### 1.2 分布与更新

| 项 | 结论 |
|---|---|
| 更新频率 | **月度**（月末快照）；日频网格上表现为阶梯常量 + 缺口 ⇒ 必须 `ts_backfill` |
| 覆盖率 | 0.5564–0.5756（主字段 0.5756），折合 TOP3000 约 **1,700 只**有效标的 |
| 覆盖档差异 | `_3` 切面低 1.9pp（0.5564），`_2` 与主字段几乎相同 ⇒ **统一用主字段**，`_2/_3` 不作独立方向 |
| 量纲 | 人数为**计数**（同一发行人各职位相加才有意义）、薪酬为**金额**、声望/资历为**无量纲分数** |
| VECTOR 语义 | 元素 = **该发行人的各职位记录** ⇒ 计数类必须 `vec_sum`（总人数 / 总招聘 / 总薪酬），评分类用 `vec_avg`（加权会放大高人数职位） |
| 缺失机理 | 供应商对中小市值覆盖更低；月度缺报是「未披露」而非「零」⇒ `ts_backfill(252)` 只补时序空洞 |

**与 pv173 的结构差异（决定本批壳形）**：pv173 是平台**已加工**的回归/标准化产物（只宜轻壳），
本集是**原始计数**（供应商只做了职位级聚合）⇒ 允许做比率与差分；但仍**不做长窗二次差分**（月度数据只有 12 obs/年）。

## §2 机制与预注册

### 2.1 十条机制（含文献锚；模板不限于 8 个）

| # | 机制 | 经济陈述 | 构造 | 预期符号 | 文献锚 |
|---|---|---|---|---|---|
| M1 | **净招聘率（水平）** | 高招聘 = 高投资 / 扩张，投资渠道压低预期收益（q 理论）；劳动力调整成本使其滞后 | `−(inflow − outflow) / headcount` | **负** | Belo–Lin–Bazdresch 2014 JFE |
| M2 | **净招聘率 66 日变化** | 招聘**加速**比水平更接近「新增投资冲击」，信息更快被定价 | `−Δ₆₆(net hiring rate)` | 负 | 同上；Bazdresch–Belo–Lin 2018 |
| M3 | **离职率（水平）** | 高离职 = 组织不稳定 / 隐性成本上升；也可能是行业景气（主动跳槽） | `−outflow / headcount` | 负 | 劳动力摩擦文献 |
| M4 | **人均薪酬 252 日增长** | 工资通胀 → 成本压力 → 利润率下修；也代理员工议价力 | `−Δ₂₅₂(salary / headcount)` | 负 | Kuehn–Simutin–Wang 2017 |
| M5 | **人均薪酬水平** | 高薪 = 高技能密度（质量假说，正）vs 高劳动成本（负）——**方向交给数据** | `salary / headcount` | 待定 | 同上 |
| M6 | **员工声望 252 日变化** | 声望上升 = 人才升级 → 未来生产率提升 | `Δ₂₅₂(prestige)` | 正 | 人力资本文献 |
| M7 | **职位资历 252 日迁移** | 资历上移 = 组织升级；也可能是管理层臃肿（负） | `Δ₂₅₂(seniority)` | 待定 | 组织经济学 |
| M8 | **高声望条件下的净招聘率**（条件门控） | 招聘扩张在**人才质量高**的公司里更可能是有效投资；在低声望公司里更像无效扩张 | `trade_when(prestige > ts_mean(prestige,252), M1, 0)` | 负（放大 M1） | **条件腿，不是相加** |
| M9 | **招聘 / 离职不对称** | 毛招聘相对毛离职的强弱 = 净扩张强度，但对分母不敏感 | `inflow / (outflow + 1)` | 正 | — |
| M10 | **M1 × market 分组兜底** | 覆盖 0.57 时 subindustry 组内样本可能偏少，用粗分组检验 SUB 是否被组粒度拖累 | 同 M1，`group_rank(..., market)` | 负 | pv173 §4.5 经验 |

> **纪律自查**：本批 10 条**全部只用 `workforce_flow_skills` 的字段**（ATOM）；`subindustry` / `market` 是平台分组元数据，属豁免项。
> M8 是**条件门控**（同一信号在不同公司状态下的条件暴露），不是 `add A,B`、也不是混合权重调参。

### 2.3 预注册止损（先写死，回测后不得改判据）

1. **10 条全部 |S| < 1.0** ⇒ 判弱封存 `USA-WORKFORCE-WEAK`，不补批（7 个构念即字段全集，剩余自由度只有切面别名 = 同族磨参）。
2. **全部 rns < 0.3** ⇒ 纯风格 beta（规模 / 行业 / 质量），直接封存不再花仿真。
3. 任一 **|S| ∈ [1.25, 1.58)** 且 rns ≥ 0.5 ⇒ Mode A 定向一轮（只动壳，不动机制）。
4. 任一 **RA 全闸通过** ⇒ 立刻 `check_correlation(refresh=True)`；prod ≥ 0.75 按 D0-P 判 `dead_end`，< 0.70 报为可交付候选（**提交仍需用户确认**）。
5. **TO < 5%（LOW_TURNOVER）** ⇒ 只允许两类修法各一次：缩短差分窗口（252→66）/ 降 decay；不得为抬换手改机制。
6. **CW（集中持仓）** ⇒ 先归因覆盖（0.5756），只允许「换分组粒度」与「`group_backfill`」各测一次。
7. 2Y < 1.6 但 S/F 过 ⇒ 参照 analyst 先验，只测一轮短窗（`ts_av_diff` 窗缩半）；月度数据不耐久即判该机制封存。

## §4 归因

### 4.1 预注册规则 #2 被证伪：**这不是风格 beta**

10 条的 `risk_neutralized_sharpe` 全部落在 **1.55–2.13**，连最弱的 M8 也有 1.55。风险中性化后不但没归零，
反而**多数比原始 S 更高**（`6XAKzWnP` 2.03→2.13、`A1QvkXol` 1.94→2.00、`GrgOk2qO` 1.69→1.89）。
这与 pv173（rns ≈ −0.02…−0.58）形成**教科书式对照**：劳动市场流量是**独立的横截面信息源**，不是规模/行业/质量倾斜的伪装。
⇒ 规则 #2 不触发；`USA-WORKFORCE-WEAK` 也不触发（规则 #1 要求 10 条全 |S| < 1.0，实测 7 条 ≥ 1.25）。

### 4.2 哪些形态能活：**"变化"与"人均量"胜过"比率"**

把 10 条按信息形态分四组，存活规律很干净：

| 形态 | 条目 | S | 2Y | 判读 |
|---|---|---:|---:|---|
| **人均量 / 质量分的**变化 | M2 / M4 / M6 / M7 | 1.89–2.30 | 1.59–1.90 | **四条里三条 RA 全过**（M4 只差 SUB 0.78）——信号在"每员工口径的相对变动" |
| 水平（未差分） | M1 / M5 | 1.49 / 1.95 | 1.75 / 1.49 | 净招聘水平能过 2Y 但差 S；薪酬水平 TO 0.0086 撞地板且 2Y 1.49 |
| **比率** | M3 / M9 | 1.54 / 2.03 | **1.28 / 1.22** | 高 S、**2Y 全崩**（<1.3）⇒ 比率形态把近期行情吃了进来，不耐久 |
| 条件门控 | M8 | 1.54 | 1.56 | 比同信号的 M1 更差（rns 1.69→1.55）⇒ 声望门控没带来额外信息，只是削薄了样本 |

**最关键的一条**：M3（离任率）与 M9（流入/流出比）的原始 S 很漂亮（1.54 / 2.03），但 2Y 只有 1.28 / 1.22；
而同族的 M1（净流量水平）2Y 1.75、M2（净流量变化）2Y 1.90。⇒ **2Y 闸在这族上不是"近期运气"检查，
而是形态判别器**：把"存量净变化"换成分母型比率，就把长期成分丢掉了。以后同类劳动力数据先做**净差**再谈比率。

### 4.3 粗分组再次胜出（与 pv173 §4.5 同向）

M10（`market` 分组）对 M1（`subindustry` 分组）是全面净化：S 1.49→**1.69**、2Y 1.75→**1.89**、SUB 0.75→**0.96**、rns 1.69→1.89，
代价只是 TO 0.0337→0.0293。**方向与 pv173 的 `market` 兜底一致**（那边 S 0.26→0.44）。
⇒ 对本类"月度、稀疏、跨行业可比"的字段，**粗分组能救 SUB**，细分组只是把同一个劳动力周期切成行业噪声。

### 4.4 CLUSTER_TEST 是唯一系统性警告（4 条，1.10–1.55 vs 1.58）

4 条 RA 通过的里只有 `akVxompO`(1.50) / `A1QvkXol`(1.23) / `GrgOk2qO`(1.48) 有警告、`omoWVjxk` 无；
警告不是 fail，且 `other` 塔 multiplier 1.4。若后续提交时被 CLUSTER 卡，修法按"加一条正交腿"而不是调 decay
（同族内再平滑只会让聚类更像）。

## §5 决策

1. **本集不判死**：`USA-WORKFORCE-WEAK` **不触发**（7/10 达 S ≥ 1.25，4 条 RA 全闸），这是 2026-10-21 唯一一个
   "IS 侧直接产出多颗候选"的新数据集。
2. **四条 RA 全闸候选已送 prod 实测**（`check_correlation(refresh=True)`）：`akVxompO` / `A1QvkXol` / `omoWVjxk` / `GrgOk2qO`。
   按预注册规则 #4 处置：prod ≥ 0.75 ⇒ D0-P `dead_end`；< 0.70 ⇒ 报为可交付候选（**提交仍需用户确认**）。
   结果见 §5.1。
3. **不再为 M4/M5 补批**（规则 #7 只允许一轮短窗）：M4 只差 SUB 0.78→1.0，M5 撞 TO 地板 —— 两者都是同构念的
   别名切面，已有 4 条候选，再开批等于同族磨参。
4. **可复用结论（三条，进 playbook）**：
   - **rns 高 ≠ 安全，但 rns 低一定危险**：本集 10 条 rns 1.55–2.13，是"劳动市场信息独立于风格"的实证；
     与 pv173 的 rns ≈ 0 对照，**同一套壳下 rns 的符号与量级直接告诉你字段是不是风格 beta**。
   - **2Y 是形态判别器**：净差 / 变化形态 2Y 1.6–1.9，比率形态 2Y 1.2–1.3。先做净差再谈比率。
   - **粗分组救 SUB**：`market` 对 `subindustry` 在 S/2Y/SUB/rns 四项上全胜，代价可忽略（本集与 pv173 两次复现）。
