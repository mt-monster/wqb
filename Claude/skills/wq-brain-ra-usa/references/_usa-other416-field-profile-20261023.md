## 3. 类型与预处理硬约束

- **371/371 全 VECTOR** ⇒ 任何字段进 `rank`/`ts_*`/`group_*` 前必须先 `vec_*` 聚合；
  直接对 VECTOR 套 `ts_backfill` 会整批 `CANCELLED`（`does not support event inputs`）。
- **Aggregation choice**：`vec_avg(x)`（同日多份文件取均值）是本数据集的主口径；
  `vec_sum` 用于计数类（如 `cnt4` 词数）的「当日总量」，`vec_count` 用于「当日文件数」。
- **补值**：CAT 段级字段一律 `ts_backfill(..., 66)`；窗口白名单 `[1,5,22,66,252,504,1008,1260]`。
- **质量闸**：`oth416_valid_mapping` = 1 表示映射可信、0 表示不可信（官方建议忽略）。
  当前未启用；若出现莫名的极值/CW，优先试 `valid_mapping == 1 ? sig : nan`。
- 单位校验（`unitHandling=VERIFY`）：比值类（如 `cnt5/cnt4`）安全；**不要**把无量纲常数加到有单位字段上。

## 4. 机制映射（学术锚 → 字段 → 构造）

| 机制 | 学术锚 | 字段 | 方向 | 备注 |
|---|---|---|---|---|
| **M1 文本变动（Lazy Prices）** | Cohen–Malloy–Nguyen, *Lazy Prices*, JF 2020 | `cat{n}_metric1_*`（同比）/ `metric0_*`（环比） | **高相似度 = 少变动 ⇒ 长期跑赢**；低相似度（大变）后续跑输 | 本数据集唯一能被论文直接机械表达的构造；14 段 × 3 方法 = 42 个同比字段 |
| **M2 语气（tone）** | Tetlock 2007；Loughran–McDonald 2011 | `sentiment1_1`（正）/ `sentiment1_2`（负）/ `sentiment1_0`（词数） | 净语气正向 = 好 | 文档级覆盖 0.84，最安全；3 个模型可做稳健性对照 |
| **M3 可读性/复杂度溢价** | Li, *Annual Report Readability*, JAE 2008；Bushee et al. 2018 | `readability_0..2`、`sentiment2_3/2_4`（复杂度）、`measure_4`（词数） | 越难读 ⇒ 信息越不透明 ⇒ 风险溢价/后续跑输 | 文档级 |
| **M4 量化披露密度** | 无直接论文；机制 = 「用数字说话 vs 用形容词」 | `cat{n}_cnt5 / cat{n}_cnt4`（数字数/词数） | 密度高 = 披露更具体 | 比值构造，无量纲 |
| **M5 主题暴露变化** | LDA 主题（Blei 2003）；事件主题 | `topic_0..19` | **水平项**是慢特征（多半是行业代理，易撞 SUB/中性化废掉）；**变化项**（`ts_delta`）才是事件 | 水平项慎用 |
| **M6 文件结构/事件强度** | 8-K 事件研究 | `doccount`、`measure_0`（句数） | 附件越多 = 事件越实质 | 未测 |

**方向声明（M1）**：论文的多空是「做多 no-change、做空 change」，所以 `+similarity` 是论文方向。
若首波 S 为大负值且其余闸同号反转，说明本数据集年度 8-K 的「变动=坏消息」不成立（8-K 与 10-K 语义不同），
此时应把它当**已证伪**而非「反号可用」（反号=赌变动是好消息，无机制支撑）。

## 7. 归因（逐条，先结论后证据）

1. **M1 方向成立，不是伪影**。#1 +0.77 / #2 +0.92 / #10 +0.81 三个正号；#1 与 #2 只差相似度算法
   （`metric1_0` vs `metric1_1`）却同号 ⇒ 「文本少变动 ⇒ 跑赢」在 8-K/季报语料上复现。
2. **同比强于环比**：#4（YoY）0.98 vs #3（QoQ）0.40。信息半衰期长于一个季度，与 Lazy Prices 的
   12 个月漂移一致。**#3 的 S 0.40 / 2Y 0.03 基本等于无信号**，环比构造可以从后续波次里剔除。
3. **预登记猜反了：热区段反而最强**。CAT12（aC 397）0.98 > CAT0（aC 283）0.77。
   ⇒ 财报主体段的相似度信息量最大，**拥挤度在这个数据集上不是主导变量**。这条要写进选集先验：
   下次别再因为「aC 高」跳过 CAT12/CAT0 去挖 CAT4/5/7/10。
4. **语气是负号，且不能直接反号用**。净语气 −0.58，与「管理层吹捧 / tone inflation」相容，
   但按 §4 预登记的方向纪律，反号必须有独立机制证据，**不把 −1× 当作可用信号直接推进**。
5. **可读性与复杂度互证**：`readability_0` −0.27 与 `−sentiment2_3` −0.32 同号同量级
   ⇒ 「越难读 ⇒ 后续越好」的 obfuscation premium 有一致迹象；但两者都 < 0.35，单独成不了 alpha。
6. **数字密度无效**：0.35，且 SUB −0.22（小市值端反向）。M4 出局。
7. **主题变化是构造坏，不是信号弱**：`ts_delta(topic_4, 66)` 的 longCount = shortCount = 0，
   CW = 0.5（2023-01-26）。topic 是稀疏 LDA 暴露，`vec_avg` 后仍大面积为 0/NaN，delta 后没有有效持仓。
   ⇒ 以后 topic 族只用**水平项 + 长窗平滑**，不用 delta。
8. **预登记风险 #1（低换手 ⇒ F 天花板）实测命中**：RET 3.6%（CAT0）@ TO 5.7% ⇒ F = 0.41，
   与 `F ≤ 0.63·S` 完全吻合。**本数据集要出 F ≥ 1.0，必须同时做到 S ≥ 1.58 且 RET ≥ 4.9%**；
   S 上不去时调 decay / 加门控都救不了 F。
9. **轴族只给 +0.04**（sector→industry：0.77→0.81）。方向对，量级远不够。

**裁决：不判死。** 方向成立、没有构造性失败，只是**单字段单壳的 S 天花板实测 0.98**。
按破闸手册「增益量级排序」，下一波只动**结构**、不动字段。

### 8.2 归因与裁决

1. **预登记判据命中**：10 臂 S ∈ [0.31, 0.99]，**全部 ≤ 1.15**。按 §8 写死的规则，
   本数据集在 **USA/TOP3000/D1 + 单一数据集构造**下不可达 LOW_SHARPE 1.58。两波 20 臂的证据一致。
2. **结构轴只值 +0.01**：波 97 基线 0.98 → 波 98 最佳 0.99（慢均值 × 算法1）。
   `vec_min` 0.98、慢均值 0.87 都没超过基线。**这不是「结构没调对」，是信息量上限**。
3. **四个结构假设里两个反向**：`ts_zscore(504)`（自有史归一）0.34、`ts_delta(mean)`（二阶）0.54。
   与破闸手册「时序归一化常把 S 打崩」一致，本族无例外。
4. **算法排序稳定**：`metric1_0`（0.98/0.91）> `metric1_1`（0.71/0.99）> `metric1_2`（0.53）。
   两波合计看，`_0` 与 `_1` 在不同壳下互有胜负，`_2`（jaccard）稳定最差。
5. **细分轴反向**：`sector→subindustry` 在 `cat12_metric1_0` 上是 0.98→0.91（−0.07）。
   与波 97 的 `cat0`（+0.04）相反 ⇒ 本数据集的轴族不可迁移，只能逐族实测（同 KOR 结论）。
6. **冷段确认无信号**：`cat5` S 0.31、SUB −0.35。波 97 的「热区最强」不是偶然——
   财报主体段（CAT0/12）承载全部信息量，冷段（CAT4/5/7/10）可整体排除。
7. **F 天花板公式再次精确命中**：`WjL3J1go` S0.99 / RET5.12% / TO1.40% →
   `F = 0.99×sqrt(0.0512/0.125) = 0.63`，与实测 0.63 完全一致。
   **本数据集要 F≥1.0，必须在 RET 5% 量级上做到 S≥1.56**；S 不到 1.58 时任何平滑都救不了 F。
8. **2Y 很强但救不了资格**：`pwvx3Y7q` 2Y 1.92、`gJWXLk3e` 1.68、`omoRZ8Vm` 1.57——
   近两年信号明显强于全期，说明信息是**近年加载**的；但 LOW_2Y_SHARPE 只是 RA 闸之一，
   S/F 不过就没有提交资格。

**裁决：停投。** 结构性成因 = 「文本相似度类字段在 USA 的横截面信息量上限 ≈ S1.0」，
不是构造缺陷。未测轴只剩 universe 迁移（TOP1000/TOP500）与 `trade_when` 门控；
按预登记纪律**不再加波**，留作日后若需要低相关补充时的备选。

**区域经验（可复用）**：
- 季报/8-K 文本相似度的换手是**结构性的 1%–7%**，`F ≤ 0.63·S` 恒成立；这类数据集不应按
  「S≥1.58 且 F≥1.0」的常规双闸规划，除非先解决换手（而换手正是它的信号本体）。
- 同一数据集内 `sector` 与 `subindustry` 的优劣**逐族翻转**（cat0 +0.04 / cat12 −0.07），
  不能一次测完就当成该数据集的轴族结论。
