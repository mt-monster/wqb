**VECTOR 处理**：全部字段按「一条帖子/一个平台一项」展开，必须先 `vec_avg` 标量化；`vec_sum` 会让「平台数多的股票」系统性占优，不作首选。
**覆盖**：0.5831 属中低覆盖，`ts_backfill(...,252)` 后可用；`platform_*_score` 覆盖 0.4% 直接剔除。
**更新频率**：日频（论坛帖子），聚合后仍高频；实测 TO 分化明显——情绪分腿 1.25–2.10%，讨论量腿 10.5–11.6%。

## §2 适用模板与机制

| 机制 | 经济陈述 | 构造 | 预期符号 |
|---|---|---|---|
| M1 情绪水平 | 散户情绪是噪声交易者仓位代理；高买入情绪 → 后续反转 | `rank(buy_opinion)` | 负 |
| M2 买卖差 | 净情绪（买−卖）比单边更干净 | `rank(buy − sell)` | 负 |
| M3 讨论热度 | 高关注度 → 短期高估（Da–Engelberg–Gao 2011） | `rank(comment_volume)` | 负 |
| M4 参与者广度 | 参与者越多 = 散户参与越广 → 反转更强 | `rank(participants)` | 负 |
| M5 热度变化 | 讨论量的边际变化才是「注意力冲击」 | `Δ22(comment_volume)` | 负 |
| M6 平台级对照 | 单平台量 vs 跨平台量 = 渠道结构差异 | `rank(volume_per_platform)` | — |

**通用壳**：`quantile(group_rank(winsorize(ts_backfill(vec_avg(<SIG>), 252), std=4), industry))`。
**ATOM 合规**：全部信号来自 equity_forum_data；`industry` 为豁免分组字段。
**文献锚**：Da–Engelberg–Gao (2011) *In Search of Attention*（关注度→短期高估→反转）；Tetlock (2007) 媒体情绪与价格压力。只取机制，不取参数。
**预注册止损**：
1. 8 条全 `|S| < 1.0` ⇒ 判弱封存 `USA-EQUITY-FORUM-DATA-WEAK`，不补批；
2. buy / sell / 价差三条两两差 < 0.10 ⇒ 情绪无方向，只保留一条口径；
3. 任一 `|S| ∈ [1.25,1.58)` 且 rns ≥ 0.5 ⇒ Mode A，**先测 prod**；
4. 任一全闸 ⇒ `check_correlation(refresh=True)`，按 D0-P 判交付。

## §4 归因

1. **预注册止损 1 触发**：8/8 的 `|S| ≤ 0.69`，离 1.58 差 0.89。不是「差一闸」，是构造层失败。
2. **预注册止损 2 触发**：buy 0.66 / sell 0.69 / 价差 0.66，两两差 ≤ 0.03 ⇒ **情绪分没有方向**。注意 sell 分与 buy 分同号且更高 —— 说明两个字段只是同一「论坛热度」成分的正向投影，不是买卖对立面。价差（0.66）没有比任一单边更好，进一步证明无净情绪信息。
3. **`rns` 全部 ≤ 0.40**：0.27–0.40，接近「纯风格 beta」判死线（<0.3 有 4 条）。剥离行业/规模/风格后几乎无特异收益 —— 这与 other567（rns 1.6–1.9）形成鲜明对照：同样的散户数据，论坛数据在 USA 只是小盘/高波代理。
4. **讨论量腿的 2Y 为负**（−0.15 / −0.12 / −0.14）而 Δ22 的 2Y 是 +0.50 —— 唯一的正向时间结构来自「边际变化」，但 S 仍只有 0.68。即 Da–Engelberg–Gao 的「注意力冲击→反转」在水平上不成立，只在变化上留下一点痕迹。
5. **TO 分层**：情绪腿 1.25–2.10%（日频但变化小），讨论量腿 10.5–11.6%。也就是说「说得多的股票」换手高、收益低 —— 典型的噪声交易者拥挤。
6. **覆盖是硬约束**：0.5831 的覆盖率意味着近 42% 的 TOP3000 股票没有论坛数据；`ts_backfill 252` 会把老数据拉进来，但这也让信号更慢、更接近「过去是否被讨论过」而非「今天在讨论什么」。平台级两个情绪字段覆盖仅 0.39%，完全不可用 —— 数据集的可用面实际只有 6/8。
7. **拥挤度低不等于有 alpha**：aC 仅 6、uC 1，是全轮里最冷的数据集之一，但冷的原因是「没人在用」，而不是「没人发现」—— 论坛情绪在 USA 早已被散户数据/社媒数据大量覆盖（同族 sentiment 塔已判死 5 个文本集），本文的结果与那条结论一致。

## §5 决策

- **封存 `USA-EQUITY-FORUM-DATA-WEAK`**（1 批 / 8 条；预注册止损 1+2 同时触发）。
- **不补批**：情绪三口径已证明无方向；讨论量/广度/单平台三口径的 2Y 为负或 Δ 才有微弱正值，没有第五条未测的合理构造。
- **可复用结论**：
  1. **「低 aC + 低 uC」是筛选的必要条件，不是充分条件**；本轮 equity_forum_data（aC 6）、event_relation（aC 29）两个最冷集都是判弱 —— 冷可能只是没人用。
  2. **买入情绪与卖出情绪同号，是「无净方向」的直接证据**（不是反向镜像）。以后遇到成对情绪字段，先看两者是否严格反号：不反号 ⇒ 只是同一热度成分的两个投影，价差无意义。
  3. **论坛/散户数据的 `rns` 普遍 ≤0.4**（本集 0.27–0.40，other567 是例外 1.6–1.9 因为数据源是公司级月度评价而非用户发帖）⇒ 散户发帖类在 USA 基本是风格代理，优先级应排在基本面/分析师/机构类之后。
