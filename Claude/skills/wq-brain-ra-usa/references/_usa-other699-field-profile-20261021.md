### 1.2 分布与更新

| 项 | 结论 |
|---|---|
| 更新频率 | **事件驱动**（供应商按小时 FTP 推送），日频网格上表现为**绝大多数标的有值、单日事件数不等** |
| 覆盖率 | 0.9612（≈2,880 只 / TOP3000）；比 workforce（0.57）高得多 ⇒ `ts_backfill(66)` 足够，无需 252 |
| **事件稀疏性** | 字段有覆盖 ≠ 每天有成交。多数标的在多数交易日 `vec_sum` 为空 ⇒ **短窗（5d）信号极易抖动，这是首个探针 TO 0.2335 的直接来源** |
| 量纲 | 股数为**计数**、时间戳为**编码**、拆股因子为**缩放** ⇒ 只有 ①②③ 可做经济运算 |
| VECTOR 语义 | 元素 = **同一标的在该日的多条用户成交** ⇒ 成交类必须 `vec_sum`（净流量 = 正买 + 负卖），经验类用 `vec_avg` |
| **不可用元素级算子** | 任何 `abs` / `sign` / 逻辑算子直接作用于 VECTOR 会报 `Operator … does not support event inputs`（已实测 `1eWsX4dCD5bk9x35ynb8PGm`）⇒ **一律先 `vec_*` 聚合到标量再运算**，分子分母同除的保护也在标量层做 |

### 1.3 首个探针的字段级教训（决定 §2.2 的壳变更）

探针 `E5VRGAj1` = `quantile(group_rank(winsorize(ts_backfill(-ts_mean(sharestraded/(prevnumofshares+1),5),66),
std=4), subindustry))`，结果 **S 0.34 / F 0.12 / TO 0.2335 / SUB 0 / 2Y 1.00 / rns 0.56 / CW 0.50**。

归因（三条，逐条对到字段）：
1. **`prevnumofshares=0` 的新开仓被 `+1` 放大成天文数字** ⇒ 极值占满尾部 ⇒ `CONCENTRATED_WEIGHT 0.50`（2016-10-28）。
   `winsorize(std=4)` 对「大量同值极值」无效（它不是分位裁剪）。
2. **5 日窗在事件稀疏下等于噪声** ⇒ TO 0.2335（接近上限 0.30）、2Y 1.00。
3. **rns 0.56** 说明残差里还有东西，但被前两条压死 ⇒ 不是"这族没信息"，是**壳错**。

## §2 机制与预注册

### 2.1 十条机制（散户流量文献锚；模板不限于 8 个）

| # | 机制 | 经济陈述 | 构造（SIG） | 预期符号 | 文献锚 |
|---|---|---|---|---|---|
| N1 | **短线净买强度**（壳修复重测） | 散户净买入 = 注意力驱动的需求冲击，月度上反转 | `−ts_mean(NET, 5)` | 负 | Barber–Odean 2008；Boehmer–Jones–Zhang 2021 |
| N2 | **22 日累计净买强度** | 同上但按 22 日累积，压掉事件稀疏抖动 | `−NET22` | 负 | 同上 |
| N3 | **N2 反号变体** | 方向若已被定价，反号应显著 | `+NET22` | 正 | 纪律：每条主候选配对反号 |
| N4 | **净买强度的 66 日变化** | 「买得更凶了」比「买得多」更接近新信息 | `−Δ₆₆(NET22)` | 负 | 形态优先：变化 > 水平（workforce §4.2） |
| N5 | **5d vs 66d 加速度** | 短窗相对自身基线的偏离 = 需求脉冲 | `−ts_av_diff(ts_mean(NET,5), 66)` | 负 | 同上 |
| N6 | **单笔净成交规模** | 平均带符号成交股数 = 单笔信念强度；不依赖仓位分母 | `−ts_mean(sharestraded/vec_count, 5)` | 负 | 无仓位分母 ⇒ 对新开仓免疫 |
| N7 | **散户关注度（成交笔数）** | 成交笔数暴增 = 关注度冲击，随后反转 | `−ts_zscore(ts_sum(vec_count,5), 252)` | 负 | Barber–Odean 注意力假说 |
| N8 | **经验倾斜的净买** | 老练用户的净买入更可能是信息交易 ⇒ 按经验加权后方向应反转（跟随） | `(−NET22) × group_rank(experience)` | 负（对 −NET22 放大） | 条件腿，不是相加 |
| N9 | **关注度条件门控** | 只在成交笔数异常日交易，削掉低关注度噪声 | `trade_when(count > ts_mean(count,66), −ts_mean(NET,5), 0)` | 负 | 事件条件桶 |
| N10 | **N1 + market 分组** | subindustry 组内事件样本可能过少，粗分组检验 SUB | 同 N1，`market` | 负 | pv173 §4.5 / workforce §4.3 |

其中 `NET = sharestraded / (prevnumofshares + 1)`，`NET22 = Σ₂₂(sharestraded) / (Σ₂₂(prevnumofshares) + 1)`。

> **纪律自查**：10 条全部只用 `other699` 字段（ATOM）；`subindustry` / `market` 是平台分组元数据，属豁免。
> N8 是条件门控（同一信号在不同用户构成下的条件暴露），不是 `add A,B`、不是混合权重调参。
> **10 条全部在标量层做除法**，VECTOR 上只出现 `vec_sum` / `vec_count` / `vec_avg`（§1.2 铁律）。

### 2.2 批 1 表达式清单（multisim `bRbODadE4qocdD1dmpPlSiW`，10 条）

**壳（本批统一，已因 §1.3 归因变更）**：
`quantile(group_rank(ts_rank(ts_backfill(<SIG>, 66), 252), <GROUP>))`

`ts_rank(·, 252)` 取代 `winsorize(std=4)` 的理由：① 逐股时序分位 ⇒ **天然有界 [0,1]**，极值不再进尾部
（直接打 CW）；② 自带规模中性化（股数级信号的大市值偏置被逐股消掉）；③ 252 日足够覆盖事件稀疏的缺口。
代价：把信号压成「相对自身历史的强弱」，跨股票的**绝对**强度差异被丢弃 —— 这是刻意的，因为
散户成交股数的绝对量级主要由市值决定，不是信息。

### 2.3 预注册止损（先写死，回测后不得改判据）

1. **10 条全部 |S| < 1.0** ⇒ 判弱封存 `USA-OTHER699-WEAK`，不补批（6 个构念已是字段全集，剩余自由度只有切面别名）。
2. **全部 rns < 0.3** ⇒ 纯风格 beta（规模 / 散户关注度），直接封存。
3. 任一 **|S| ∈ [1.25, 1.58)** 且 rns ≥ 0.5 ⇒ Mode A 定向一轮（只动壳，不动机制）。
4. 任一 **RA 全闸通过** ⇒ 立刻 `check_correlation(refresh=True)`；prod ≥ 0.75 按 D0-P 判 `dead_end`，
   < 0.70 报为可交付候选（**提交仍需用户确认**）。
5. **CW** ⇒ 先查是否仍是仓位分母极值（`prevnumofshares=0`）；只允许「换 `vec_sum` 分母」与「换分组粒度」各一次。
6. **TO > 0.25** ⇒ 只允许加长窗口（5→22）与加 decay 各一次；不为压换手改机制。
7. **2Y < 1.6 但 S/F 过** ⇒ 参照 workforce 先验，只测一轮短窗（`ts_av_diff` 窗缩半）后判该机制封存。

## §4 归因

### 4.1 CW 的根因不是极值，是「事件稀疏日」——M9 的对照组把它钉死了

批 1 里 **9/10 条都挂 `CONCENTRATED_WEIGHT`（value 恒 0.50，日期恒 2016-10-28）**，
包括用 `ts_rank(252)` 做了逐股有界化的那几条。这直接推翻了 §1.3 的第一版归因（"新开仓极值"）：
**有界化压不住它，说明它不是量级问题**。

真正的对照是 `JjPQG8Ke`（N9）：它和 N1 用的是**同一个净买信号**，唯一区别是外面套了
`trade_when(关注度异常, 信号, 0)`，结果 **CW 消失、S 0.50 → 2.07、DD 19.5% → 2.2%**。
⇒ 2016-10-28 这类日期上，**几乎没有标的有有效信号**（散户事件全空），而 `nanHandling=ON` 会把权重
塞进那少数几个还有值的名字里 ⇒ 单票 50% 权重。
`trade_when` 的"触发日才换仓、其余日持有"机制天然消除了这类空日 ⇒ 这是**结构解**，不是参数解。

**可复用结论（第 8 条，进 playbook）**：稀疏事件数据集上，`CONCENTRATED_WEIGHT` 先看**空日**而不是极值；
判据是「同信号加 `trade_when(事件异常, ·, 0)` 后 CW 是否消失」。若消失，就不要再花时间调 winsorize / 换分母。

### 4.2 关注度门控是本集唯一的大杠杆（4× Sharpe）

| 同一净买信号 | S | DD | rns |
|---|---:|---:|---:|
| 无门控（N1 `QPYKG0kM`） | 0.50 | 19.5% | 0.65 |
| 有门控（N9 `JjPQG8Ke`） | **2.07** | **2.2%** | **1.81** |

4 倍 Sharpe、1/9 的回撤、rns 从 0.65 抬到 1.81。经济上说得通：散户净买入的信息只在
**关注度异常日**才被定价（Barber–Odean 注意力假说），平日的净买入是噪声。
⇒ 本集（以及后续任何「事件流水 + 计数字段」的数据集）**默认形态应该是 Event-conditioned，不是裸水平**。

### 4.3 22d 累计把 2Y 抬到 1.96，但抬不动 S

但短线需求冲击的信息被摊薄。这条与 workforce 的「比率形态丢长期成分」互补：
那边是**形态**（比率 vs 净差）决定 2Y，这边是**窗口**决定 2Y。

### 4.6 关键归因：nan ON 多出的 1.5 点 Sharpe 全在「稀疏名」里，而 SUB 恰好不认那一块

把 settings 当单变量隔离后（§3.3），三条读数拼出一张完整的因果图：

| 事实 | 数值 | 含义 |
|---|---|---|
| nan **ON** | S 2.66 / SUB 0.78 / 比值 **0.293** | 高 S 但比值远低于 0.432 |
| nan **OFF** | S **1.17** / SUB 0.51 / 比值 **0.436** | 比值过线，绝对 S 掉 1.5 点 |
| MARKET 中性化（nan ON） | S 2.33 / 比值 0.279 / 2Y **1.13** | 换粗中性化两头不讨好 |

⇒ **`nanHandling=ON` 的 1.5 点 Sharpe 全部来自「当天没有散户事件、但权重仍被加载」的稀疏名**。
次全宇宙（SUB）按流动性挑样本，这些名字本来就不该被大权重持有，所以：
① 在 nan ON 下怎么调窗、换分组、换分母都抬不动比值（§3.2 全族 0.069–0.308）；
② 在 nan OFF 下比值立刻合格（0.436–0.485），代价是绝对 Sharpe 掉到 1.17–1.30；
③ `MARKET` 中性化把 2Y 从 2.15 打到 1.13 —— **SUBINDUSTRY 是 22 日累计成分的持久性来源**，不能换。

**可复用结论（第 9 条，进 playbook）**：当 SUB 卡死而 S 很高时，先做 `nanHandling` 单变量隔离。
若 **关掉 nan 后比值翻过闸线而 S 掉档**，说明「多出来的 Sharpe 是稀疏名贡献的、不可交付」，
此时唯一有意义的修法是**在信号里显式过滤稀疏名**（覆盖率/活跃度门控），而不是继续调窗或换中性化。
判据形态：`nan ON + trade_when(and(事件门, 活跃度门), 信号, not(活跃度门))`，目标是
**逐档逼近 nan OFF 的比值，同时尽量少丢 nan ON 的 S**。

因此「再调一次门」的期望收益是零：K 再大→2Y 更差，K 再小→比值不过线。**这不是参数问题，是人群问题。**

**可复用结论（第 10 条，进 playbook）**：当两个闸分别对「人群 A」和「人群 B」成立时，
**筛人只能把一个闸换成另一个闸**，不能同时过。判据形态：若闸 A 随「限制人群」单调改善、闸 B 单调恶化
（或反之），即判定该数据集存在**人群分裂（population split）**，立即停止在同人群上扫窗 / 扫平滑 / 扫分组
—— 唯一有信息量的下一步是**重建设计让信号在目标人群内自身成立**（改分母、改标准化、换分组作为信号维度而非筛人维度）。

### 4.12 论坛两条 SUB 经验（本轮取证，可复用）

- **「主 Universe 好、Sub-universe 失败」四查**（作者 YX50005，2026-09-27）：① 字段覆盖是否偏向小盘/低流动性；
  ② 收益是否由少数极端权重贡献；③ **经济机制是否只在某类股票成立**；④ 参数是否对 universe 变化过敏。
  排查顺序：覆盖 → 权重 → 市值/流动性分桶 → 最后才改参数。**本集命中第③类**（与 §4.8 / §4.11 H4 判决同一结论）。
- **`hump` 修 SUB**（作者 YW79016）：适用前提是 **TO > 0.05**；低换手信号会被「速度限制器」冻死
  （评论实测 GBR `kqPrzzlK` TO 0.135 → S 1.63→0.2；USA 一条 TO 0.015 → 0.0063 直接触发 `LOW_TURNOVER`）。
  另两条硬约束：① hump 可能**锁死**集中度（CW 反升，因为它把昨日大权重冻结住）；② 必须放在 group 之后
  （`hump(group_op(x, group), hump=…)`），且 NaN 污染型 SUB 失败 hump 救不了（要先 `ts_backfill` / nan ON）。

**结构结论（可复用到后续数据集）**

1. **组内自比（bucket）能解 SUB，不能造收益**：它是把「人群内相对排名」做干净，但组内自比天然抹掉流动性溢价
   ⇒ S 天花板 1.25。**先测 bucket-only 核的 S/F 再谈门控**，顺序反了会误判成「比值问题」。
2. **信号幅度门 ≠ 好选名**：用 `|C22|` 选名把 DD 推 0.03 → 0.195、CW 必挂、SUB 塌到 0.1x。
   选名应该用**截面外生变量**（活跃度 / 流动性 / 交易笔数），不是信号自身幅度。
3. **`else` 常量必须先钉语义**：`else=1`（常数多头）会把被剔除的低活跃人群加回来稀释，制造出
   「K 越大 SUB 越高、2Y 越低」的假单调——§4.8 的「人群分裂」就是这条造成的，§4.14 已更正。
4. **F 换算先行**：F 1.0 @ S 1.58 要求年化收益 ≈ 6.4%（TO 0.16 档）。若某结构的 bucket 核收益只有 2–3%，
