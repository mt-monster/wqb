# USA 闸门与提交纪律

> 本区最贵的一课：**分析师族的墙不在 IS 指标，在 prod**；破墙靠**换中性化**，不是磨算子。
> 全部结论附实测数字；as_of 2026-10-18。

## 一、选集铁律（开工前判定，省掉整轮无效努力）

| 维度 | 硬判据 | 反例（实测判死） |
|---|---|---|
| **频率** | 日更字段直接跳过（TO 结构性爆表）；季频**存量**差分跳过 | `short_interest_pred` 日更 ⇒ TO 0.66 ⇒ fitness 结构性不可达 |
| **形态** | 要**流量/变化率**，不要**存量/水平值** | `institutions18` 季频存量 ⇒ TO 0.037–0.143 达标但 S ≤ 0.92 |

## 二、破 prod 墙：本区最有效的旋钮是 neutralization

| 手段 | 效果（实测） | 备注 |
|---|---|---|
| **`REVERSION_AND_MOMENTUM`** | 同信号 prod 0.70+ → **0.648**；同时 S/SUB 最高档 | 破墙第一杠杆，成本 1 条 sim。⚠ 模型预测分位族反例见下 |
| **`CROWDING`** | 同信号 prod → **0.644–0.676** | 水平背离族有效；**加速度族无效（0.772）** |
| `SECTOR` | 破 fitness / margin（F +0.13、margin ×2.7） | **prod 0.703–0.72 全挂**，别用它破 prod |
| **`STATISTICAL`** | **依数据集类型分叉**：pv/fundamental 水平值族 IS 侧崩（F 0.89 / SUB 0.53 / 2Y 1.02）；**模型预测分位族是阶梯式增益** | 水平值族不适用；模型预测族**首选**（2026-10-23 实测见下） |
| MARKET / INDUSTRY | IS 侧就崩（F 0.89 / SUB 0.53 / 2Y 1.02） | 本区不适用 |
| `hump` | SUB +0.18、TO 减半（**仅水平值/慢信号族**） | **参数不敏感**（0.01–0.05 同效）；但 prod +0.012。⚠ **日频分位共识族上是灾难**：实测 TO 0.2726→**0.0346**（−87%）、S 1.97→0.49、SUB 1.06→0.19 —— 它把逐日信号更新掐成**持仓冻结**，不是平滑（2026-10-23 techindi_model，见下） |
| **表达式内层 `group_neutralize`（放在 `rank()` 之前）** | 论坛 43 条横切实测（GLB/TOPDIV3000/高换手）：PC 0.6875 → **0.4918**（−28%）、SC 0.8233 → **0.3076**（−63%），**同时** S 2.44 → **3.01**、F 0.90 → **1.10**，margin 不动 | 只在 alpha 用**裸 `rank()`** 时是新增杠杆；已用 `group_rank()` 的与外圈等价，实测无增量（见 fnd1 Q5） |

**机理**：RAM/CROWDING 剥掉风格因子（反转动量 / 拥挤度）暴露后，与生产池分析师 alpha 的重叠大幅下降，
且残余信号更纯 ⇒ SUB 同步升高。**一举解开「SUB 要低换手、prod 要高换手」的两难。**

**⚠ 档位好坏依数据集类型而异，不可跨数据集照搬（2026-10-23 实测，techindi_model）**：
同一表达式（7 腿分位共识 q3、decay5、TOP3000/D1）只换中性化，三臂结果：

| neutralization | S | F | TO | 2Y | SUB | DD |
|---|---|---|---|---|---|---|
| **STATISTICAL** | **1.97** | 0.86 | 0.2726 | **3.39** | **1.06** | **0.087** |
| CROWDING | 1.29 | 0.71 | 0.2567 | 1.88 | 0.79 | 0.246 |
| REVERSION_AND_MOMENTUM | 0.88 | 0.38 | 0.2706 | 1.79 | 0.40 | 0.353 |

对照 MARKET 同行 S 1.09 / 2Y 1.73 / SUB 0.70 / DD 0.305。判据：数据集输出**已是模型预测的横截面分位**时，
其收益主要来自排序残差，剥「反转动量」等于剥掉它赖以成立的结构层 ⇒ RAM 垫底；而 STATISTICAL（最接近
平台风险模型口径）直接把风格敞口那部分收益切掉，S/SUB/DD 同步改善——**这类数据集首选 STATISTICAL**。
水平值/原始信号族仍按原表（RAM / CROWDING 优先）。

**⚠ 先测 prod 再磨 F（2026-10-23 同批实测，代价 3 条 sim）**：同一 q3 一日共识核把 F 从 0.86 磨到 0.94
（`ts_decay_linear` 5→10，RET/TO 0.192→0.258）之后才发现该核 **prod 0.7947**（直方图 `[0.7,0.8)` n=6）
⇒ 整个 F 侧工作白做。三条横向结论：

- **`hump` 别用于日频分位共识**：TO 0.2726→0.0346（跌穿 0.125 分母地板）、S 1.97→0.49、SUB 1.06→0.19。
- **`ts_target_tvr_decay` 劣于纯平滑**：它把 TO 钉到 0.167 的同时把 S 打到 1.63（−0.34）、RET −0.71pct，
  F 0.85 < 纯 decay10 的 0.94。压换手伤信号，只在裸 TO 远超目标时才值得试。
- **顺序铁律**：核级（字段/机制）定下来后，**先花 1 次 `check_correlation(refresh=True)` 测 prod**，
  prod 已死 ⇒ 转机制，不进入 F 侧调壳。

**中性化分两类，别混为一谈（2026-10-21 据论坛 43 条样本校正）**：
- **组型**（MARKET / SECTOR / INDUSTRY / SUBINDUSTRY / COUNTRY）＝组内去均值，对已是组内排名的 alpha 近似**保序** ⇒
  论坛实测 7 档切换 PC 钉在 0.745–0.89「几乎不动」。**用它们破 prod 是白花 sim**（本区 `SECTOR` 的 0.703–0.72 全挂也印证）。
- **因子回归型**（`REVERSION_AND_MOMENTUM` / `CROWDING` / `STATISTICAL`）＝真剥风格暴露 ⇒ 才会改写 PC（本区 0.648 / 0.644 是这一类）。
- 想在**组型**这一侧拿到效果，唯一有效写法是把 `group_neutralize` 放进**表达式内层、`rank` 之前**——它是重写截面结构，
  不是在输出端做一次保序投影。

## 三、决策表 D0-P 在本区的落地

```
IS 八闸全过
  ├─ prod 与 self 均低于阈值（见 `PLATFORM_CHECK_LINES`）且 self 未超线  → 稳健性闸（brain-alpha-robustness）→ 用户确认 → 提交
  ├─ prod 0.70–0.75（贴线区间）      → 换 RAM 重跑（当日进步 8）
  ├─ prod ≥ 0.75 或踩线失败    → dead_end，换正交概念（禁止同族磨参数）
  └─ self > 0.7                → 同族互残，查已提交同族（同机制互相关常 0.9+）
```

## 四、提交三条铁律（2026-10-18 实测，两条血泪）

1. **MCP `workflow_submit_alpha` 报 `fetch failed` ≠ 未提交**——实测 POST 已送达、状态在 ~240s 后翻转。
   **fetch failed 后等满 flip 窗口再判；换路径重试前必须复查**（否则 403 重复提交）。
2. **提交即改变相关格局**——新 alpha 同时进 prod 池与 self 池 ⇒ 同族候选 PC/self 暴涨
   （实测 0.696 → 0.978）。**同族必须逐个提交，每提交一个即重测剩余候选**；互残 >0.9 立即放弃。
3. **PC 只向上漂**（生产池单调增长）——早上 0.64 的候选下午可能 0.71。**提交前必须重测。**

## 五、base payment 选型（提交目标是 base payment 时）

论坛 4 帖互证：**高 fitness + 低 PC** 是版本答案；self < 0.3 是 BP > 1.5 的强信号；
**`returns` 只影响 OS 特许权使用费、不影响 BP 档位**；VF 是账号级乘数、同批无差异。

选型链：`F×(1−PC) 粗排 → robustness 近 3 年 Sharpe 均值 ≥ 平台 2Y 线且每年 >0.3 → 提交前 PC 重测 → self 互残检查 → 提交`。

## 六、单数据集同族的硬上限

analyst44 三种机制变体（水平背离 / 加速度 / 秩背离）在 PnL 层高度共线：同机制互相关 **0.98**、
跨机制 0.68–0.94。⇒ **单数据集同族最多提交 2–3 颗**，第 N 颗必被 self 闸顶爆。
要更多提交数必须换数据集或换机制族。

实证数字与候选清单见 [`../references/_usa-mining-playbook-20261018.md`](../references/_usa-mining-playbook-20261018.md) §3。

## 七、prod 可剥离性三问（2026-10-21 新增；卡 prod 时先算，再决定要不要动手）

卡在 prod 且 IS 面已经能交付时，**先判「共享暴露能不能剥离」，再谈修法**。三问按顺序，任一问否决即停：

| # | 问 | 怎么算 | 否决判据 |
|---:|---|---|---|
| **P1 时间集中度** | 最肥的 2 年占多少 PnL？ | `get_alpha_yearly_stats` → 逐年的 pnl 排序 | **最肥 2 年 ≥ 60%** ⇒ 拥挤来自同一段行情；剔除后 S 若 < 1.2，**prod 不可降**（去掉拥挤=去掉交付） |
| **P2 墙是针还是带** | max 之下那一桶有多密？ | `check_correlation` 的 `histogram_nonzero` | **max 下方一桶 n ≥ 100** ⇒ 是「带」，微调（窗口/decay/hump）量级 ±0.05 穿不过去；只有 `[0.7,0.8)` **n = 0** 才适用 `wq-window-valley-break-prod-wall` |
| **P3 是不是风格** | rns 保留率多少？ | `risk_neutralized_sharpe / sharpe` | **保留率 ≥ 60%** ⇒ 不是风格，风格中性化无效（最多动 28–40%，且移不到拥挤处） |

**任一条成立 ⇒ 判 `dead_end`，不许再调算子/窗口/中性化。** 三问都过（集中度 <60%、带很稀、rns 保留率低）
才轮到换 RAM / 降风格暴露这类杠杆。

**战例（2026-10-21，`board_gov_stats`）**：G2 `ZYmKpQ1n` prod 0.8508，P1 = 2021+22 占 **65.4%**（剔除后年均 S 0.87、2Y 塌到 0.98）、
P2 = `[0.7,0.8)` **n=286**、P3 = rns 1.12/1.56 = **72% 保留** ⇒ 三问全否决，封存；
同集 M1 `3qjezndX` 同样 74.4% / n=10271 / 61%。

**反向应用（什么情况值得救）**：若某形态 P1 < 40%（收益跨年均匀）、P2 的 `[0.7,0.8)` n=0、P3 保留率 < 0.4（纯风格），
则它卡 prod 是「风格暴露」而非「同一笔交易」，换中性化/RAM 有真实机会。

## 八、Fitness 墙的算术（2026-10-21 新增；选集与判死都用这一条）

平台口径：`F = S × sqrt(|returns| / max(turnover, 0.125))`。**换手只是分母，收益率才是分子。**

改写成可执行的判据：要让 `F = 1.0`，`|returns| ≥ 0.125 · (1/S)²`。

| 目标 S | 通过 F 闸所需的最低年化收益 |
|---:|---:|
| 1.58 | **5.0%** |
| 2.00 | 3.1% |
| 2.71 | 1.7% |

⇒ **三条硬结论**：
1. **S 1.58 的形态必须做到 ≥5% 年化收益**，否则 F 结构性不可达。查一个集能不能挖之前，先问
   「这套字段有没有可能做出 5% 年化」——比问「S 能到多少」更省仿真。
2. **把换手压到 12.5% 地板只解锁分母，不解锁分子**。若收益本身 <5%，压换手到地板仍不过闸
   （order_flow_imb 实测：`ret 2.88%` / TO 压到地板 → 同 S 下 F 仅 0.50）。
3. **平滑不是通用杠杆**：order_flow_imb 把 `ts_mean 5→22`，S 1.04→0.71、TO 0.212→0.095、**F 反降**
   （收益与换手同向下降）；而论坛 option 集 `ts_decay_linear 120` 却把 F 0.74→1.39。
   差别在信号的时间尺度——**平滑只在「噪声快、信号慢」时提 F，在信号本身就是短周期修正时杀信号**。
   判据：先看平滑后 |returns| 是否守住，守不住就不是噪声问题。

**战例（2026-10-21，`order_flow_imb`）**：`F/S = 0.369`，S 天花板 1.06 ⇒ 需 S 2.71 或收益翻 1.74 倍，
两者都不可得 ⇒ 判 `dead_end`。详见 [`../references/_usa-orderflow-field-profile-20261021.md`](../references/_usa-orderflow-field-profile-20261021.md) §7.2。

## 九、平台门槛按 `delay` 分档：D0 是 2.69 / 1.5，不是 1.58 / 1.0（2026-10-21 实测）

`get_pyramid_alphas` 显示 **USA/D0 全部 14 个类别都是 0 颗 ACTIVE**（塔位全空），容易被读成「空白市场、门槛低」。
**实测相反**：D0 的 RA 闸是 `LOW_SHARPE ≥ 2.69` / `LOW_FITNESS ≥ 1.5`，比 D1 的 1.58 / 1.0 高 **70% / 50%**。

| 证据 | delay | LOW_SHARPE | LOW_FITNESS | LOW_2Y_SHARPE |
|---|---|---|---|---|
| `omoW5QMk` / `kqJgrRzK` / `d5K1Vegx` / `0mjr3nq6`（同日同公式） | **0** | **2.69** | **1.5** | **2.69** |
| 同一公式的 D1 版本 `1Yjzp5mz` / `gJW98zPl` | 1 | 1.58 | 1.0 | 1.58 |

三条落地口径：

1. **D0 探针的验收线先按 2.69 / 1.5 算**，不要按 D1 的 1.58 / 1.0 报「差一点」。差 0.5 Sharpe 在单数据集上限只有 1.33 的族上等于无解。
2. **D0 空塔不是空头支票**：平台用更高线补偿了 delay-0 的信息优势。评估「要不要转 D0」时，先问「这个族在 D1 能否做到 2.69」，
   做不到就不投 —— 这一问能省掉整轮 D0 配额。
3. **`LOW_SUB_UNIVERSE_SHARPE` 的 limit 随主闸等比走**：D0 下 SUB 线 ≈ 2.69 × 0.4367 ≈ 1.17，实测 SUB 1.21–1.39 全过；
   所以 D0 的瓶颈**只在前两项**，不要误判成「SUB 也过不去」。

## 十、prod 存量读数一律作废，只认 `refresh=True`

**铁律**：任何历史台账里的 `prod_correlation` / `self_correlation` 数字**只能用于排序，不能用于放行**；
提交前必须对**这条 alpha 本人**跑一次 `check_correlation(<id>, refresh=True)`。`READY` 状态与 `verified_at`
时间戳**不提供任何保护**——它们记录的是「当时测过」，不是「现在仍如此」。

2026-10-21 实测三条，全部来自 `get_submit_ready(USA)` 的 READY 池：

| alpha | 台账旧值 | 当日 `refresh=True` | 结果 |
|---|---:|---:|---|
| `pw5RbrYX` | 0.5857 | **0.9000** | 拒提 |
| `KPrGMEe1` | 0.6593 | **0.9991** | 拒提 |
| `leKLRA1N`（从未测过） | — | **0.9394** | 同族不可用 |

**机制解释**：prod 池是**生产池**，别人每天在提交同族 alpha；PC 只向上漂。所以「两周前 0.59」
与「今天 0.90」并不矛盾，**漂移本身就是族级饱和的证据**。推论：
1. 一个「低 prod」的历史读数**不能**当成库存资产，只能当成一次观测；
2. 同族已有 ≤ 0.7 的读数、但直方图 `[0.7,0.8)` 桶 n ≥ 1 时，按 D0-P 仍判死；
3. 反过来，`refresh=True` 的读数若**低于**旧值，要怀疑是不是换了 universe / delay / neutralization
   导致对象不可比（PC 不因算子调整而下降，只会因「换了一整套交易」而下降）。
