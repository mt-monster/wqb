# 探针派发 SOP —— 最大化「测出数据集好结果」的概率

> 来源：2026-10-13 DEU 战役 32 波 / 293 条实证。每一条规则背后都有真金白银的反例。
> 目标：用最小预算回答「这个数据集有没有配得上**已验证结构**的机制」，并把误杀率与连坐率压到最低。

## 第 0 步：开批前筛选（零成本，能杀掉大部分无效探针）

1. **语义闸（读字段级 description，不是数据集级）**
   - 数据集级 description 会骗人（`other532` 写「标识符映射」实为 Barra 残差收益）。
   - 元数据/代码/记账指示器直接跳过（实证省掉 2 个数据集：`analyst48` 全是 index 代码；`insider_matrix.director_intensity_score` 描述明写 "timing/bookkeeping indicator"）。
2. **画像闸**（`tools/fields/field_profile.py --query --region <R>`）
   - coverage<0.6 剔除（DEU 占 77.6%）；`to_med<0.03` → DEAD_STATIC；`to_med>0.7` → DEAD_TURNOVER；名字含 `count/num` 且 S≤0.7 → DEAD_COUNT。三类**开批前定论**。
3. **历史闸（最重要的单条规则）**
   - 先查 `output_report/{REGION}_*`、skill `references/*`、`.workbuddy/memory/*`：**有没有已验证结构？禁止自造结构开荒。**
   - 实证：自造 40 条结构全灭（2Y≤1.17）；改用历史 A 级框架后同字段 1.77。**「墙」常在「结构」不在「字段」。**
   - `field_profile` 的 S_sg 是历史最优回测行的读数——先反查那行用的什么结构，直接复用。
4. **概念族分组**：把候选字段按机制族分组（水平量 / 变化率 / 计数 / 比率 / 评级 / 情绪…），**每族选 1–2 个代表**（cov 最高、α 最低）。
   - 依据：同族字段高度相关（eps_y1 ↔ starmine 同机制字段 PnL **0.991**；同字段全结构变体 0.9988+）——**测族内一个 = 测族内全部**；不同族才带新信息。

### 第 0 步的一键工具（区域级潜力扫描，零成本）

```bash
$WQ_PY <skill>/scripts/potential_scan.py --region DEU --out cache/deu_scan.json
```
输出每个数据集的：可用面 `avail` / 概念族数 `fams` / α=0 占比 `zero` / 已测占比 `tested` / 历史最优 `bestS` / **合规单字段最优 `best1field`** / 多腿标记 `maxfields`，并自动分档（★★ 多腿强信号 / ☆ 近失带 / × 低产）。

**★★ 使用铁律**：
1. **必须剔除标签行**——`code` 形如 `R83`/`R102`/`RV+Vk65式` 的是配方引用不是表达式（DEU 占 16%）；不剔除会把它们的 S 误判为「合规过闸」（实测踩坑）。
2. **`maxfields ≥ 2` = 多腿 add = 被禁形态**——其高 S 只说明「字段有信号」，需合规重表达才可提交。
3. **跨数据集核验同腿**：若多个数据集的高 S 行共享同一组字段，则它们是**同一条腿**（DEU 实证：511 条 S≥1.58 行中 66% 含同一「预期变化率」腿，其余为标签）——扫出的「高潜力」不构成新腿。


- **2 个结构 = 本区域已验证的赢家**（DEU：A 级框架 + DEU 核心）。**只测一个结构 = 重蹈 starmine 覆辙**（框架 0.97 会错杀核心 1.81 的字段——「结构最优性」是字段属性，逐字段不同）。
- **4 个字段 = 跨概念族代表**，不是同族 4 个。
- **2 个机动槽**：
  - VECTOR 数据集 → 留给 `vec_max`（DEU 实测 `vec_max` 0.43 > `vec_avg` 0.35，聚合算子是独立搜索维度）；
  - 语义方向不明的字段 → 留给 `reverse`（`rv` 的 reverse 精确 −0.90，方向本身就是信息）。
- 同批混多个数据集允许（字段各自成腿），但**发批前三闸必须逐条过**：
  ① `preflight_expressions`（带 `dataset_id`，否则 VECTOR 检测失效——实证两次整批连坐）；
  ② `op_arity.ensure_safe_for_dispatch`；
  ③ 本地类型闸（VECTOR 必须 `vec_*` 包裹）+ 单位闸（作分组轴的 `bucket(...)` 内层必须 `rank(...)`，实证一条错整批 CANCELLED）。

## 第 2 步：读数三分法

| 双结构最好读数 | 动作 |
|---|---|
| **S≥1.58 且 2Y≥1.58** | 进全闸验证：`get_alpha_details`（全 checks）→ prod/self（直连 API 可用 `cache/verify_alpha.py`）→ **PnL 互相关去重** |
| **S 1.0–1.58** | **不要判死——这是「结构没找对」的信号带**。升级：窗扫描（w1∈{1,5,22}×w2∈{66,120,200,252}）、轴扫描（sector/industry/subindustry/bucket/图聚类轴）、算子微调（quantile/rank/zscore、winsorize、ts_decay_linear 的 d）。实证：npApoGRx 从 1.38 一路推到 1.81（9/10 闸） |
| **S<0.5（双结构都）** | 判死；同族字段免测。判死前自检两问：这批真的用了**两个**结构吗？字段真的**跨概念族**吗？ |

- **2Y 要单独看**：S 高 2Y 低 = 早衰信号（实证：`down_cnt` 反向 S0.90 但 2Y=−0.38，不可用）；判死线对 S 和 2Y 同时适用。

## 第 2.5 步：两条发批纪律（2026-10-14 实证）

1. **字段名绝不可截断后用于构造表达式** —— 打印/列表展示时用 `[:44]` 之类截断，再拿截断名发批 ⇒ 平台报 `unknown variable` ⇒ **连坐整批 CANCELLED**（DEU WANL42 实测，浪费 10 槽）。**构造表达式一律从完整字段名（`/data-fields` 的 `id` 原值或本地库 `field_name`）取。**
2. **发批前必须跑 `preflight_expressions`（带 dataset_id）** —— 它是**唯一**能识别「字段名错误 / VECTOR 未包 vec_* / 字段不在该 region」这类问题的闸；本地 `op_arity` + 类型 + 单位闸**都测不出来**。跳过 = 拿整批赌。

## 第 2.6 步：复审「是否穷尽」的正确判据 = **族级，不是字段级**（2026-10-14 实证）

用户问「字段都穷尽了吗」时，**不要用「已测字段数 / 总字段数」回答**——DEU 实测：高覆盖（cov≥0.6）信号字段 **3,573** 个，只测了 **622（17%）**，但**信号并未遗漏**：

| 归属 | 未测字段 | 结论 |
|---|---|---|
| 已采样族的同概念变体（如 starmine 的 estimate-change 族其它窗口/指标） | ~2,390 | **测之无新信息**（族内 PnL 相关 **0.99**） |
| **真未采样族** | ~520 | **才是应补测的对象** |

**操作流程**：把未测字段按**概念族**归因（族 = 机制相同的字段集合）→ 只补测「族从未出现过的」→ 实测。DEU 实证：6 个真未采样族（analyst7 估计水平/中位/计数、analyst93 预测准确性、analyst44 实际值、model216 ARM 修订分量、fundamental6 报表科目、fund_holdings 微观结构）补测后 **max |S| 0.32 ⇒ 判死**。

**★ 一句话**：**「未测字段 83%」≠「遗漏信号」**；判据是**族覆盖率**，不是字段覆盖率。

## 第 3 步：出闸后去重（一条腿只出 1 颗）
- `GET /alphas/{id}/recordsets/pnl` 取两条 PnL 求 Pearson——**零平台配额**的互相关。
- 同机制跨数据集 = 同一条腿（starmine ↔ analyst 候选 0.991）；换结构/换数据集**不产生新腿**。
- `self` 相关池**包含自己未提交的 alpha**：self max 高先看驱动记录是不是自己建的，再判「被占用」。

## 本会话反例清单（每条都是实测教训）

1. 自造 40 条结构全灭 → 历史 A 级框架同字段 1.77（**先查历史产物**）。
2. 框架测 starmine 10 字段全灭 → 正确结构下同字段 1.81（**双结构必须**）。
3. DEU 核心测 rv 30 条 → 0.90 封顶（**结构不是万能的，字段本身要带信号**）。
4. `bucket` 忘包 `rank` → 整批 CANCELLED；VECTOR 裸进 `ts_*` → 整批 CANCELLED（**发批前本地四闸**）。
5. 台账 dataset 列缺失导致对账时 9 个数据集被误判「未测」（**收割时落全字段**）。
6. `self` 池含自有未提交 alpha，差点把主推候选误判成「被占用」（**看驱动记录再下结论**）。
