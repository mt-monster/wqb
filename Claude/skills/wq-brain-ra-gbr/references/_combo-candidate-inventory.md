## 四、★★ 规律二（最终版）：配角的**硬门槛是 TO，不是「形态差异最大化」**

### ⚠ 本条经W64/W65 两波实测修正（初版表述是错的）

初版据「删外层rank 让 prod 降 0.133」推出「**两腿形态差异越大越正交**」⇒
选了 `fundamental86`（1–10 分位）+ `risk60`（借券拥挤度）+ `news20`（事件情绪）配pv47，
**W64（8 条）+ W65（8 条，加`rank()` 归一重测）全部判死**：

| 主腿 | W64（S / TO / 2Y） | W65 加 rank（S / TO / 2Y） | 根因 |
|---|---|---|---|
| `fnd86_earnings_score` / `_risk_score` | 0.18~0.28 / **0.99** / ≤1.01 | 0.29~0.47 / **0.995~0.9999** / ≤1.01 | **1–10 分位型离散评分：排序后相邻股频繁跨档 ⇒ 天天全体换仓** |
| `rsk60_crowding` | −0.12 / 0.38 / 0.63 | −0.69~0.85 / **0.32~0.38** / ≤1.16 | **慢变状态量**（借券费率/拥挤度） |
| `nws20_multiple_comp_event_sentiment_score` | 0.56 / 0.61 / 1.55 | 0.68 / 0.58 / **2.50 ✓** | 唯一 2Y 过线但 TO 0.58 出界 |

**加 `rank()` 后 TO 完全没降** ⇒ 根因**不是量纲失配**，而是**这两个族的天然 TO 就过高**。

### ✅ 正确的判据（按优先级）

| 优先级 | 判据 | 通过标准 |
|---|---|---|
| **①（硬门槛）** | **单腿水平信号的天然 TO** | **TO < 0.30** |
| **②** | 两腿**量纲可比** | 或都rank / 或都不 rank 且量纲同阶 |
| **③** | 分布**形态差异**（prod 正交性） | 差异越大 prod 越低（同形态 ⇒ prod 偏高） |

⇒ **★ 正确表述：组合两腿要么「同形态」（都 rank / 都不 rank 且量纲相近），
要么用 `rank()` 显式对齐；**绝不能让天然 TO > 0.3 的族进组合**。**

### 配角类型速查（GBR 实测）

| 配角类型 | 天然 TO | 适配 |
|---|---|---|
| **变化量型**（残差收益、情绪分位、涨跌幅累积） | 0.19~0.24 ✅ 可控 | ✅ **可用**（已提交那条就是） |
| **分位型离散评分**（1–10 decile / quintile） | **≈1.0**（排序天天变） | ❌ **不可用** |
| **慢变状态量**（借券费率 / 拥挤度 / 持仓比例） | 0.32~0.38 | ❌ 不可用 |
| 已 rank 化的`*_rank` / `*_percentile` | 0.15~0.25 | ⚠ 可用但**形态同源 ⇒ prod 偏高**，只适合当配角不能当主角 |

> ⚠ 慢变状态量想救只能靠 `ts_target_tvr_decay` TO 定标，

## 七之二、★ 工程铁律：`ts_target_tvr_decay` 三层以上嵌套触发平台元数误报

- **症状**：`ts_target_tvr_decay` 嵌在 `winsorize(signed_power(ts_quantile(...)))` 里
  ⇒ 平台报 **`Invalid number of inputs : 2, should be exactly 1 input(s)`**，
  **整批 8 条全部 ERROR**（W66 + W66b 共 16 条报废）。
- **★ 真因不是语法错、不是字段问题**：W67 用 8 条二分探针证明该算子**单独与双层嵌套都完全正常**：
  ```
  rank(ts_target_tvr_decay(vec_avg(F), lambda_min=0, lambda_max=1, target_tvr=0.13))   ✅ 成功
  ```
  ⇒ 是**三层以上嵌套时平台解析器把 named 参数误计入 input 数**。
- **★ 纪律**：
  1. `ts_target_tvr_decay` **最多嵌 2 层**；需三层时把外层换成 `ts_zscore`，
     或把 `winsorize`/`signed_power` 挪进内层括号。
  2. **发批前必跑括号平衡自检**（`expr.count('(') == expr.count(')')`）——
     W66 就是靠这个发现 3 行各多一个右括号（`std=3.0))`）。

## 八、方法论沉淀（跨区可迁移）

### ★ 五道筛的顺序（不可颠倒）

1. **塔闸**（免费）— 排除已点亮
2. **机制闸**（免费）— 用账本反解机制占用图，排除 ≥2 颗的机制
3. **字段语义闸**（1 次 API）— 逐集读 `get_datafields` 的 **description**，判"能否直接当横截面信号"
4. **cov 闸**（同一次 API）— 只判"能不能回测"，**不当信号判据**
5. **★天然 TO 闸**（1 波仿真）— 组合候选必测单腿水平信号的 TO，**> 0.30 直接跳**

★ **第 5 道是本轮新增的最重要一道筛**：前四道只能筛出"机制白"，
**筛不出"换手可控"**。GBR 实测：四个 A 类候选全部通过前四道，
却在第 5 道全灭（TO 0.32~0.9999）⇒ **省掉后续 16 条仿真**。

★ **第 3 道仍是最容易跳过的一步**：机制白空间只说明"账本里没有这类"，
**不说明"有字段能用"**。GBR 白空间候选 34 个里有 15 个 cov=0、10 个字段全是元数据 ⇒ 真正能进第 5 道的只有 4 个。

### ★ 配角选型口诀（最终版）

**「先看天然 TO，再看量纲可比，最后才看形态差异」**
- TO > 0.30 的族（分位型评分 / 慢变状态量）**直接跳**，形态再正交也没用
- 量纲差 3 倍以上的两腿**不能直接相减**（要用 `rank()` 对齐）
- 同形态 ⇒ prod 偏高但 S/F 干净；形态差异大 ⇒ prod 低但可能量纲失配

### ★ 零字段集是硬出局信号

`get_datafields` 返回 **count=0** ⇒ 该数据集在当前 region/universe 下**完全不可用**，
不必再看 description。GBR 实测 5 个白空间候选是这种情况（socialmedia5 / sentiment33 / news104 / option1 / institutions25）。
