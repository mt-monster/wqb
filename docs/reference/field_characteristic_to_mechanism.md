# 字段特征 → 机制骨架 匹配框架（依据分级版）· 2026-10-07

> **本版核心变化**：每个骨架、每条映射都标注 **依据级别**，并把"实测"与"推断"严格分开。
> 起因：用户质疑「模板是否正确、匹配依据是什么」——审出 **4 处问题**（3 个模板有实体错误 + 1 个我在测试中新犯的 arity 错）。

---

## 〇 依据级别的定义

| 级别 | 含义 | 怎么算 |
|---|---|---|
| **A · 实测正** | 有模拟记录，且为**正**结果（过闸或接近） | 能给出 alpha_id / S 值 |
| **B · 实测负** | 有模拟记录，且为**负**结果（判死） | 能给出 alpha_id / S 值 |
| **C · 推断** | **无模拟记录**，由类比/文献/字段语义推出 | **必须标注"未验证"** |
| **D · 已纠正** | 曾写错，经审计后修正 | 注明错在哪 |

**★ 规则：任何骨架/映射若为 C 级，禁止在决策中与 A 级同等对待。**

## 五 「穷尽」的操作定义（级别 A 的部分）

| 特征 | 必须逐一测的形态 | 级别 |
|---|---|---|
| 有符号 | 水平 · 反号 · 符号门 | 水平=**B** ｜ 反号、符号门=**C** |
| 非负 | 水平 · 时序归一 · 对数 | 水平/时序归一=**B** ｜ 对数=**C** |
| **有历史快照** | **快照差分** | **C（未验证）** |
| 季频/事件 | 事件门 · 极值时点 | **B**（两者均负） |
| **VECTOR** | **7 个聚合算子** | **A**（已完成） |
| 关于别人 | 当门 · 当轴 · 当分母 | 当门=**B** ｜ 当轴=**A**（一直在用）｜ 当分母=**B**（价值收益率） |

**⇒ 这张表现已标明哪些是"已验证的穷尽"，哪些还只是"待验证的清单"。**
