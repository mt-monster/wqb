## 1.3 ★ `ALIVE` 精确含义（容易混淆，必读）

### 定义（代码级）

```python
elif best_s_sg is not None and best_s_sg >= 1.58:   verdict = "ALIVE"
elif best_s_sg is not None and best_s_sg >= 1.10:   verdict = "WEAK"
```

| 要素 | 含义 |
|---|---|
| `best_s_sg` | 该字段全部实测记录里 **单信号（合规形态）的最好 Sharpe** |
| `_sg` 后缀 | **s**in**g**le = 已剔除多腿 `add(A,B)` 污染（多腿是禁形态） |
| `1.58` | 平台 `LOW_SHARPE` 闸门限（**已实测 8 区全为 1.58**：DEU/GLB/IND/USA/KOR/GBR/EUR/ASI，故硬编码安全） |

### 判定阶梯（九类 verdict）

```
ALIVE  S≥1.58  → 同腺 DEU 仅 2 个
WEAK   S≥1.10  → 29 个
DEAD   S<1.10      → 405 个
```

### ★ ★ ★ 关键区分：`ALIVE` ≠ 可提交

| 层级 | 含义 | DEU 例子 |
|---|---|---|
| **字段级 `ALIVE`** | 这个**字段**历史上被测出来 S≥1.58 | `netprofit_y1_estimate_change_3mo` |
| **alpha 级 IS 全过** | 某条**具体表达式**通过全部 IS 闸门（S+2Y+sub+TO） | `A1vv9mmX`（S1.64/2Y1.59，**0 失败项**） |
| **可提交** | 再过 **PROD ≤0.70 且 SELF ≤0.70** | ❌ **DEU 三个候选全卡在 PROD 0.80** |

**⇒ 核心结论：`ALIVE` 是「值得投入」的信号，不是「能提交」的信号。**

**实战验证（DEU）**：2 个 ALIVE 字段 → 做出 3 个 **IS 全过**（`A1vv9mmX` / `QPKKMg6Q` / `j288RaEQ`）→ **三个全部卡在 PROD 0.80~0.807**，**0 可提交**。

### 怎么用（三条路径）

| 用法 | 说明 |
|---|---|
| **① 开批前筛选** | 从 `ALIVE` 池挑字段 —— **省掉「有没有信号」的探测成本** |
| **② 定优先级** | `ALIVE`（过闸）> `WEAK`（有信号但不够，**深挖优先**）> `UNTESTED`（完全未探） |
| **③ 提交前必做** | ALIVE **不代表可提交** ⇒ 必须回测 `prod` + `self` 两端点 |

# ★ 第二部分 · 我怎么用画像判断有无信号

## 2.1 核心原则：**逐级否决漏斗 —— 先否决最便宜的**

画像的价值不是"告诉你有没有信号"，而是**在花仿真之前把大部分候选零成本地否掉**。
我把 7 个判据按**成本从低到高**排列，形成漏斗：

```
┌─ Step 1 区域级（决定投哪个区）
│    判据：ALIVE 数 + 未测池 + 已测密度
│    成本：零（一次 --list）
│    否决权：决定"是否在这个区投入"
│
├─ Step 2 覆盖率闸 ★零成本
│    cov < 0.6 ⇒ UNUSABLE
│    效果：DEU 砍掉 77.6%
│
├─ Step 3 类型闸 ★零成本
│    GROUP ⇒ 只能当轴 ｜ VECTOR ⇒ 须 vec_* 聚合
│    效果：避免整批 CANCELLED（VECTOR 裸用会被秒拒）
│
├─ Step 4 假信号闸 ★零成本（★ 最容易被忽略）
│    ★ 字段名含 *_label_* **不等于无意义** —— 必读 description 再判
│    依据：必须读 fields.description 确认
│    效果：DEU 砍掉 111 个"高 S 假信号"
│
├─ Step 5 换手闸（需外推）
│    <0.03 静态（实测死区）｜>0.70 被闸拒 ｜甜区 0.03~0.10
│    外推优先级：族级 > 数据集级 > 无
│
├─ Step 6 ★ 同族外推（最强 predictor）
│    family IN (有 ALIVE/WEAK 的族) AND verdict='UNTESTED'
│    DEU 实证：族级命中率 66.7%（vs 全区 0.133%，高 500 倍）
│
└─ Step 7 扣除"已否证"与"同腿占用"
     族级否证记录（pattern_scores 40 条全灭等）
     同腿占用（estimate_change 腿被 58gkLAkk 占 ⇒ PROD 会高）
     ⇒ 剩下的才是真候选 → 发探针批
```

## 2.2 ★ 三个必须扣除的「假信号」（DEU 教训）

| 假信号类型 | 识别方式 | DEU 实例 |
|---|---|---|
| **⚠️ 已被推翻的假信号判断** | 我曾按字段名把 `probability_label*` 判为「分位数桶标签，非信号」 | **错**：description 显示它是「未来 N 日**市场中性收益**落入分位桶的 log 概率」，`quantile_label_*bucket_*` 是**连续回归预测值**（且注明 *requires winsorization*）⇒ **是收益预测，不是标签** |
| **计数类陷阱** | 字段名含 `count`/`num` 且 S 低 2Y 高 | `analyst7` 全部计数类（S≤0.7 但 2Y 1.3~1.9） |
| **多腿污染** | 历史高 S 来自 `add(A,B)` 多腿（非合规形态） | `model264` 历史 1.94 全来自多腿；单信号仅 0.74 |

## 2.3 ★ 证据等级（我在使用时对每条判据的信任度）

| 等级 | 判据 | 信任度 | 理由 |
|---|---|---|---|
| **硬**（平台实测） | `coverage` / `ftype` / `to_med` / `S` / `2Y` / `verdict` | **可直接下结论** | 来自平台回测，非推断 |
| **软**（统计外推） | 同族命中率 66.7%｜换手外推｜S×2Y 正相关 | **可用于排序，不可用于定论** | 是相关性不是因果 |
| **假设**（须实测） | 跨区对照 | **只能提出假设** | W199 实证：EUR S2.06 的同名字段在 DEU 只有 0.82 |

**★ 关键纪律**：**任何"软"或"假设"级的判断，在发批前都要用实测验证；不可因为画像数字好看就跳过一整轮。**

## 2.4 画像的三条边界（踩过才知道）

| # | 边界 | 实证 |
|---|---|---|
| 1 | **画像是「存在性证明」不是「复现证明」** | `avg_estimate_...90d` 画像 2Y1.33，同框架实测仅 0.63 |
| 2 | **画像不显示 `sub`** | `eps_y2_estimate_change_3mo` 画像 2Y 真实但 sub 崩到 0.64 |
| 3 | **`n_sg ≤ 3` 只能当下界** | `netprofit_y1_...` 样本 2→57 时 S 从 1.32 升到 1.49 |

## 2.5 实战：DEU 用这套流程走完的六个方向

| 方向 | 用画像筛出什么 | 实测结果 |
|---|---|---|
| 1 | estimate_change 族（104 个字段，族级命中率最高） | S 1.33→1.70，**IS 全过但 PROD 0.80 卡死** |
| 2 | 换机制（信用/排名/评分） | 最高 1.32 |
| 3 | B 类第二腿（anl93/mdl216，非同族） | 最高 1.32，新框架反降 |
| 4 | 修正宽度族（99 个 count 字段） | S1.49 但 2Y 0.99 |
| 5 | 六新机制 + pct 形式 | 最高 0.74 / 1.04 |
| 6 | **候选池甜区 30 个（cov≥0.9 + MATRIX + 数据集换手外推落甜区）** | **最高 1.10 / 2Y −0.04** |

**⇒ 六个方向全部实测否证 ⇒ DEU 结论是"实测穷尽"，不是"推理穷尽"。**

## 2.6 ★ 判断流程的可复用版（任何区都适用）

```bash
PY="/d/coding/traeCN_project/wqb/world-quant-brain-mcp/.venv/Scripts/python.exe"

# Step 1 选区：一眼看全局
$PY tools/fields/field_profile.py --list

# Step 2-4 零成本否决：筛候选（示例：某区 WEAK 池）
$PY tools/fields/field_profile.py --query --region <R> --verdict WEAK
$PY tools/fields/field_profile.py --query --region <R> --verdict UNTESTED --limit 60

# Step 5-6 同族外推：找最值得探的未测池
#   SQL: family IN (SELECT family WHERE region=? AND verdict IN ('ALIVE','WEAK'))
#        AND verdict='UNTESTED' AND coverage>=0.9
# ⚠ 必须带 region 过滤（漏了会虚高 11 倍）

# Step 7 发探针批（10 条/批）+ 收割 + 回填画像 → 循环
$PY tools/data-repair/backfill_deu_from_platform.py --region <R> --stage IS
$PY tools/fields/field_profile.py --build --region <R>
```

**★ 循环的核心**：每批实测都回填画像 ⇒ 下一轮的 Step 6 筛选更准 ⇒ **画像是资产，会复利。**
