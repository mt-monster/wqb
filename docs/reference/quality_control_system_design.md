# 质量改进控制体系设计文档

> 设计日期：2026-09-09
> 设计目标：针对模板、字段、表达式、回测等多个层面产出进行质量把控和诊断
> 核心原则：预防为主、层层拦截、数据驱动、持续改进

---

## 一、体系架构

四层质量把控：
1. 模板质量层：确保模板的经济学逻辑正确、字段匹配合理、构造链完整
2. 字段质量层：确保字段的数据质量、覆盖率、更新频率满足要求
3. 表达式质量层：确保表达式的语法正确、结构合理、多样性达标
4. 回测质量分析层：分析回测结果，识别信号苗头，诊断失败原因

---

## 二、四层质量把控

### 2.1 模板质量层

检查项：
- 经济学逻辑：模板是否有明确的经济学含义
- 字段匹配：模板要求的字段形状是否匹配
- 构造链完整：模板构造链是否完整
- 机制覆盖：模板是否覆盖目标经济学机制
- 历史表现：模板历史回测表现

输出：模板质量评分（0-100）+ 改进建议

### 2.2 字段质量层

检查项：
- 覆盖率：字段覆盖率是否达标（coverage >= 0.6）
- 更新频率：字段更新频率是否匹配 delay
- 数据类型：字段类型是否正确（MATRIX/VECTOR）
- 形状分布：字段形状是否匹配机制要求
- 竞争度：字段 alphaCount 是否过高
- 历史表现：字段历史回测表现

输出：字段质量评分（0-100）+ 可用性标记

### 2.3 表达式质量层

检查项：
- 语法正确：表达式语法是否正确
- 结构合理：表达式结构是否合理
- 多样性：表达式多样性是否达标
- 配额合规：表达式配额是否合规
- 字段重复：字段重复次数是否超限
- 机制匹配：表达式机制是否匹配字段形状

输出：表达式质量评分（0-100）+ 风险标记

### 2.4 回测质量分析层

检查项：
- 达标率：回测达标率是否达标（>= 10%）
- 信号苗头：是否发现信号苗头
- CW 墙：是否触发 CW 墙
- PROD 相关性：PROD 相关性是否超标（> 0.7）
- 机制表现：各机制族表现如何
- 字段表现：各字段表现如何

输出：回测质量报告 + 信号苗头清单 + 失败原因诊断

## 三、质量评分体系

| 评分等级 | 分数范围 | 含义 | 动作 |
|----------|----------|------|------|
| A | 90-100 | 优秀 | 直接通过 |
| B | 80-89 | 良好 | 通过， minor 改进 |
| C | 70-79 | 合格 | 通过，需要改进 |
| D | 60-69 | 不合格 | 拦截， major 改进 |
| F | 0-59 | 失败 | 拦截，重新设计 |

## 四、质量改进控制流程

模板设计 → 模板质量检查 → 字段选择 → 字段质量检查 → 表达式生成 → 表达式质量检查 → 回测执行 → 回测质量分析 → 质量报告

## 五、质量改进建议生成

### 5.1 模板改进建议

| 问题 | 改进建议 |
|------|----------|
| 经济学逻辑不清晰 | 重新设计模板，明确谁在交易、为什么 edge 存在 |
| 字段形状不匹配 | 更换字段或调整模板构造链 |
| 构造链不完整 | 补充缺失的构造链阶段 |
| 历史表现差 | 参考历史表现好的模板，调整机制 |

### 5.2 字段改进建议

| 问题 | 改进建议 |
|------|----------|
| 覆盖率低 | 使用 ts_backfill 回填或更换字段 |
| 更新频率不匹配 | 调整 delay 或更换字段 |
| 竞争度高 | 寻找零竞争字段或换数据集 |
| 历史表现差 | 更换字段或调整预处理 |

### 5.3 表达式改进建议

| 问题 | 改进建议 |
|------|----------|
| 语法错误 | 修复语法错误 |
| 结构不合理 | 调整表达式结构 |
| 多样性不足 | 增加机制多样性 |
| 配额超限 | 调整配额配置或更换表达式 |

### 5.4 回测改进建议

| 问题 | 改进建议 |
|------|----------|
| 达标率低 | 检查模板和字段质量，调整挖掘策略 |
| 无信号苗头 | 更换数据集或调整机制 |
| CW 墙 | 降低线性组合占比，增加事件门控 |
| PROD 相关性超标 | 更换字段组合，增加正交性 |

## 七、持续改进机制

### 7.1 质量数据收集

| 数据 | 收集方式 | 用途 |
|------|----------|------|
| 模板质量数据 | 每次模板质量检查 | 优化模板设计 |
| 字段质量数据 | 每次字段质量检查 | 优化字段选择 |
| 表达式质量数据 | 每次表达式质量检查 | 优化表达式生成 |
| 回测质量数据 | 每次回测质量分析 | 优化挖掘策略 |

### 7.2 质量指标看板

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| 模板质量平均分 | 所有模板质量评分平均 | >= 80 |
| 字段质量平均分 | 所有字段质量评分平均 | >= 75 |
| 表达式质量平均分 | 所有表达式质量评分平均 | >= 85 |
| 回测达标率 | 达标表达式数 / 总表达式数 | >= 15% |
| 信号苗头发现率 | 信号苗头数 / 总表达式数 | >= 20% |

## 八、总结

质量改进控制体系通过四层质量把控（模板/字段/表达式/回测）和持续改进机制，确保挖掘因子流程的质量和效率。

核心价值：
1. 预防为主：在模板设计、字段选择、表达式生成阶段前置拦截质量问题
2. 层层拦截：每个阶段都有质量检查，避免问题传递到下一阶段
3. 数据驱动：基于历史数据和回测结果生成改进建议
4. 持续改进：通过质量数据收集和指标看板，持续优化挖掘策略

预期效果：
- 模板质量提升 20%
- 字段质量提升 15%
- 表达式质量提升 25%
- 回测达标率提升 30%
- 信号苗头发现率提升 40%
