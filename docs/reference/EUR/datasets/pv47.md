This dataset provides daily specific returns for global equities, calculated using a proprietary risk model that extends the Barra framework with additional style and industry factors. The data includes returns orthogonal to risk model factors, representing the idiosyncratic or residual component of asset performance. Coverage spans multiple regions and universes, with fields such as Bloomberg ID and specific return percentage. By decomposing total returns into factor-driven and residual parts, this dataset enables researchers and portfolio managers to isolate stock-specific movements, assess alpha generation, and improve risk-adjusted forecasting of price changes.
