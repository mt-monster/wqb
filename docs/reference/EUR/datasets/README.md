- **语义族**：按字段名 + 描述关键词自动归类（10 族 + 其他），用于快速定位可做尽的维度
- **更新频率**：由描述关键词与字段类型推断（VECTOR=事件/逐笔；MATRIX=快照）
- **可用性评级**：基于平均覆盖率（≥90% 优 / 70–90% 良 / 50–70% 中 / <50% 低）
- **覆盖分档**：高 ≥0.90｜中 0.70–0.90｜低 0.50–0.70｜稀疏 <0.50
