# GBR NEWS 模板总结（速查版）

> 一句话：**GBR 的 NEWS 不是 10 个模板，是 5 条信息轴 + 1 套强几何 + 8 条结构性教训**。
> 跨区复用时带走的不是表达式，是「语义槽位 + 强几何 + 换档纪律」。

## 1. 强几何（唯一固定的部分）

```
G(SIG) = ts_target_tvr_decay(
           group_neutralize(
             -ts_rank(ts_mean(SIG, 60), 252),
             densify(market)),
           target_tvr=0.05, lambda_max=5, lambda_min=0)
```

GBR 档：`GBR/TOP700/D1/FAST/decay15/trunc0.05/VERIFY/nanHandling ON/maxTrade OFF/pasteurization ON`
**只有 SIG 的结构不同** ⇒ 归因干净，且不存在「换窗口当模板」的伪多样性。

## 2. 五条独立轴（NEWS 塔容量上限 = 5）

| 轴 | 语义 | GBR 代表 |
|---|---|---|
| A | 新闻到达率（level/偏离/×广度/跨集门控） | `wpQwjWn6` |
| B | news18 `sse` 事件级情绪强度 | `6XdPedNJ` |
| C | 事件强度求和 `vec_sum(event_relevance)` | `leA6jmoe` |
| D | 情绪分到达率 `vec_count(event_sentiment_score)` | `9qxPX77V` |
| E | 合成置信 `ssc × 新颖度` | `58E7jkaN` |

**换轴只有两条路**：换语义不同字段 / 换数据集。**换结构救不了相关性**（S4↔P1 同字段 0.8346；X1 跨集门控↔W3 0.8294）。

## 3. 八条结构性教训（跨区直接照搬）

| # | 教训 | 证据 |
|---|---|---|
| L1 | 相关性的载体 = **字段的信息轴**，不是结构、不是来源数量 | 同字段不同结构 0.8346 |
| L2 | **强几何 vs 弱几何差 2 倍**：同字段弱几何 S 上限 0.91 → 强几何 1.86–2.18 | news18 N1–N10 全灭 → 强几何两条全闸 |
| L3 | `vec_count` 对**完全填充的同事件字段**是恒等变换 | nip↔relevance 相关 **1.0000** |
| L4 | 量纲恒等要提前排：`winsorize∘ts_rank`、`ts_zscore` 前置 | S6/S8 撤回派发 |
| L5 | 二阶矩几何（自相关/残差/回归）在「到达率」字段上无信息 | S7 S 0.11、S9 残差恒 0 |
| L6 | **同一字段当乘子有效、当信号本体无效** | `event_similarity_days`：乘子→S1.85 全闸；本体→S **−0.33** |
| L7 | 掩码类模板双杀（TO↑ + 广度↓ ⇒ F 崩） | S2 F 0.78 |
| L8 | **裸 `rank(sentiment)` 禁用**；水平类走慢平滑，变化类配衰减 | forum `42659817284375` |

## 4. 平台侧纪律（迁移时照搬）

1. 换手超标先归因三分类（数据源翻转 / 构造放大噪声 / 权重集中）；`decay` 平滑不了排名翻转。
2. `target_tvr` 须与信号**自然换手同量级**（0.7–1.2×）；压到 1/8 ⇒ S 1.81→0.04。
3. `ts_mean(·,5)` 是新闻字段的**必选前置**。
4. prod 是唯一真瓶颈；闸是降 prod 的唯一有效手段；设置类杠杆对 prod 的极限收益约 0.06。
5. 浅钉（n=1, [0.7,0.8)）不判死；破墙首选 **同信号几何换面**（quantile↔zscore↔rank），窗口位移对 n=1 无效。

## 5. 跨区迁移三查（详见语义映射表）

- [ ] universe 用目标区 `config.py` 的 `default_universe`（否则 `get_datasets` 静默返回空）
- [ ] 字段 **description** 语义对齐槽位（不是字段名相似）；同源镜像字段对（X vs X_storyid）禁做差
- [ ] 目标区既有死路（`tracking/<R>/config/cells.json`）+ 严闸（CHN LOW_SHARPE **2.07**）
- [ ] 首波必须 **2×N 因子 A/B（设置档 × 壳）**；单档低 S 不构成判死依据
- [ ] **先换档再换结构**（CHN 实测：FAST 档放大 0.36–0.90）

## 5b. ★ 中性化族隔离（跨区迁移必做，CHN 实测四读数）

**规则**：设置项之间有交互，**不能把「S 的差」归因给单方**。换区第一波必须做**单因子隔离**——每格只动一项：

| 格 | 变动 | 目的 |
|---|---|---|
| 1 | 基准（目标区既有档） | 复现锚点 |
| 2 | 去壳 | 壳是否拖累 |
| 3 | 去 group_neutralize | 分组轴是否拖累 |
| 4 | 中性化 → FAST（因子型） | **因子型是否毒档** |
| 5 | 中性化 → STATISTICAL / SLOW | 同族复核 |
| 6 | 中性化 → MARKET / SECTOR（分组型） | 分组型对照 |
| 7 | decay 4→22 | decay 档是否拖累 |
| 8 | target_tvr 0.05→0.15 | 壳的目标换手是否压过头 |

**CHN 实测结果（同一 SIG，只换 neutralization）**：

| neutralization | 族 | S |
|---|---|---:|
| SUBINDUSTRY | 分组型 | **+0.18** |
| MARKET | 分组型 | +0.08 |
| FAST | 因子型 | **−0.67** |
| STATISTICAL | 因子型 | −0.74 |
| SLOW | 因子型 | −0.76 |

⇒ **因子型中性化（FAST/STATISTICAL/SLOW/CROWDING/SLOW_AND_FAST）在 CHN 制造系统性负漂**，
而 **GBR 出货档恰是 FAST** ⇒ **设置档高度区域特异，源区出货档不可跨区照抄**。

**机理**：因子型中性化剥离风格/因子暴露；「事件到达率」类信号**本身就是因子暴露**，剥离后留下与原信号**反向**的残差 ⇒ 负漂。分组型只减组均值，不翻转符号。

## 5c. 正负两极必须成对（伪影 vs 真信号）

- **真信号**：S_pos ≈ −S_neg（符号相反、|S| 接近）。
- **伪影**：两极**同号**（尤其同负）⇒ 不是「方向反了」，是成本/结构拖累（CHN 台账 `CHN-PV27` 同款判词）。
- 单看一条负 S **无法区分**这两者 ⇒ 任何「负 Sharpe 想翻正」的开波，先成对跑正负两极。
- 判成本伪影的第二判据：`returns` 与 `margin` 是否同号（同负 = 真实负暴露/真实拖累；margin 负而 returns 正 = 纯成本）。

## 0. ★ 本轮跨区迁移实测所得的四条「不要踩」铁律（2026-11-03，80+ 条回测）

| # | 铁律 | 实证代价 |
|---|---|---|
| 1 | **源区出货设置档不可跨区照抄** | GBR 出货档 FAST+decay15+壳 在 GBR 全绿，搬到 CHN 全负（因子型中性化负漂 −0.67…−0.76） |

| 3 | **跨区后必须重扫窗口，且窗口往往比轴更能决定强度** | HKG 同轴同档：120/504→0.10、60/252→0.27、**22/66→0.64**（单调 2.4×）；换轴反而更差（0.11） |
| 4 | **数据集质量分不预测可挖性** | CHN news46 是全平台评分最高（cov 1.0 / aC 7 / vs 6），却是三区里最弱的（最优档 +0.18） |

```

  → 单因子隔离波（找毒档） → 双极波（判真伪） → 窗口阶梯波（最高性价比增益）
  → 换轴波（优先用目标区独有的新结构） → 终验四审 → 回写台账
```
