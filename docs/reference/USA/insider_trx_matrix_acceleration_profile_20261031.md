## 0. 为什么这份文档重要

本会话前 21 波对 `insider_trx_matrix` 的挖掘全部集中在三种骨架上：

| 骨架 | 代表表达式 | S 天花板 |
|---|---|---|
| 水平累加 | `ts_zscore(ts_sum(total_buy_transaction_count, W), 252)` | 3.42 |
| 截面比 | `group_rank(...)` / `tail(winsorize(group_rank(...)))` | 2.73（但可过全闸） |
| 差值失衡 | `ts_zscore(subtract(ts_sum(buy), ts_sum(sell)), 252)` | 1.63 |

**模板池系统性缺了「时间一阶差分」这一维。** wave286 从全库历史记录（`mcp-20261030` 波次）里翻到一条被漏掉的记录后，这个维度被补上，**S 天花板从 3.42 直接抬到 5.36**，并在 wave288 拿到首颗 fRA=0 全闸候选。

## 1. 骨架定义与第一性原理

```
加速度 = ts_zscore( subtract( ts_mean(X, Ws), ts_mean(X, Wl) ), Wz )
```

| 部件 | 作用 | 机理 |
|---|---|---|
| `ts_mean(X, Ws)` | 短期强度 | 窗口内事件密度 / 平均强度 |
| `ts_mean(X, Wl)` | 长期基线 | 该股自身的历史常态 |
| `subtract` | **同公司两条均值相减** | ★ **公司规模在相减中被约掉** ⇒ 得到无量纲的「行为突变度」 |
| `ts_zscore(·, Wz)` | 二次自基准化 | 让「突变」相对自身 252 日历史分布说话 ⇒ 双重自基准化 |

**为什么比 `ts_sum` 强一个量级**：
- `ts_sum(x, W)` 测的是**强度水平**，必然含公司规模暴露 ⇒ 换手高（17–55%）、S 上不去
- 加速度骨架测的是**相对自身基线的偏离**，规模被约掉 ⇒ 无量纲、跨股票可比、可做截面排序

⇒ **任何序数化 / 缩尾 / 截面化都会毁掉这个骨架**。

## 6. ★★★ 平台闸门机理（本波最重要的一条）

**`LOW_SUB_UNIVERSE_SHARPE` 的闸线 = 0.435 × S**（实测自 `checks.fail[].limit`，不是固定值）。

⇒ **提 S 会同步抬高闸线**，所以「把 S 从 1.15 推到 1.58」对 SUB 是**负作用**。

破 SUB 只有两条路：
- **(a) 提高 SUB/S 比** ⇒ 换表达式（高管子集 + mean 口径 + 22/126 窗口）
- **(b) 主动把 S 压到刚好够线** ⇒ decay ↑ / 换中性化轴（实测这是破最后 0.04 缺口的实际手段）

**USA/D1 平台闸线速查**：
`LOW_SHARPE` 1.58 / `LOW_FITNESS` 1.0 / `LOW_2Y_SHARPE` 1.58 / `LOW_SUB_UNIVERSE_SHARPE` **0.435×S** / `HIGH_TURNOVER` 0.7 / `CONCENTRATED_WEIGHT` 0.1

## 9. 横向复用指引（★ 跨数据集迁移）

加速度骨架是**字段无关**的 —— 只要字段是「某类事件强度随时间变化」的量就能套。已确认可迁移的路径：

| 目标数据集 | 字段 | 状态 |
|---|---|---|
| `insider_feats`（OTHER 塔，118 字段，USA 零回测） | `buy_sell_ratio_all_{5d,20d,60d,250d}_filled`、`buy_sell_tx_count_ratio_all_*_filled` | wave289 在跑 |
| `insider_matrix`（OTHER 塔，已有 3 颗四绿） | `eur_aggregated_value_1/2`、`eur_signal_value_1`、`eur_top_value_1`、`eur_director_value_1` | wave289 在跑 |
| `insider_agg_matrix`（INSIDERS 塔） | — | ⚠️ 已判死（26 条全灭，最高 S 0.96） |
| `insiders1`（INSIDERS 塔） | — | ⚠️ 已判死（38 条全灭，最高 S 1.17） |

**迁移时的三条纪律**：
1. **单数据集**（不跨集）⇒ 塔位纯净
2. **mean 口径优先于 total 口径**（规模更干净 + 覆盖更宽 ⇒ 不触发 CW）
3. **窗口用 22/126 或 22/252**（SUB/S 最优区），**别用 5/66**（S 高但 SUB/S 低）
