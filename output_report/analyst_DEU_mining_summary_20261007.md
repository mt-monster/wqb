**最好 S 0.68**（未过 0.7 闸）。形态完全合规（同数据集、同指标、同窗口、互补），但**无信号**。

**最好 S 0.78。** 机制上与"变化率"不同（幅度是流量、非标准化），确实不同源。

### ❌ 族 D「分歧度收敛」（最大类，17 个字段）

`*_{skewness, asymmetry, coeff_var}`（eps / netprofit / revenue × 多期限）。
构造：**取"变化"**（`subtract(ts_mean(22), ts_mean(252))`）—— 依据论坛《分析师预测分歧度：从一致预期的收敛中寻找 Alpha》。

**⇒ 这是最有说服力的一次否证**：机制选择有研报依据、字段是该数据集最大的一类（17/49），**依然全灭**。

### ❌ 族 E「水平偏离」

`*_consensus_value`（6 个）。构造 `ts_av_diff(bf, 252)`。
**最好 S < 0。**

### ❌ 族 F「计数 / 事件类」

## 三、成功路径的完整复盘（`eps_y1_estimate_change_3mo`）

这一颗经历了 **5 轮迭代**，是本会话最有教育意义的案例：

| 轮次 | 动作 | 结果 |
|---|---|---|
| W100 | 重框架（3 轴） | S1.37 / 2Y1.34 |
| W104 | 桶粒度 0.1 → **0.05** | S1.41 / 2Y1.54 |
| W105 | 治 sub（market/exchange/industry/sector） | ❌ **加轴全是退化操作**（5 个变体指标一位不差） |
| W106–W107 | 窗口/桶精调 → **发现 `group_rank` 轴抬 S +0.21** | S1.62 / 2Y1.34 |
| W114–W120 | 全方位算子穷尽（截面/轴/外层/时序） | `3qVpM32N` S1.65 / 2Y**1.58 == limit**（**卡在分辨率墙**） |
| **W136** | **轻框架探针 `rank(ts_mean(bf,5))`** | **S1.57 / F1.37 / TO0.059** ← 发现重框架在压信号 |
| **W138** | **轴深扫描（0/1/2/3/4 轴）** | 确认「轴越多 S 越低、2Y 越高」 |
| **W139** | **★ 双窗 × 轻轴**（双窗抬 2Y + 单桶轴保 S） | **`58glOpJn` S1.58 / 2Y1.73 / 0 失败** ✅ |
| **W140** | 窗长终扫 → **`w1=1 / w2=210`** | **`9qWX78vV` S1.65 / F1.47 / 2Y1.69 / 0 失败** ✅ |

**关键洞察（推导链条）**：
1. 重框架下 S 卡在 1.58~1.65、2Y 卡在 1.58（**== limit 判 FAIL**，需真值 ≥1.585）
2. 轻框架下 S1.62 但 2Y 只有 1.13 → **轴层数是 S↔2Y 的跷跷板**
3. **把两个旋钮拆开用**：**双窗（管 2Y）+ 单桶轴（管 S）** → 一次破关
4. 窗长微调到 `1/210` 再抬 S +0.07

## 四、ANALYST 专属经验（4 条）

### 1 ★★★ 49 个字段分 7 类，只有「变化率」携带信号

连**有研报支撑的最大类（分歧度，17 字段）**也全灭。
**⇒ 机制匹配是必要条件而非充分条件；先判字段有无信号，再谈配机制。**

### 2 ★★★ 同族字段不迁移（8 个里只有 1 个成立）

`eps_y1/y2`、`netprofit_y1/y2`、`revenue_y1/y2` —— 命名、结构、覆盖几乎相同，**只有 1 个能过闸**。

### 3 ★★ 「2Y 有 S 无」是本族计数类的判死形态（出现 3 次）

见到即判死，**不必再调参**。

### 4 ★★ `w1=1 / w2=210` 是本族最优双窗

且在 MODEL 式框架（W140）**独立复现** ⇒ 捕捉的是该机制的真实时间尺度，不是过拟合。
