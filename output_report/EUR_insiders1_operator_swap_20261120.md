> 触发：用户 2026-11-20 新规则「每加一个算子就把同类型算子全替换一遍回测，看是否对指标值有改善」。
> 工具：`tools/operator_swap_matrix.py`（本轮为该工具首个实盘应用）。
> 基线：`blaO2YVN`（insiders1 六层骨架，历史标准档最优）S1.01 / F0.52 / TO4.18% / 2Y1.30，TOPCS1600×COUNTRY×decay4。
> 结论：**16 个同 category 替换全部劣于 `ts_sum`；该族内核是「累积水平」而非「时序形状」，算子替换不是破闸杠杆。**

## 1. 基线表达式与替换轴

```
rank(group_scale(tail(winsorize(group_zscore(
  ts_sum(divide(multiply(vec_sum(insd1_valueeur), vec_avg(insd1_tradesignificance)),
                  vec_sum(insd1_holdings)), 44),
  industry), std=2), lower=0.25, upper=0.75, newval=0.5), industry))
```

替换轴 = `ts_sum`（Time Series，窗口类 `op(x,d)`）。工具产出 **16 个合法替换 / 6 个 arity+no-op 跳过**
（跳过的：`days_from_last_change`/`hump`/`ts_step`/`ts_target_tvr_decay`/`ts_target_tvr_hump` arity 不兼容、`ts_sum` 自身）。
`ts_product` 撞 UNITS 闸（`Incompatible unit ... expected Unit[], found Unit[CSPrice:1]`）——量纲坑再现，已剔除。

## 3. 归因：为什么 `ts_sum` 不可替代

三类替换各自破坏同一件事——**「累积水平」信息**：

1. **时序相对化（等价族）全灭**：`ts_rank` −0.04 / `ts_zscore` −0.09 / `ts_quantile` −0.20 / `ts_scale` −0.31。
   这族 alpha 的全部信息在**「这只股票的内部人累计买入有多重」的截面水平**上；
   把它换成「在过去 44 天里的相对位置」等于把 level 扔掉，只剩形状 —— 形状里没有 alpha。
   ⇒ **与 institutions6（买家**比例**是内核）相反：insiders1 的内核是水平，不是比例、不是形状。**
2. **`ts_mean` 掉到 0.20（ΔS −0.81）**：稀疏事件流下 `ts_mean` 按**有效观测数**归一，
   `ts_sum/44` 的常数抵消只在「44 天全有值」时成立；insiders 申报是事件型（cov 0.55），
   有效观测数本身携带信息（**申报越频繁 = 内部人越活跃**），归一化把这层信息抹掉了。
   ⚠ 因此 `ts_mean` 在「divide → group_zscore」链上**不是** `ts_sum` 的 no-op（§17.1 的等价性只对「窗内有效数恒定」成立）。
3. **时点/差分类（`ts_arg_min/max`、`ts_max_diff`、`ts_delta`、`ts_av_diff`）**：最好也只有 0.54。
   它们回答「多久没发生极值/相对峰值多少」，与「累计买了多少」是不同经济问题。
4. **平滑类 `ts_decay_linear` 归零且 TO 冲到 152%**：与 GBR news50「ts_decay_linear 一次抬 S/F/2Y」正相反。
   该族信号是**存量**（持仓累积），平滑存量只会引入滞后 + 把权重摊到历史，反而制造换手。

**判据**：`ΔS` 沿「保留水平 → 保留部分水平 → 丢掉水平」单调下降（1.01 → 0.54/0.49 → −0.31），
是一条**机制可解释的单调轴**，不是噪声。

## 4. 结论与后续

- **本族算子轴已穷尽**：`ts_sum` 是最优实现，同 category 替换**无改善**（16/16 劣化，最好 −0.47 S）。
- 该族真正的缺口仍在 S（1.01 vs 1.58）与 F（0.52 vs 1.0）；按 EUR 三段式 §2.1 C 分支已否决（S_required≈1.9 > 1.01+spread），
  **不进入设置轴扩网格**。
- 唯一未被本轴覆盖的破闸方向：换信息源 / 换经济机制（如 buy/sell 分向、稀释 vs 增持的方向拆分），
  这不是算子替换能解决的。
- **方法论沉淀（两条）**：
  ① 「同 category 全替换」的**收益取决于族的内核是水平还是形状**——水平型族（insiders1）替换必负，
     形状型族（GBR news50）才可能靠替换破闸；
  ② `ts_mean` 在稀疏事件窗上不等于 `ts_sum/常数`，**no-op 判据必须绑定「窗内有效观测数是否恒定」**。
