## 三、机制解释（为什么不可移植）

`ts_delta`（水平 → 变化）在**水平量**上有效，因为变化量含增量信息；
但 anl93 的字段本身已是**率**（correct_revision_ratio / profitability = 比率/skill）——
对一个率再做差，得到的是**噪声主导的二阶量**，因此级联崩到 0.32~0.66。

**⇒ 配方的可移植性取决于「字段的类型」**：
| 字段类型 | 有效变换 |
|---|---|
| 水平量（利润额、借券笔数） | **`ts_delta` 双窗级联** |
| 率 / 指数（正确率、评级、换手） | `ts_mean` 平滑 + 字段联合（**不要级联**） |

这与 memory 既有结论一致：「`ts_delta` 是基本面类的有效杠杆，但长窗平滑/其它变换**非普适**，逐字段族实测」。
