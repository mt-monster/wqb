## 三、为何「10 颗」在本数据集不可行（结构性三条）

| # | 原因 | 证据 |

| 3 | **同骨架互斥** | 同骨架变体互相关 >0.99（项目铁律）；换窗/换 tvr 即撞池 ⇒ 本骨架族**只能留 1 颗** |

`analyst` / `news` / `sentiment` / `insiders` / `risk` / `pv` / `earnings` / `macro` / `imbalance` / `option` / `socialmedia`
（已点亮：`institutions=1` / `model=1` / `other=2` / **`fundamental=1`** —— 本次目标类别已在上一轮被点亮）。

**`fundamental` 类别的可产出上限 ≈ 1 颗。**
