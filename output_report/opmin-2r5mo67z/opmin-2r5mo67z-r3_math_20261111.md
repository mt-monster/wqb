## 一、数学层面的可压缩性判定（先证后测）

把 27 ops 按「数学角色」拆成 6 类，逐类判定能否压缩：

| 类别 | 构成 | ops | 数学性质 | 判定 |
|---|---|---|---|---|
| 向量→标量 | `vec_avg(insd1_holdings)` | 1 | VECTOR 字段必须降维 | **不可压**：`insd1_holdings` 是 VECTOR（coverage 53.4%），平台无 MATRIX 等价字段 |
| 分组构造 | `bucket(rank(cap))` | 2 | 分组必须无量纲整数 | **不可压**：类型系统强制，见 §二.4 |
| 同字段多统计量 | `ts_mean(v,66)` / `ts_delta` / `ts_ir` | 3 | 均值/差分/信息比 | 部分承重，见 §二.3 |
| 分组秩 | `group_rank(·,sector)` ×4 | 4 | 各接不同输入，无公共子式 | **不可合并**（单调变换不能跨输入分配） |
| 截面秩+时序均值 | `rank(ts_mean(x,w))` ×4 | 8 | 见 §三「秩不可加」 | **唯一真实空间** |
| 线性组合 | `add`×3 / `multiply`×2 / `divide` | 6 | 多参算术已摊平 | **已到下限**：因式分解不省（见 §四） |

## 二、已实证否决（4 条，全部有平台读数）

### 1. `vector_neut(core, cap)` 替代分桶中性化 —— ❌
- 数学设想：`bucket(rank(cap))` 桶内去均值 ≈ 对 cap 做 10 段阶梯式中性化；`vector_neut` 是对 cap 线性回归取残差，更细腻且省 2 ops（3→1）。
- 实测（`LLKl8EZm`）：S **2.64 → 1.52**（−1.12），F 1.22，2Y 1.42，触发 `LOW_SHARPE` + `IS_LADDER_SHARPE` 双 FAIL。
- 附带 `UNITS` 警告：cap 单位为 `CSPrice×CSShare`，不符合 `vector_neut` 第 2 参期望的 `Unit[]`。
- 结论：**规模效应在本骨架中是非线性的**，阶梯分桶不可用线性回归替代。

### 2. `ts_zscore(x,w)` 替代 `rank(ts_mean(x,w))` —— ❌
- 数学设想：两者都是「标准化」，`ts_zscore` 是 1 op，原式 2 ops，4 项可省 4 ops。
- 实测（`xAvmV0lw`）：S **0.18**，F 0.02，TO **78.6%**，DD 35.8%，5 项 FAIL。
- 结论：**时序标准化 ≠ 截面标准化**。截面 rank 抹掉了个股量纲差异、保留「当期相对强弱」；时序 z-score 保留了量纲、引入了个股自身波动率差异，且信号变成慢变量 → 换手率暴涨。

### 3. `ts_rank(v,66)` 替代 `group_rank(ts_ir(v,66))` —— ❌
- 数学设想：`ts_ir` 是 `ts_mean/ts_std` 的比值，`ts_rank` 也是「沿时序归一化」，1 op vs 2 ops。
- 实测（`9qlA86zq`）：S **0.20**，F 0.04，TO **93.9%**，`CONCENTRATED_WEIGHT` 0.5。
- 结论：`ts_ir` 的**分母 `ts_std` 是承重件**——它把持股水平按自身波动率归一，等价于「信噪比」；`ts_rank` 丢掉分母，退化成纯水平排序，与 leg1 的动量项高度共线。

### 4. `bucket(cap, ...)` 去 `rank` —— ❌（**类型系统强制，非经验**）
- 数学设想：`bucket` 官方签名写作 `bucket(rank(x), range=...)`，若内部自动 rank 则外层 `rank` 冗余。
- 实测报错原文：
  > `Incompatible unit for input of "group_neutralize" at index 1, expected "Unit[Group:1]", found "Unit[]"`
- 结论：**`cap` 带 `CSPrice×CSShare` 单位，`bucket` 无法产出 `Unit[Group:1]` 分组对象；只有 `rank(cap)` 先抹掉量纲才能成组。** 这是类型检查层的硬约束，任何区域/骨架都适用 —— 计入通用规则。

## 三、数学硬边界：「秩不可加」

4 个 `rank(ts_mean(x_i, w_i))` 共 8 ops，是 27 ops 里最大的一块（30%）。为什么压不掉：

- **`rank` 不是线性算子**：`rank(a) + rank(b) ≠ rank(a+b)`。前者是「两个相对强弱的和」，后者是「合成的相对强弱」。
- 上一轮把 4 项全部合并成 `rank(add(4 个 ts_mean))`（`gJaoeM50`）：S **1.80**（−0.84）。
- 本轮把 4 项按**同窗口两两合并**成 `rank(ts_mean(x_a+x_b, 5))` + `rank(ts_mean(x_c+x_d, 22))`（`blaWJYZM`）：S **2.21**（−0.43），TO 14.51%（**改善 3.88pp**），全闸 PASS。
  ⇒ 合并粒度越粗，损失越大；但**换手率同步改善**，说明被合并掉的正是「高频截面翻转」部分。
- 数学解释：4 个分析师字段（`predicted_surprise_f12m_ebitda`、`predicted_surprise_pct_fy2_earnings`、`mean_estimate_change_pct_f12m_ebitda_14d`、`_90d`）测的是**同一经济量的不同视角**（水平 surprise / 相对 surprise / 短期修正 / 长期修正）。分开 rank 再相加，等于让 4 个视角**各自投一票**；合并后只投一票，等于降权。S 掉 0.43 就是这 3 票的价值。

## 四、为什么因式分解不省算子（一般结论）

`core` 是 8 参 `add`，本身就是 **1 次调用**。任何「提公因式」都要额外引入 `add`/`multiply`：

```
原式：multiply(grA, grm) + grm    →  multiply 1 op ＋ core 里 grm 项（免费）
因式：grm * (grA + 1)             →  add 1 op ＋ multiply 1 op          ⇒ 多 1 op
```

**规则**：在多参算术只计 1 次调用的前提下，**加法项永远「免费」**，任何把「和式中的两项合并成乘积」的变换都会净增算子。⇒ 后续不必再尝试因式分解类压缩。

### 关键读数解读

**1. 删 `leg1`（D，27→23）几乎免费**
- ΔS **−0.04**、ΔF −0.05、ΔRet −0.02pp、ΔTO +0.34pp、ΔDD −0.03pp。
- 落在方案 D v2 的 L1 边界内（`ΔF<−0.05` 才算硬拦，此处恰为 −0.05，不越线），L2 配对判据完全不触发。
- 业务解读：`leg1 = gr(Δ持股) × 份额` 这条「动量交互」被 `grm` 主效应 + 4 个分析师项**完全吸收**了。DEU 内部人持股变动本身信息量低（季度披露、53% 覆盖），市场对「持股变化」的定价早已反映在「持股水平」里。

**2. 删 `leg2`（E，27→23）换到更好的尾部质量**
- ΔS −0.05、ΔF −0.09，但 **2Y 2.86→2.94（+0.08）**、**DD 5.06%→4.33%（−0.73pp）**。
- 业务解读：`leg2 = gr(ts_ir) × (1 − gr(近期变动))` 这条「新鲜度」腿把**老持仓**也纳入多头，是老持仓在近两年贡献负 alpha → 删掉后 2Y 显著改善、回撤变浅。**它是「提升全期 S、牺牲近期稳健」的项。**

**3. 两条交互腿是互斥的「S vs 尾部」取舍**
- 保留 `leg1`：S 更高（2.60）、2Y 略低（2.77）
- 保留 `leg2`：2Y 更高（2.94）、DD 更浅（4.33%）、S 略低（2.59）
- 两条都删 = 见 §六（20 ops）

**4. 纯内部人版本（G）不可行** —— S 1.52 < 1.58 线。
分析师 4 项不是「装饰」，是**信号强度主体**：删掉后 TO 从 18.4% 降到 11.3%（说明分析师项是换手的主要来源），但 S 崩到线下。
⇒ 结论：**这条线本质是「内部人 × 分析师修正」的合成信号，任一半单独都不过闸。**

**5. 分析师 4 项的合并代价（B/C）**

- ⇒ **换手率改善全部来自 5 日窗口那一对的合并**（22 日对合并几乎不再降换手）。说明高频翻转由 5 日短窗口驱动。

## 九、最终结论

### 采纳：`88NKJOav`（23 ops，−15%）

```
v    = vec_avg(insd1_holdings);
tot  = add(significant_value_1, significant_value_2, significant_value_3, significant_value_4);
grm  = group_rank(ts_mean(divide(significant_value_1, tot), 66), sector);
gri  = group_rank(ts_ir(v, 66), sector);
leg2 = multiply(gri, add(group_rank(days_from_last_change(v), sector), -1), -1);
core = add(leg2, grm, gri,
           rank(ts_mean(predicted_surprise_f12m_ebitda_4, 5)),
           rank(ts_mean(predicted_surprise_pct_fy2_earnings_4, 22)),
           rank(ts_mean(mean_estimate_change_pct_f12m_ebitda_14d_4, 5)),
           rank(ts_mean(mean_estimate_change_pct_f12m_ebitda_90d_3, 22)));
group_neutralize(core, bucket(rank(cap), range="0,1,0.1"))
```

**方案 D v2 判定**：ΔS −0.04（未破 −0.05 硬拦）、ΔF −0.05（恰在边界，未越线）、ΔRet −0.02pp / ΔTO +0.34pp / ΔDD −0.03pp ⇒ L2 配对判据不触发 ⇒ **`pass`**。

**塔（六元组）**：席位 `DEU/D1/PV` + `DEU/D1/INSIDERS` + `DEU/D1/MODEL`（三类混塔）→ 倍率按木桶短板 ⇒ `effective = 0` → 当季计数 PV 0 / INSIDERS 1 / MODEL 3 → 交后计数不变（三席均未被本件推进到 3）→ **不新点亮** → **塔边际 0**。与 `oma9apvk` 完全一致，压缩不改变塔属性。

**六维**：distinct ops 12→11，T1 Δ +0.0196 → **+0.0169**（改善 0.0027）；T2 Δ +0.0189 不变；T3 保留 `days_from_last_change` 新算子（**+1**）；T4 新字段不变。⇒ 六维**净改善**。

### 备选：`Jj85zO52`（同样 23 ops，尾部更优）
保留 `leg1`、删 `leg2`：S 2.59 / F 2.08 / **2Y 2.94** / **DD 4.33%**。
适合「要近期稳健、能接受 T3 −1」的场景。**因 T3 会丢掉 `days_from_last_change`，六维上劣于 `88NKJOav`。**

### 已封死的方向（不必再试）
1. 压缩分析师 4 项（任何粒度）：S 至少 −0.27
2. 压缩 `bucket`+`rank`：类型系统强制
3. 压缩 `vec_avg`：字段是 VECTOR，无 MATRIX 等价
4. 压缩 `ts_ir`：它是 `gri` 的唯一承重件
5. 因式分解 `core`：多参算术下加法项免费，必然净增算子
6. 两条交互腿都删：S 0.47
7. Python alpha 移植：VECTOR 字段不支持
