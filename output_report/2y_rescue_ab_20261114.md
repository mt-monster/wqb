## 1 `winsorize` 的适用边界（三次证伪后收窄）

上一轮 GBR 分组式靠 `winsorize(std=2)` 把 2Y 从 1.52 修到 2.46，本轮在 EUR/IND 全部失效：

| base 最外层算子 | 输出分布 | winsorize 效果 |
|---|---|---|
| `group_neutralize`（GBR 分组式） | 去均值原始幅度，厚尾 | **有效**：2Y 1.52 → 2.46 |
| `group_zscore`（EUR） | 已标准化的 z 分数 | 无效：1.13 → 1.08 |
| `rank`（IND） | 0–1 均匀分布 | **no-op**：五项逐位相同 |
| `trade_when`（GBR 条件式） | 锁值（rank 值 / −1） | **no-op**：std=2 与 std=3 逐位相同 |

⇒ **判据：`winsorize` 只对「保留原始量纲且厚尾」的输出有效。**
看到 `rank` / `group_rank` / `quantile` / `zscore` / `group_zscore` / `trade_when` 作最外层，
就别在上面试 `winsorize`——它要么 no-op，要么只是白掉一点 margin。

⇒ **跨区不可照搬**（与论坛自己的免责声明一致）。这两个区的 2Y 不是中性化口径问题。

## 3 真正的病因：信号生命周期衰减，不是设置或权重

两条候选的共同特征：**全期 Sharpe 极高（3.14 / 3.63），但近两年断崖**。
若病因是「少数极端股主导收益」，`winsorize` 应有效——实测无效；
若病因是「中性化模型与近期市场冲突」，换档应有效——实测无效（甚至更差）。
两个假设都被排除后，剩下的解释是**信号本身在近两年失效**：

- EUR `imb5_score` 是订单簿失衡（微观结构），这类信号在高频化市场中衰减极快；
- IND `sector_value_momentum_rank_float` 是行业价值动量排名，近两年风格切换后失效。

论坛评论亦印证：「主池强会掩盖近年衰减，只看总 Sharpe 你根本不知道信号是不是已经过期。
数据集是有生命周期的。」

## 4 结论

| 结论 | 证据 |
|---|---|
| `winsorize` **不是通用 2Y 修复器** | 4 个 base 外层算子中只有 `group_neutralize` 有效 |
| 中性化换档**不能跨区照搬** | IND +0.01、EUR −0.21（对 2Y） |
| 这两条候选的 2Y 是**结构性衰减** | 两种病因假设均被证伪 |
| 应判死，不再磨 | 设置/算子层面已无杠杆，继续投入属 D0-P 禁止的「磨同腿变体」 |

## 5 可复用的预判规则（本轮净产出）

**在给一条 2Y 不达标的候选安排「抢救」之前，先看它的 `S / 2Y` 比值**：

| S / 2Y | 解读 | 动作 |
|---|---|---|
| < 1.3 | 长端与全期一致 | 值得试 `winsorize`（若外层未标准化）/ 换档 |
| 1.3 – 2.0 | 有衰减但可救 | 优先试设置轴，其次算子轴；最多两轮 |
| **> 2.0** | **信号已过生命周期**（本例 3.63/1.13 = 3.2、3.14/1.51 = 2.1） | **直接判死换机制**，不在参数上磨 |

本轮两条的比值分别是 **3.2** 与 **2.1**，都落在「直接判死」区，事后再看两个方向全灭，规则成立。
