## 三、本轮学到的可复用纪律（已固化到工具）

1. **三闸查不出参数值类型** —— 实测事故：辅助函数按位置传参写成 `d(AD, 8, '-')`
   ⇒ 生成 `ts_backfill(F,-)`，**元数合法但值非法**，`ensure_safe_for_dispatch` 放行，**整批 8 条 CANCELLED**。
   **已固化**：新增值型自检 `_lint_expr_values()`，**自动接入 `dispatch`，检出即 exit 3 拒发**。
   **写法纪律**：符号放最外层（`-rank(ts_delta(ts_backfill(F,500),8))`），辅助函数一律关键字传参。
2. **收割必须对"非 JSON 响应"容错** —— 平台限流时返回非 JSON body，原代码直接 `.json()` 炸掉整批。
   **已固化**：新增 `_get_json()`（空 body/非 JSON 重试 + 打印片段）；单条 alpha 拉取失败改为**跳过不断批**。
3. **`group_zscore` 有作用域** —— 对信用/结构化信号 +F 0.10~0.17，但**对模型概率输出反而变差**（1.11→0.95）。
4. **分组轴 × 信号强耦合** —— 统计聚类轴 `sta1_*` 对信用/估值信号全面劣于 `industry`。
