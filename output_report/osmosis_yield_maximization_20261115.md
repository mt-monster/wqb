## 1. 收益公式（官方机制，决定优化目标在哪）

```
每日收益 = Base Payment × Quality Factor
         = (Quantity × Self Growth × Quality × Value) × [合并主题倍数 × Osmosis Multiplier]
                                                    ↑__________↑
                                          Osmosis 分配只影响这一项（1–2×）

合并倍数 = (Pyramid + Theme + ... − 项数 + 1)     ← 由挖掘选题材决定，与点数无关
Osmosis Multiplier ∈ [1, 2]                        ← Daily Osmosis Rank 决定
```

关键事实（官方指南原文 + WL13229 70 赞帖）：
- Daily Osmosis Rank = **各已分配 scope「当日 OS PnL 横截面排名」的算术平均**（不是点数加权、不是质量排名）
- rank 锁点周日 23:59 EST，**+7 天生效**，评的是「2 年前对应日的 OS PnL」
- rank → multiplier 是 1–2× 的映射（WL27618 9 赞帖实证：乘数 = 1 + rank，即 rank 0.97 ≈ 1.97×，rank 0.2 ≈ 1.2×）
- **scope 数量不加钱**："Performance is not proportional to number of scopes"——加 scope 只有在它 rank 好于现有均值时才加分
- VF/WF 与点数分配无关（VF 是提交质量维度）

⇒ **优化目标唯一：最大化 E[各 scope 的 PnL 横截面排名均值]**。PnL 由「选哪些 alpha + 各给多少点」决定，点数是组合内权重。
