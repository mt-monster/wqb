## 三、★ 结构性成因（为什么本类不可能出可提交 alpha）

1. **因子性质**：GBR TOP700 = 英国**大市值蓝筹**。VA / 质量 / 应计是**全球最拥挤、被研究最久的经典因子**，
   在成熟大盘股上 α 已被套利抹平（195 条平均 S ≈ 0 就是证据）。
2. **fitness 结构上限（最致命）**：季频数据 ⇒ 换手天然只有 **0.02–0.09**，远低于 `F` 公式的 0.125 地板：
   `F = S·√(ret / max(TO, 0.125))`，地板生效时 `F = S·√(ret/0.125)`，
   而慢信号的 `ret` 也低 ⇒ **即便 S 做到 1.6，F 也只有 ~0.8–1.0**，双闸难以同时过。
3. **2Y 普遍塌**：本类最佳腿 2Y = −0.1，说明近年效应反向。
